# 已领养作品发布

已领养角色沿用同一条作品记录和详情链接。管理员可以下架整理图片，仅保留出厂照，再重新上架。

| 操作 | 验收条件 |
| --- | --- |
| 创建或保存草稿 | 可先录入角色资料，之后补图。 |
| 发布或重新上架已领养作品 | 至少一张已就绪的出厂照，图片说明、主图和构图沿用现有校验。仅有横版封面、设定图或两者都没有时，缺出厂照均拦截发布。 |
| 移除旧封面 | 下架后已有合格出厂照时，可以移除横版封面。旧设置里指定的领养封面来源不阻塞保存和发布。 |
| 公开展示 | 仅有出厂照也可进入作品目录，详情展示出厂照、已领养状态及已填写的署名和价格。具有合格竖版出厂照且被选为代表作品时，可用该照片进入首页精选。已领养作品退出当前领养和领养目录。 |
| 重新开放领养 | 已发布作品须有可用的领养展示来源才能切回可领养。草稿按原流程补齐横版封面或设定图再发布。 |

本规则适用于发布动作。历史已发布作品保留原有详情和展示资格。公开领养与作品目录继续沿用需求 6、12、13 的选图、收录和署名规则。
