# 媒体公开与保护策略

> **角色**：当前媒体公开行为的唯一事实源。
> **状态**：2026-08-05 经用户确认；阶段 C.1 的实现目标。当前代码仍存在站点大图带水印的旧行为，必须按本文迁移。
> **适用范围**：首页、委托页、作品、领养、管理预览、OSS 衍生图、品牌水印切换与清理。

## 1. 核心原则

是否打水印由**公开展示位置**决定，而不是由图片横版或竖版决定。

- 站点展示位用于品牌首页和业务入口，应保持图片干净，不打水印。
- 作品展示位用于公开作品档案和领养展示，继续使用活动品牌水印。
- 永久原图、预处理源和水印 Logo 始终保存在私有 Bucket，不得直接作为公开 URL 返回。
- 所有公开图片都必须是服务端预生成、可校验、不可变的公开衍生图；浏览器不得通过 OSS 查询参数临时变换私有原图。

## 2. 展示位置矩阵

| 展示位置 | 媒体来源 | 公开保护方式 | 说明 |
| --- | --- | --- | --- |
| 首页 Hero 横图 | 首页横版资产 | 无水印 | 生成独立站点展示衍生图 |
| 首页 Hero 竖图 | 首页竖版资产 | 无水印 | 与横图使用同一站点展示配方族 |
| 委托页 Hero 横图 | 委托页横版资产 | 无水印 | 不复用作品详情水印图 |
| 委托页 Hero 竖图 | 委托页竖版资产 | 无水印 | 不受活动水印 profile 切换影响 |
| 首页“自设委托”入口 | 委托业务代表源 | 无水印 | 使用独立 `home-entry-commission` 衍生用途，不直接复用 Hero URL |
| 首页“角色领养”入口 | 当前领养代表源 | 无水印 | 使用独立 `home-entry-adoption` 衍生用途，不直接复用领养设定图公开 URL |
| 首页精选作品 | 作品主图 | 活动水印 | 使用作品卡片衍生图 |
| 作品列表 | 作品主图 | 活动水印 | 保持现有作品保护边界 |
| 作品详情图集 | 出厂照、设定图 | 活动水印 | 横竖图都按作品位置打水印 |
| 领养列表 | 领养设定图 | 活动水印 | 继续使用活动水印 |
| 领养详情 | 设定图、出厂照 | 活动水印 | 与统一作品详情保持一致 |
| 管理端原图预览 | 私有原图 | 不公开 | 仅认证管理 Host、`no-store` |
| 管理端水印预览 | 私有临时预览 | 活动或草稿 profile | 有时效、可清理、匿名不可读 |

## 3. 两类公开配方

### 3.1 站点展示配方

阶段 C.1 新增 `site-display-v1` 配方族，覆盖首页 Hero、委托页 Hero 和首页两个业务入口。

目标身份至少包含：

- `assetId` 与输入 SHA-256；
- 公开用途；
- 输出宽高、格式、质量、裁剪或焦点身份；
- `recipeVersion = site-display-v1`；
- `protectionMode = none`；
- 不携带水印 Logo、profile、位置、不透明度或缩放身份。

数据库可以使用显式 `protection_mode`，也可以使用等价的严格枚举表达；不得靠空字符串和宽松 NULL 组合猜测是否有水印。

站点展示衍生图必须：

- 同时提供 WebP 与 JPEG/PNG fallback；
- 写入公开 Bucket；
- 使用内容寻址或完整身份寻址的不可变 Object Key；
- 禁止覆盖既有对象；
- 写入后校验 MIME、尺寸、字节数、摘要与匿名读取；
- 失败时只清理本次新建对象，不影响当前已启用版本。

### 3.2 作品保护配方

作品列表、详情、领养列表和领养设定图继续使用：

- `recipe-v2`；
- 活动 `brand-centered-v2` profile；
- 当前配置的 Logo、位置、透明度和缩放身份；
- 现有横竖图片水印几何规则。

水印 profile 的变化必须生成新 Key，并在完整校验后原子切换。旧 profile 在仍被公开快照引用时不得删除。

## 4. 首页业务入口的独立派生

首页两个入口不能再直接消费以下 URL：

- 委托页 Hero 当前公开 URL；
- 第一件领养作品设定图当前公开 URL。

允许继续从对应业务源资产选择输入，但必须生成独立用途：

- `home-entry-commission`；
- `home-entry-adoption`。

独立用途的意义包括：

- 保证两个入口采用统一比例、尺寸和裁剪策略；
- 保证入口图片无水印，而作品和领养页面仍有水印；
- 后续调整首页入口样式时不改变委托 Hero 或作品详情图；
- 清理与再生成可以按展示位置精确执行。

若委托 Hero 或可公开领养不存在，对应入口应隐藏或显示无图片的受控状态，不得回退到任意作品或私有原图。

## 5. 品牌 profile 切换边界

应用新的水印 Logo 或参数时：

- 只重新生成和切换需要水印的作品保护衍生图；
- 不重新生成 `site-display-v1` 无水印衍生图；
- 不删除站点展示衍生图；
- 管理端影响摘要必须明确区分“作品保护图片”和“站点无水印图片”；
- 旧 profile 切换失败时，公开作品继续使用旧活动 profile，站点展示图片不受影响。

## 6. 私有与公开存储边界

### 私有 Bucket

保存：

- 永久原图；
- FFmpeg 预处理或低分辨率适配源；
- 水印 Logo 候选；
- 管理预览与临时处理对象。

要求：

- 匿名读取失败；
- Object Key 不进入公开 DTO、HTML、日志或 CSV；
- 临时对象有精确清理和生命周期兜底；
- 永久原图不得由生命周期规则误删。

### 公开 Bucket

只保存通过完整身份生成和验证的衍生图。公开对象必须能从数据库记录追溯到输入资产、用途、配方和保护模式。

## 7. 迁移与兼容

阶段 C.1 迁移应满足：

1. 保留现有作品水印变体和历史 profile；
2. 为站点展示位生成新的无水印变体，验证完成后再切换公开投影；
3. 不原位覆盖当前有水印 Hero 对象；
4. 新代码只把旧 Hero 水印变体作为迁移前兼容读取，不再生成；
5. 首页领养入口切换到独立无水印用途后，领养列表与详情仍继续引用有水印变体；
6. 迁移失败时保持旧公开页面可用，并留下可恢复操作记录；
7. 完成用户验收后再清理不再引用的旧站点 Hero 水印对象。

## 8. 验收标准

- 首页 Hero 和委托页 Hero 的横竖请求均命中无水印站点展示变体。
- 首页委托与领养入口命中各自独立的无水印入口变体。
- 作品列表、作品详情、领养列表和设定图仍命中活动水印变体。
- 更换活动水印 profile 后，作品图片变化，四类站点展示图片的 URL 和摘要保持不变。
- 匿名用户无法读取任何永久原图、预处理源、Logo 候选或管理预览。
- 三个固定视口 `390×844`、`768×1024`、`1440×900` 均无坏图、错误裁剪和横向溢出。
- 真实双 Bucket 预检、失败清理、容器重启恢复和公开 DTO 泄漏检查通过。
