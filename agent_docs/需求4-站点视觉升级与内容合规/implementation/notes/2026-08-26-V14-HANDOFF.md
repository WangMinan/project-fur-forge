## Regression Risks

- Header overlay、scrolled 与 mobile-nav-open 三态共同影响背景和 Logo 颜色；后续改动必须回归非 Hero 页与首页滚动后的移动菜单实底。
- 修改 carousel 控制尺寸或 grid 时，必须同时检查 390px 宽度、单项隐藏逻辑和 pause/resume 可达性。
- 搜索清除行动不得通过去掉 padding 再次缩成小于 44px；隐藏控件也不得被自动审计误判为可见目标。
- Reduced Motion 覆盖必须保持与 Hero 初始媒体入场选择器同等或更高优先级，避免首帧短暂生成动画。
