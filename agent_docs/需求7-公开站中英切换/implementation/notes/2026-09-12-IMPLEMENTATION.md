## 已处理的接入问题

1. 模块默认匹配接受 `Accept-Language: en;q=0`。SSR 浏览器测试证明该行为违反规格；初始化钩子先过滤 q=0/非法范围，再调用模块公开匹配 API，保留其变体、权重与排序逻辑。Cookie 仍优先，无匹配回退中文，客户端沿用服务端结果。没有另建语言 store 或完整解析器。
2. SSR 图标在水合前已经可见，第一次点击可能丢失。按钮在 mounted 前保持 disabled，之后才接受交互；不是靠等待固定时间掩盖问题。
3. 公开与管理 Host 共用 i18n 模块。由现有 Host 边界给出管理站标识，公开组件翻译和 HTML lang 在管理站固定中文；错误页内部请求仅保留合法语言 Cookie 和有限语言头，不转发整份 Cookie。
4. 表单状态保留在原页面，语言只切换展示分支；不使用 locale page key。busy 状态实时阻止切换，英文 submit 处理函数也拒绝写请求。
5. Linux/x64 声明生成遇到 `tosource@2.0.0-alpha.3` 缺少 package.json license。该版本随包 LICENSE 为 Zlib，原字节 SHA256 为 `22cfaab2256435450e4375ef5593354cc3d53501f0ead3564336415b3909bae4`。生成器只为精确版本且每份已安装 LICENSE 均匹配该哈希的情况校准并附全文；其他未知包、版本或改动字节仍拒绝。单测覆盖正常、字节变化与版本变化。
