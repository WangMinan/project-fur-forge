# 素材输入私有归档说明

原始素材、旧研究输入及原型已转入仓库外私有备份。这里保留仍适用的输入边界；正式SPEC、媒体策略及后续明确覆盖条款继续为权威，不恢复旧原型里的退役能力。

- 用户提供的品牌、作品、设定图与返图分别由相应权利人授权，不因代码公开而授予素材复用权。
- 原始图片私有；公开站仅使用现用品牌衍生图或后台READY公开派生物，原始文件不得直连到公开DTO。
- 不把竞品截图复制为正式页面资源，不把宣传图中的历史二维码当作当前联系渠道。
- 横竖画幅、媒体角色、尺寸与构图按当前需求和发布链分别验证，不能用早期示例替代后台正式素材。
- 研究输入只提供历史参考。后续规格已明确退役的功能不因保留备份而重新启用。
