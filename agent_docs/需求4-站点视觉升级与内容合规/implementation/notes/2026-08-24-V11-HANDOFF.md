## Locked Decisions

- 首页不新增人工精选字段；既有领养排序和 `available` 状态是唯一来源，最多三项。
- 目录优先完整设定图、无设定图才回退横版领养封面；不改变数据库、媒体表或上传拓扑。
- V11 当前实现为 Desktop 两列、Mobile 一列；Desktop 结构继续作为本任务的完成基线。Mobile 一列只作为当前 Structural Safety 基线，后续可在 V12-G 按独立 Mobile Art Direction 重新构图；设定图完整性始终高于机械压缩图片高度。
- 角色名称固定进入独立横排信息面板，不再作为图片 caption；物种、价格和状态按无标签三行值展示。右下 folio 只是由真实列表顺序推导的构图元素，不是后台业务编号；详情入口由整项点击与面板行动共同承担。
- V11 不加入领养自动轮播、切换动画或 Motion choreography。
- V04 中“单幕双图且不恢复 folio/翻页”的 Featured 约束只保留为历史实现/Evidence；当前 Active Featured Visual Contract 已由 V09+、现行 Type × Media Scene、Featured switching 与 GATE-E criteria supersede。
- V09～V11 的完成状态、实现、Evidence 与 Handoff 保持关闭，不重新打开；这些任务已有的 390/430 截图只作为当时版本的 Mobile Structural Safety Evidence，不代表 Mobile Final Art Direction 已获批准。
- 后续静态路线固定为 V12-A～V12-E → `GATE-DESKTOP` → V12-F Mobile Homepage Independent Art Direction → V12-G Remaining Public Mobile Art Direction → `GATE-MOBILE`。Mobile 遵循 **Same visual language, different composition**，不要求继承 Desktop grid；页面媒体、非品牌 Typography、标题/meta、CTA、wayfinding、背景字、Negative Space、overlay 和 controls 可独立重构。Hero 的 Photography、crop/focal、media、scrim/overlay、controls、wayfinding、supporting copy 和周边空间可大胆调整，但“有点小狗工作室”默认继续遵守 Brand Lock，优先重构其周围空间。
- 仅当真实 390×844 / 430×932 构图证明品牌终态无法优雅成立，V12-F 才可记录具体冲突、提供 Mobile-specific alternative 与 before/after，并等待用户显式 exception approval；批准前不得修改品牌字号、核心位置或对齐。V12-F 不重新设计 Motion：一次性首次入场、换图不重复、Reduced Motion 直达终态、font flash 修复与当前 4s autoplay 事实继续保持，最终 choreography 属于 V13。
- V13 Motion 只有在 `GATE-DESKTOP` 与 `GATE-MOBILE` 均由凌巽本人明确通过后才可启动；V15 只负责跨断点、Input 与 Accessibility 最终 QA，不承担首次 Mobile Art Direction。
