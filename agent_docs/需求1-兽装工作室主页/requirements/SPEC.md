## 目标

1. 为“有点小狗工作室”建立以既有作品为核心的公开展示主页，让首次访问者快速理解其制作风格与完成能力。
2. 通过真实、获授权的作品图片和必要元数据形成可信的作品档案，而不是只有社交平台式零散图片。
3. 提供真实可用但保持精简的委托业务入口，以基本制作范围、当前开单状态与基本约定帮助访客判断是否值得联系，并通过邮件向 `3114559925@qq.com` 请求人工估价。
4. 提供明确的官方 QQ 与抖音入口，使感兴趣的访客能够离开网站后继续了解或联系。
5. 展示常规领养与展会掉落的角色、所属展会、当前状态、作品级属性与已录入的人民币价格，但把登记、定金、签约和后续沟通留在线下与邮件中完成。
6. 提供与公开站隔离的独立后台管理站，使景宸能够自行维护作品与状态、基本服务约定、领养设定图、出厂照、返图、展会、领养方式与状态。
7. 在不建设站内估价、线上登记或交易能力的前提下，为未来加入官网估价和更完整的领养流程保留可演进的信息架构。
8. 为后续设计和开发锁定可验证的页面、内容、权限与交互契约，防止从竞品外观反推本站需求。

## 非目标

- 本阶段不选择框架、托管平台、CMS、数据库或支付方案。
- SPEC 阶段不直接制作正式 Logo、生产品牌文案或业务代码；用户已在 PLAN 阶段明确要求用只读快速原型验证界面与交互，原型不是生产前端。
- 不直接复刻任何竞品的页面、图片、文案、Logo、专有插画或世界观。
- 不根据竞品价格、周期、付款比例或售后规则推定朋友工作室的规则。
- 首版不提供站内委托表单、在线估价器、自动报价或在线接受委托；委托意向与人工估价通过邮件完成。
- 首版不把委托统一价、排期、付款比例、修改次数、量体、运输和异常处理写成面面俱到的公开业务手册；这些内容由工作室在邮件或社交媒体中根据具体委托/领养确认。单件领养/掉落作品已录入的人民币价格不属于该禁止项。
- 首版可以公开一般领养与展会掉落的内容和状态，但不接受线上登记，不完成线上付款或签约。
- 公开站不建设注册、登录、个人中心、收藏、角色绑定、订单、进度管理或在线支付；后台管理账号不属于访客账户。
- 网站和后台不存储或展示制作过程图片，不建设独立制作完成度跟踪；制作过程通过 QQ 等私下渠道向客户沟通。
- 未经用户确认，不默认首版需要实际多语言页面；访问分析以 OQ-076 锁定的轻量访问统计为准（仅页面浏览量、来源页面、设备类型），多语言页面一期不做；独立内容后台已经纳入一期。

## 契约

> **需求与设计边界**：本 SPEC 锁定业务范围、页面集合、数据/存储契约、内容权限、验收口径，以及景宸确认的公开站视觉原则：“简洁、以图片为主，Logo、文字介绍和符号均为兽装展示服务”。因此图片优先级、首页全幅作品首屏和文本从属关系属于需求契约；具体字体、间距、组件造型和正式素材裁切仍在 PLAN/设计基线中确定。设计不得以品牌装饰、长篇说明或技术效果抢夺作品主体，不得引入未实现的交互控件，也不得破坏稳定 URL、动效预算与响应式目标。

### 接口契约

- 采用单一主站、多页签结构；一级页面固定为首页、作品展示、自设委托、角色领养、返图墙、关于我们/基本约定、联系。展会名称和掉落状态属于角色领养内容，不建设独立展会、公告/排期或 FAQ 页面。“关于我们”与“基本约定”共用一个页面和导航入口；`/terms` 仅作为 `/about#terms` 的兼容入口。自设委托页在正文后内嵌常见问题折叠区。
- 公开站全程无需登录即可浏览；独立后台必须登录。
- 公开主站不得显示后台地址、后台登录入口、原型切换按钮、开发/评审标签或其他管理面入口；管理员只通过独立后台子域名直接到达登录页。
- 生产公开页面不得出现只对设计、开发或维护者有意义的解释性文本，包括但不限于“规划阶段”“原型”“示例”“由后台维护”“后台人工顺序”“骨架/加载如何切换”“正式版本将如何表现”等。公开文案只描述访客需要知道的真实作品、业务状态、规则与可执行行动。
- 公开站视觉层级固定为：兽装作品图片 > 工作室名称/Logo/短页名 > 必要业务事实、状态和行动 > 装饰符号。Logo、文字介绍、图形标、编号和装饰符号只能帮助识别作品或完成行动，不得成为与作品图片竞争的主视觉。
- 首页禁止使用文字区与作品图区等权的左右分栏首屏。第一屏必须以一张获授权的代表作品图铺满可用视口，导航、工作室名称、最多一句短口号、一个作品主行动和向下提示以叠加方式辅助；不得出现多句介绍段落、业务说明卡或大面积纯文字区。
- 从首页首屏向下滚动后，必须优先进入代表作品浏览，再出现委托与领养入口、营业状态和其他辅助信息；不得在访客看到作品集之前插入大段品牌介绍或说明性文字。
- 有真实图片内容的一级页面应尽快把图片放入首个主要内容视口：作品展示和角色领养使用大图网格，返图墙使用照片墙，委托页先用代表作品图建立制作气质再提供范围、邮件入口与 FAQ。关于我们、基本约定和联系因内容本身为事实或规则，可以文字为主。
- 叠加文字必须避开后台保存的主体焦点，不得遮挡兽头、眼睛或关键工艺细节；正式素材到位后必须分别校准桌面与手机裁切和文字安全区。
- 首版首页必须回答：
  1. 这是“有点小狗工作室”；
  2. 工作室已经完成过哪些作品；
  3. 作品可以如何继续浏览；
  4. 如何进入独立联系页面。
- 委托是一期正式业务页签：通过基本制作范围、当前开单状态、简要邮件提示、内嵌常见问题和基本服务约定说明业务，并提供向 `3114559925@qq.com` 请求人工估价的入口。委托页不维护独立的「委托例图」图片类型；制作能力展示由作品页与出厂照承担。委托页可提供非穷尽的资料提示（引导访客在邮件中说明需求与准备材料），但不发布穷尽式资料清单，二者不冲突。
- 委托常见问题只可回答已确认事实：如何开始邮件咨询、可制作全装/半装、委托由人工估价、单件领养/掉落作品可公开人民币价格、官方联系渠道、作品展示与完工前不公开请求。不得把单件价格写成委托统一价；固定周期、加急、付款比例、修改次数、量体/DTD、运输或其他尚未确认的逐单规则不得写入 FAQ。
