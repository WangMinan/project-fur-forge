## 新确认的水印决定

- P0 新目标 profile 为 `brand-centered-v2`；
- 位置固定居中；
- 默认不透明度 50%；
- 默认缩放为目标图 60%；
- 管理端可以在 10%–90% 和 20%–90% 的受限范围内调整不透明度/缩放，但不能关闭水印或改回角落；
- 水印 Logo 由站点级候选资产管理，景宸可以上传/选择；浏览器不接触本地路径、Bucket 或 Object Key；
- 当前随应用 Logo 迁移为初始候选，不再作为服务端硬编码唯一来源；
- 水印源保存在私有 Bucket，与处理源同 Bucket；公开结果继续由 OSS 烘焙并 `sys/saveas` 到公开 Bucket；
- profile 和 Logo 变化生成新 identity 和新 Key；
- 应用配置必须先完整生成/验证，再原子切换，失败继续使用上一 profile；
- 旧 v1 variant 保留历史身份，但切换后不能满足当前发布检查；
- 作品编辑器中的四角“水印安全角”是 v1 遗留 UI，GATE-07 后移除。

## 仍然有效的边界

- 私有原图和私有预处理源永远无水印、不可覆盖；
- 水印不替代访问控制；
- OSS 是公开 variant、最终格式和水印的唯一像素权威；
- FFmpeg 只解决超过 OSS 20 MB 输入上限；
- 不引入自动媒体 worker、消息队列或多实例；
- 首页横版/竖版是独立资产；设定图、出厂照、返图和水印 Logo 是独立角色；
- 公开 DTO、日志和错误不含联系人、私有 Key、签名 URL、Session 或水印源信息；
- 所有非测试配置值由 `.env`、环境变量或不入库配置文件注入。
