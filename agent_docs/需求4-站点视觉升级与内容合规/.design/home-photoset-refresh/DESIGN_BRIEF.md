## 问题（真实浏览器 1440×740 实测，`screenshots/before-*.png`）

1. 第二幕留白过多：两张竖图上限 360×480，右侧约 45% 宽度全空，说明与按钮垂直居中漂浮。
2. 第三、四幕标题与居中文字列之间有死白带；媒体高 `min(68svh, 40rem)` 在 740px 矮视窗超出预算，图片底缘溢出视口。
3. 三幕图文排布各自为政；第二幕无进入动效；hover 旋转角不一致。
4. 文案行内字号不一（状态 label/tone、名称/物种）、段间前导 `·`、上下不对齐（用户逐轮指出）。

## 定稿：三幕同一「题注行 + 居中图版」语法

每幕 = **题注行（通栏）+ 居中图版**：

1. **题注行**：左置 eyebrow + 中文标题；右端同一簇收纳全部文字与行动——**文案一行、按钮一行**。文案行内所有字同号（`--font-size-sm`）、同行同轴（flex 行内居中），只靠颜色/字重区分内容；不加前导分隔符。名称·物种、营业状态 label/tone、领养状态、价格全部拉平到同一字号。
2. **图版**：占满题注行之下的剩余视口高度；桌面幕高 = `100svh − Header`，网格行 `auto / minmax(14rem, 1fr)`，图片居中。
3. **三幕媒体严格等高**：`--scene-media-height = min(图版剩余高度, (图版宽度 − 2×间距)/3 ÷ 0.75)`——第二幕三张 3:4 竖图均分宽度是各幕共同的最宽约束，因此任一桌面视口下三幕媒体高度一致（实测 1440×709 下三幕均 485px）。
4. **第二幕**：最多三张 3:4 竖图等高并排居中（对页感），1/2 件时同尺寸居中；隐藏名称/物种与唯一目录按钮不变。
5. **第三、四幕**：横版图按统一媒体高 × 16:9 居中放大（与既有 cover 裁切同向，宽源图轻裁顶底），图片继续主导画面。
6. 图片节奏由"左—右—左分栏交替"改为"三幕居中图版"，题注行恒定。
7. 移动端（<1024px）原生纵向滚动不变：第二幕文字在上、双图两行换行居中；三四幕图在上文在下；不套用桌面图版高度。

## 动效（依据 /animate 与既有 token，PC 优先）

- **进入（每幕首次进入视口，一次）**：图版 `clip-path: inset(0 0 6% 0) → 0` + `opacity .72→1` + `scale(.99)→1`，`media` 720ms / `standard`；题注行（标题簇与文案簇）`opacity + translateY(8px)`，`content` 420ms，延后 90ms。第二幕多图作为同一图版同时进入，不逐图错峰。
- **hover（仅 fine pointer）**：三幕统一 `scale(1.025) rotate(0.3deg)`，`state` 180ms `standard`，仅命中图片本身。
- **reduced-motion**：关闭 transform/clip，只保留 `state` 180ms opacity；SSR/无 JS 内容默认可见不变。
- 不新增循环动画、视差、Ken Burns、逐图 stagger、键盘长动画；逐幕 wheel 锁定节奏不变。
- 频率/目的判定：三幕进入属"每次首页一次"的营销场景（偶尔级），目的=防止突变+解释；hover 属 tens/day 轻反馈。
