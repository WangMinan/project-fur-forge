## Regression Risks

- 若重新加入 `.home-adoption-poster__stepper` 或其 `data-controls-revealed` / `data-paused` 状态，会恢复本次明确删除的重复控件和初始显隐缺陷。
- 若删除下方 `.home-adoption-poster__selector-item`、swipe 或 section 键盘事件，Homepage Adoption 将失去用户保留的显式切换入口。
- 若在 Mobile 恢复 `min-height: calc(100svh - header)`，最后一幕会再次在行动与 Footer 之间产生大段空白。
- 若 persistent Header 再次直接绑定 incoming route，Homepage 非 Hero scene 离场的 77px 单帧闪动可能复发。
