# 管理端信息架构

> **状态**：阶段 D 内容管理已落地并由用户验收；阶段 E 开发访问统计和生产媒体运维反馈，阶段 F 只在正式环境复验，但不把后台改造成通用 CMS。

## 1. 导航

已实现导航顺序：

1. 作品管理；
2. 返图管理；
3. 大图管理；
4. 文案配置；
5. 全局水印；
6. 修改密码。

阶段 E 增加“访问统计”，放在“全局水印”之后、“修改密码”之前。统计是低频只读工具，不占据后台首页，也不改变内容对象优先的顺序。

管理端可继续显示“有点小狗工作室 · 管理端”；公开导航显示“有点小狗”是独立契约，不能用一次全局字符串替换混淆两个场景。

## 3. 作品管理

列表使用共享 `.admin-list-page*`、`.admin-list-toolbar*`、`.admin-list-table` 样式，提供查找、状态和必要摘要。编辑页按管理员心智顺序组织：

1. 基本信息；
2. 作品类型与领养/展会掉落字段；
3. 私有源图；
4. 公开预览与保护模式；
5. 首页精选和顺序；
6. 发布状态；
7. 危险操作。

`event_drop` 只增加展会名称和时间文本。已发布作品仍可调整首页精选与 `sort_order` 并立即生效；该字段不影响 `/works` 和 `/adoptions`。

## 4. 返图管理

### 列表

- 一行一个设定，不是一张照片；
- 显示圆形主图、设定名称、照片数量、可选关联作品和发布摘要；
- 共用作品列表的页头、查找条和表格样式；
- 删除入口只在列表，确认信息明确：设定及其返图记录会删除，已发布内容先下架并清理公开对象，私有原图保留。

### 编辑页

1. 设定名称、公开 slug 和可选 `@昵称`；
2. 可选关联作品；
3. 多张返图上传、处理状态和删除；
4. 选择圆形主图 `is_primary`；
5. 设定级授权来源、确认时间和备注；
6. 公开预览；
7. 发布/下架。

关联作品为空、未发布或后来删除均不阻断返图发布。授权字段只在认证管理 DTO 中出现；界面不得暗示其会公开。

返图照片不提供人工排序。公开墙随机；设定页只承诺稳定、可理解的展示，不暴露内部 ID 或 Object Key。

## 5. 大图、文案和水印

- 大图管理服务首页与委托页，低分辨率图片可保存；启用时显示清晰度风险并要求确认；
- 文案配置只编辑既有固定字段，空字段真实隐藏；
- 全局水印只影响作品保护链，返图继续使用无水印 `return-display-v1`；
- 不展示内部 recipe、Bucket 名、Object Key 或数据库版本术语。

## 6. 访问统计（阶段 E）

页面只读，优先回答：

- 时间范围内的页面访问趋势；
- 热门公开页面；
- 来源与终端的粗粒度概况；
- 数据更新时间和采集边界。

不显示个人访问轨迹、可回溯长期访客标识或虚假实时数字。无数据、统计延迟和查询失败必须明确；统计失败不能影响内容发布。

## 7. 生产媒体反馈（阶段 E 开发）

- 发布成功表示公开查询可见且稳定的 ESA HTTPS 媒体 URL 可取图；
- 下架先立即从页面移除，再显示“正在撤销 ESA 边缘缓存”一类短状态；
- 撤销完成时间由 T53 在目标环境实测；成功/失败状态可追踪、失败可重试，不能把客户端已保存副本描述为可删除；
- 不向管理员显示 ESA/OSS 凭证、AK/SK、OSS 原站 URL 或缓存刷新 API 原始响应；
- 运维细节和阿里云人工步骤进入上线 Handbook，不堆在日常编辑页。

## 8. 错误与并发

- 表单错误使用清楚中文并定位到字段；
- `409` 区分版本冲突与业务门禁，按稳定服务端错误码/消息映射；
- 处理中、失败、可重试和已完成状态不能只靠颜色；
- 离开有未保存内容的页面时给出提示；
- 成功提示不能掩盖仍在进行的媒体处理或 ESA 边缘缓存撤销。

## 9. 验收

- `390×844`、`768×1024`、`1440×900` 三视口；
- 管理 Host 固定 `localhost`，公开 Host 固定 `127.0.0.1`；
- 作品与返图列表共用结构且无样式漂移；
- 返图多图、主图、可选作品、私有授权、发布和删除心智模型正确；
- 成功、冲突、失败、恢复、重载、键盘和焦点均实际点击；
- 生产媒体撤销状态真实且不会泄漏凭证、对象键或原站地址；
- 访问统计无数据/失败状态不会影响主要内容操作。
