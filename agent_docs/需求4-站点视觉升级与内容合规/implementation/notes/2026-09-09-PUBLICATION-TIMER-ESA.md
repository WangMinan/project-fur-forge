# 发布计时与 ESA 非阻塞下架

本次用户明确授权直接修复 main，并通过 `release-image.yml` 出包；业务范围仅重开下架等待 ESA 的行为。

- 发布面板为发布、下架、清理重试分别记录本次请求开始时间，进度组件在开始时间变化时刷新计时；不再复用首次挂载时间。
- 作品下架和 Hero 停用复用后台 ESA 精确提交，不等待提交响应，也不轮询完成。OSS 清理仍需完成，失败仍可重试。
- ESA 提交成功/失败仅更新缓存字段，不重开已完成的业务 operation；旧任务重试保留已有 TaskId，不重复提交。
- 页面不再声称 ESA 缓存已经撤销。后台提交为当前进程 best-effort，进程退出可能中断，不新增持久重试系统。
- 不修改 Schema、迁移或生产数据；截图中的历史数据库处理仅作为定位背景。本任务出包不包含服务器部署。

回归覆盖慢提交成功/失败均不阻塞下架、精确 URL manifest、迟到响应不改变 DONE、旧任务重试/恢复不重复提交，以及同页面发布→下架→再次发布计时重置。

本地验证：`pnpm check:fast` 通过（61 文件 / 318 测试）；`pnpm build` 通过；系统 Chrome 定向 smoke 通过（作品上传、发布、下架、再次发布和计时）。远程 release 结果以对应 Actions run 和镜像摘要为准。
