FAQ / 常见问题

委托前可以先看看这里。

如何开始自设委托？

先浏览作品与制作范围，再通过邮件说明角色名称、希望制作的装型和需求简述。景宸查看资料后会回复可行性与后续安排。

目前可以委托哪些装型？

目前提供全装与半装。半装由头部、手爪和尾巴组成；其他配件或服务不在当前公开范围内。

网站会直接报价或接收委托吗？

不会。网站不公开价格，也不保存委托表单；点击邮件入口后，由工作室根据实际角色资料人工沟通和估价。

如何确认工作室的官方渠道？

请以本站列出的邮箱 3114559925@qq.com、QQ 3114559925 与抖音 to3114559925 为准。

可以申请不公开自己的作品吗？

可以在完工前通过书面方式提出不公开请求，具体展示安排由双方逐单确认。

基本约定

01

工作室与制作范围

02

逐单沟通

报价、排期、付款、修改、量体、运输和异常处理以邮件或官方社交媒体的逐单沟通为准。

版权、实体所有权与使用

二次转让前应通知工作室，并禁止明显高价炒卖；具体情况通过官方渠道沟通。
