## Regression Risks

- 删除 `ResponsivePicture` 的横竖比例变量会让图片失败时重新引入 CLS 或错误裁切。
- 直接显示 Nuxt 或 API 的错误详情会重新暴露内部信息；任何错误页文案改动都必须重跑 500 泄露测试。
- 重新使用居中空态或第二套 fallback 会破坏目录、详情和错误页的状态一致性。
