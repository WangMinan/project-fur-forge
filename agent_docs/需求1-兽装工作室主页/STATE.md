## 仍然有效的边界

- 私有原图和私有预处理源永远无水印、不可覆盖；
- 水印不替代访问控制；
- OSS 是公开 variant、最终格式和水印的唯一像素权威；
- FFmpeg 只解决超过 OSS 20 MB 输入上限；
- 不引入自动媒体 worker、消息队列或多实例；
- 首页横版/竖版是独立资产；设定图、出厂照、返图和水印 Logo 是独立角色；
- 公开 DTO、日志和错误不含联系人、私有 Key、签名 URL、Session 或水印源信息；
- 所有非测试配置值由 `.env`、环境变量或不入库配置文件注入。
