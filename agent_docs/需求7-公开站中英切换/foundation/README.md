# 地基：公开站中英切换

## 依据与继承

- [需求导航](../../README.md)、[需求4规格](../../需求4-站点视觉升级与内容合规/requirements/SPEC.md)、[需求5规格](../../需求5-委托邮件通知与站点配置/requirements/SPEC.md)、[需求6规格](../../需求6-作品图片构图与详情展示/requirements/SPEC.md) 构成现有基线。
- 用户在本任务确认公开界面级中英切换，并于 2026-09-12 明确中文 fallback 和右上角语言按钮。前序讨论中“非中英文回退英文”的建议已被覆盖。
- 本需求仅覆盖 [SPEC](../requirements/SPEC.md) 明列的旧条款，需求6保持独立验收记录。

## 模块边界

- `app/`：公开文案、语言选择、英文 Hero、联系分流、申请页状态与公开 SEO。后台及登录页继续中文。
- `nuxt.config.ts`、新增根目录 `i18n/`：语言模块、消息与初始语言；不新增另一套语言 store。
- `server/`、`shared/schemas/`：公开价格契约、完整 sitemap 路径、错误页语言上下文；业务值不因界面语言改变。
- `deploy/`：继承精确 Host 和 SSR/API 共享缓存绕过策略；本轮不执行云配置或部署。

## 接口与数据库口径

- 作品、领养、首页及站点内容继续共用原有公开 API；语言切换不统一增加 locale 参数，不因换语言重新获取作品数据。
- 中文站点文章保留既有后台来源；英文公开正文由后台按语言编辑，保存在 site_content_translations，空译文逐字段回退中文。
- 按用户追加授权新增站点文案翻译表及 0054 前向迁移；不增加英文作品字段。停止公开金额只修改公开投影及其 schema，保留管理数据。
- X 使用后台联系方式中的单一配置值，不扩展现有 QQ 二维码平台枚举。

## 安全与实现约定

- 公开图片只消费 READY 派生物；构图、公开资格、下架撤销、私有预览和上传安全沿用现有链路。
- 语言 Cookie 只保存合法语言值，公开站 Host 范围；不得携带身份或地区推断。表单 PII 不进入 URL、日志、analytics 或持久浏览器存储。
- 英文不展示在线申请表单、不触发上传或提交；中文表单的政策就绪、手机号、QQ、内部邮件契约不变。
- SSR 首屏内容可见，水合沿用服务端语言；手动切换不重建页面、轮播和图集，不静默丢失表单输入。
- 不增加翻译服务、机器翻译 API、UI 库或通用国际业务框架；复用现有组件和原生交互。
