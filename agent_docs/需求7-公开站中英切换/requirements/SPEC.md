- 状态：方案已获用户同意，功能已实现；本地自动验证完成，独立 Review/人工验收未完成。

## 目标与非目标

1. 为公开站提供无前缀的中英界面切换，浏览器自动匹配、手动选择可保留，默认中文。
2. 英文访客可理解工作室、制作范围和联系流程，非大陆委托通过 X 联系景宸。
3. 保留现有图片体验和作品原始内容，停止公开价格并修复既有基础 SEO 问题。

不翻译后台、运维、内部通知、中文申请表字段与反馈；不扩展国际手机号、支付、货币、运输或客户自动邮件；不建立作品翻译模型、英文别名搜索、多语言 URL 或独立英文 SEO。

## 1. 语言与状态契约

支持语言标识 `zh-CN`、`en`。简繁中文地区变体统一匹配现有简体中文；英语地区变体统一匹配英文。不增加其他选项。

| 输入情况 | 预期语言 |
| --- | --- |
| 有合法的已保存选择 | 保存的选择，优先于浏览器 |
| 无保存选择，`en-US,zh-CN;q=0.8` | 英文 |
| 无保存选择，`zh-TW,en;q=0.8` | 简体中文 |
| 无保存选择，仅日语等不支持语言 | 中文 |
| 无语言头、无效语言头或没有可接受的匹配语言 | 中文 |
| 非法 Cookie 值 | 忽略该值，继续浏览器匹配，仍未匹配则中文 |

- 尊重浏览器语言顺序和权重，不以“列表里出现中文”覆盖优先英文；不接受 q=0 的匹配项。
- SSR 首次请求决定语言并传入客户端；水合时不再次用 navigator 覆盖已渲染语言。
- 手动切换后同页即时更新，刷新和翻页保持；URL 的 path、query、hash 不因切换改变。
- 不重置当前图片、播放/暂停、滚动和来源返回状态；文案自然换行产生的高度变化不等同于主动滚回页首。
- 语言 Cookie 限当前 Host、只保存语言标识；生产 Secure，不扩散到父域。Cookie 不可用时仍能在当前应用会话切换，刷新按浏览器重新匹配。
- 管理 Host、管理登录及管理错误界面保持中文；公开错误页面跟随公开语言。

## 2. 右上角语言按钮

- 桌面：在现有“关于我们”右侧、页头右端增加语言/翻译图标按钮，位于页头布局内，不使用独立浮动工具条。沿用本项目尺寸、颜色与焦点样式。
- 可悬停鼠标移入语言区域展开，移出整块图标/面板区域隐藏；移到菜单选项上不提前关闭。触屏点击图标展开或隐藏，键盘激活同样可切换，Escape 关闭并还原焦点。展开右对齐的紧凑面板，只有“中文”“English”两项，标识当前选择；不复制参考图的日语、韩语，也不以国旗代表语言。
- 首页透明叠加页头与内页页头均须清晰可见；展开面板保证文字对比和层级，不被 Hero 或 overflow 裁切。
- 窄屏保留可直接访问的右上角入口，与现有移动导航按钮并列，触控目标至少 44×44 CSS px；面板不越过屏幕安全区。不把语言入口仅藏入移动菜单。
- 支持 Tab、Enter/Space、Escape、外部点击关闭；关闭后焦点返回触发器，当前语言按用户最新要求仅以文字颜色作视觉区分，选项左对齐，菜单宽度与“关于我们”下拉共用同一尺寸、字号统一为 --font-size-sm，不展示勾号；保留 aria-pressed 供读屏识别。图标有随语言变化的可访问名称。
- 选择当前语言不重置页面。选择其他语言成功后关闭面板；加载失败保留原语言并提供可读反馈，不出现语言 key 原文。
- 移动导航与语言面板避免相互遮盖；打开一处时妥善关闭另一处，并保持焦点可达。

## 3. 文案与原文边界

| 内容 | 中文 | 英文 |
| --- | --- | --- |
| 导航、页面标题、按钮、搜索、分页、空态、错误、图片控件和无障碍提示 | 现有中文 | 翻译，包括动态计数与状态反馈 |
| 作品名称、物种、图片 alt | 原始内容 | 同一原始内容，不清空、不翻译 |
| 工作室介绍、制作范围、委托说明 | 保留后台来源，可选段落留空隐藏 | 后台维护译文，缺译文逐字段回退中文，联系流程转 X |
| 委托营业状态 | 后台自定义标签 | 后台维护英文标签，缺译文回退中文；tone 为共享状态，切换开放程度时核对各语言文案 |
| 服务条款、隐私政策 | 中文原文 | 翻译页面外壳，标注中文原文；正文区域 lang=zh-CN |
| 备案号、许可证原文 | 原文 | 原文；周边操作说明翻译 |

- 英文词条不得虚构制作范围、受理能力、排期、联系方式或内容空态；公开作品搜索仍只按现有名称匹配。
- 英文事实按实际发布中文内容核对，后台更新介绍、范围或联系事实时人工同步英文。缺失词条运行时回退中文，但验收不能用回退掩盖漏译。
- 图片本身含有的中文无需重制；图片 alt 与查看器操作文字分开验收。

| 位置 | 中文 | 英文 |
| --- | --- | --- |

- 核对条款及联系说明中“官方 QQ 逐单确认”表述，明确新增 X 联系渠道的适用场景；无需全文英文条款。最终业务措辞须由工作室确认。
- 领养咨询仍可进入 /about#contact；已领养的禁用咨询行动保持。

## 5. 英文首页 Hero

- 第一行唯一主标题 `DITE DOG`，大写、中间空格；第二层为英文 slogan，两层水平居中，文字块保留画面安全区。

- 英文去掉中文大标题和重复的小号英文品牌；中文沿用当前结构。沿用现有品牌字体和预加载字体，轮播、媒体、构图及图片来源不变。
- 窄屏优先保持两行；如候选 slogan 无法以合理字号容纳，先校对短译，不强制 nowrap 造成溢出。正常及文本放大状态保证可读性。

## 6. 公开价格与接口契约

- 中英文首页、领养目录、卡片、详情均移除金额、价格整行和“以详情为准”等价格占位；SEO 描述不再承诺展示价格。
- 首页聚合、领养列表、作品详情等所有公开投影及公开 schema 不含 price 金额；SSR/payload 同样不含。私下逐单沟通价格的业务机制不因此删除。
- 后台金额字段、历史记录、私有制作单与数据库保留；不删除或批量清空数据。
- 语言不改变公开 API 查询和作品身份；保留原 slug、href、媒体与 READY 资格。
- 若公开图片或后台维护文案自带价格，单独列入内容检查，由工作室调整；不自动改图或清库。

## 7. SEO、错误与缓存

- 每个页面保留单一 canonical 和 sitemap 地址，不创建 /en、语言 query 或同 URL 的伪多语言 alternate。
- HTML lang、标题、description、OG 等随界面更新；分享图共用。无语言偏好请求返回中文，不按爬虫身份分流。
- 不因英文状态而添加 noindex；申请页两种语言维持禁止索引，后台保持原有 robots 规则。
- sitemap 完整枚举当前可公开详情路径，包括仍公开的已领养作品，复用媒体资格；不只取默认第一页、不收录草稿/下架/不可公开内容。
- 作品和领养目录有效分页保留规范 page；第一页去掉 page=1；详情去掉 from，canonical 不含锚点。非法/越界页不生成伪有效分页 canonical；站内搜索结果采用 noindex，不纳入 sitemap。
- 公开 404/500 页面保留语言上下文，内部渲染仅传递必要且校验后的语言信息，不转发整份 Cookie，不泄露底层错误。
- SSR HTML/API 继续绕过共享缓存；不因引入语言给作品 API 加不同语言缓存。生产实际行为须在后续明确授权的部署验收中验证。

- 公开文案使用语言选择器和同一套分区表单：首页 slogan、委托简介/估价说明/邮件引导、工作室介绍/制作范围、营业状态展示文案。当前仅中文和英文。
