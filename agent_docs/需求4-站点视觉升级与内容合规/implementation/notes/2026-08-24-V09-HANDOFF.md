## Locked Decisions

- 代表作品业务上限继续为两件；数字必须映射真实内容，只允许双项状态的 `01 / 02`、`02 / 02`，单项不显示数字。
- Desktop 使用 Typography / Media overlap；Mobile 使用明确 clear，不把桌面构图压缩成拥挤的一屏。
- Mobile 切换器紧跟摄影并在 375/390/430 初始视口内可见，主要触控目标至少 44px；在不删除语义信息的前提下缩小装饰性 Typography 与摄影尺度，使完整 scene 和 destination rail 同屏。
- V09 只提供静态状态选择：无 autoplay、无 transition、无 directional choreography、无 settle。
- Hero 品牌终态和一次性入场、Hero 4s autoplay、Footer 全部冻结。
