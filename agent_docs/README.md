本目录保存 `project-fur-forge` 的需求契约、历史实施记录和证据。后续需求只在明确条款上覆盖旧行为；安全、媒体、隐私和部署基线继续继承。

| 目录 | 状态 | 用途 |
| --- | --- | --- |
| [`需求1-兽装工作室主页/`](./需求1-兽装工作室主页/) | 已关闭 | 历史实现与 Host、媒体、OSS/ESA、部署/恢复基线 |
| [`需求2-站点导航与内容增强/`](./需求2-站点导航与内容增强/) | 已关闭 | 历史增量；部分功能已被需求3/4覆盖或退役 |

关闭分为两种：`[x]` 表示有相应完成证据；`[-]` 表示按 2026-08-21 产品决策关闭、不再执行，不能被解释为补签生产操作、独立 Review、真实手机或用户验收。

## 执行边界

- 需求1～3不再接受新功能；需要恢复或改变其契约时必须由用户重新开放范围。
- 需求4阶段 E 之外的旧待办已按产品决策关闭；部署、安全和法定义务保留在对应 Runbook/事实源中，不作为 UI backlog。
- 后续 PR 默认只做 UI 美化、布局/响应式、可访问性和动效优化。
- 实现、自动测试、独立 Review、人工验收、远程 CI、部署和生产执行互不代签。
- 生产部署以 [`../docs/DEPLOYMENT.md`](../docs/DEPLOYMENT.md) 为准；媒体以 [`需求1 MEDIA-PUBLICATION-POLICY`](./需求1-兽装工作室主页/requirements/MEDIA-PUBLICATION-POLICY.md) 为准。
