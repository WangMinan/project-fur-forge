# Information Architecture：兽装工作室管理端

## 1. 路由与阶段可见性

后台使用由 `ADMIN_BASE_URL` 显式配置的独立 Host，不内置 `localhost`、`127.0.0.1` 或部署域名 fallback；生产后台 Host 的 `/` 重定向到 `/admin/login`。路由可以提前保留实现位置，但导航只展示当前阶段已经可用的页面。
管理端只能消费统一运行配置；除测试夹具外，设计实现不得另行硬编码任何配置具体值。

### P0 可见

- 登录 `/admin/login`；
- 作品管理 `/admin/works`；
  - 新建作品 `/admin/works/new`；
  - 编辑作品 `/admin/works/{id}`；
- 首页内容 `/admin/site/home`：T20 完成后显示，包含首页轮播与精选；
- 文案配置 `/admin/site/content`：委托/领养营业状态与委托、关于、联系固定字段；
- 账号 `/admin/account`；
- 草稿预览 `/preview/{resource}/{id}`（认证、noindex，不在主导航）。

P0 密码重置通过受保护命令完成，不要求公开 `/admin/forgot-password`。`/admin/site/home` 在真实保存、上传和预览链路接通前不得出现在导航中。

### P1 实现后可见

- 返图管理 `/admin/returns`；
- 当前展会 `/admin/events`；
- 回收站 `/admin/trash`；
- 更完整站点文字内容编辑。

### P2 实现后可见

- 找回密码 `/admin/forgot-password`；
- 重设密码 `/admin/reset-password`；
- 永久原图档案 `/admin/original-archive`；
- 完整导出 `/admin/exports`；
- 访问统计 `/admin/analytics`。

一期不设置 `/admin/dashboard`、订单、客户、排期、支付、多账号或消息中心。

## 2. Navigation Model

- 登录成功进入 `/admin/works`。
- P0 主导航固定为：首页管理、文案配置、全局水印、作品管理、修改密码。“文案配置”只编辑既有受限字段，不形成页面树或万能内容页。
- P1 增加：返图、当前展会、回收站。
- P2 增加：数据与恢复、统计；邮件找回只作为登录页辅助入口，不进入主导航。
- 工具入口：账号、退出。
- 手机优先作品、状态、站点文字内容、账号；首页横竖配对和复杂媒体操作明确提示桌面使用。

## 3. Content Hierarchy

### 登录

1. 后台身份与工作室名称；
2. 用户名/邮箱、密码；
3. 统一错误或锁定时间；
4. 只有 T43 完成后才显示邮件找回。

### 作品列表

1. 新建作品；
2. 角色名/物种查找、用途/装型/发布状态筛选和结果数；
3. 作品名、用途、发布状态、业务状态、媒体完整性；
4. 领养/掉落作品的 CNY 价格摘要；
5. 快速编辑、预览、发布/下架；
6. 人工排序与首页精选；
7. 分页大小与上一页/下一页，结果保持人工顺序。

媒体完整性至少区分“设定图”“出厂照”，不能只显示总张数。不显示定金、付款备注或私有 Object Key。

### 作品编辑

1. 保存状态与主要动作；
2. 基础信息、必填的角色主人公开值、后台私有联系人；工作室作品填写“有点小狗工作室”，隐私作品填写“不公开”，不得以留空表达作品归属；
3. 用途、状态、0–8 条短属性、适用 CNY 价格；
4. `design_sheet` 区：仅领养作品可见，最多 1 张，横版完整画布、公开水印、设定图预览；
5. `studio_photo` 区：最多 5 张，顺序和作品主图，3:4 卡片/原比例详情预览与公开水印；
6. 公开预览和发布检查。

私有联系人明确标注“仅后台可见”。CNY 价格清空后公开端整区隐藏。媒体角色用标题、帮助文字和数量约束同时表达，不允许仅靠缩略图猜测。

### 首页内容

1. 站点级工作室身份、口号与主行动摘要；
2. 1–5 项轮播列表和人工排序；
3. 每项两个独立槽位：`home_hero_landscape`（16:9）与 `home_hero_portrait`（9:16）；
4. 非空 alt、启用状态、可选已发布作品关联；
5. 横屏/竖屏公开预览、水印安全角和处理状态；
6. 站点级自动轮播开关；默认关闭，开启时展示“可暂停、减少动效下停止”的公开影响；
7. 首页精选作品排序与轮播分开维护。

缺失任一方向、alt、READY variant 或水印结果时，该项不能启用。保存草稿不等于发布；发布失败保留上一版完整公开投影。

### 媒体工作区

1. 申请上传时先确定媒体角色和归属；
2. 浏览器计算摘要并直传私有 Bucket；
3. 展示校验、私有 READY、裁切/contain、水印、生成公开图片和失败状态；
4. 页面以 `assetId` 工作，不展示完整私有 Key；
5. 私有原图无水印，公开预览展示烘焙水印；
6. 发布动作描述为“生成并验证公开图片”，不出现“切换 ACL”；
7. 原图下载通过受控动作获取短时 URL。

### 返图（P1）

1. 关联已有作品；
2. 上传与排序；
3. 可选公开字段：昵称、日期、主页；
4. 可选私有字段：授权来源、确认时间、简短备注；
5. 三个授权字段全部为空仍可发布；
6. 使用原比例照片预览和轻量水印 profile；
7. 发布前只校验作品关联、媒体完整性和公开 variant，不把授权记录设为阻断项。

### 营业状态与站点文字内容

- 委托/领养营业状态独立维护；
- 在独立“文案配置”页按“营业状态 / 委托说明与 FAQ / 关于与基本约定 / 联系渠道与防诈骗”固定区块组织；
- 只允许受限纯文本和“问题 + 回答”FAQ，不允许任意脚本/HTML/iframe/富文本；
- 首页轮播媒体由 `/admin/site/home` 专用编辑器维护，不进入通用文字内容表单。

### P2 数据与恢复

原图档案、导出、统计只在实际实现后出现；不得用空表、禁用按钮或“敬请期待”占位。

## 4. Core User Flows

### 第一件作品垂直切片

1. 初始化唯一管理员并登录；
2. 新建非领养作品；
3. 填写基础字段、联系人和短属性；
4. 在“出厂照”区上传原图到私有 Bucket；
5. 校验并生成带 `brand-standard-v1` 水印的所需公开 variant；
6. 发布检查通过后提交公开状态；
7. 新访客在 `/works/{slug}` 看到 SSR 页面；
8. 在首页内容中上传一组横版/竖版图片、预览两种方向并发布；
9. 新访客横屏请求横版首屏、竖屏请求竖版首屏；
10. 下架后公开投影消失并清理公开 variant。

### 首页轮播

1. 新增轮播项；
2. 分别上传横版和竖版原图；
3. 填写 alt，可选关联已发布作品；
4. 等待两份资产完成校验、水印和公开预览；
5. 调整排序与安全角；
6. 启用并发布整组轮播；
7. 发布失败保留上一组公开配置，不出现半项或单方向缺失。

### 领养作品

1. 选择领养用途，维护方式、状态、展会、短属性和可选 CNY 价格；
2. 在“设定图”区上传横版设定图并生成完整画布水印 variant；
3. 有出厂照时在独立区域追加并排序；
4. 发布后 `/adoptions` 以设定图为主，统一 `/works/{slug}` 详情分区显示两类媒体。

### 返图（P1）

1. 关联作品并上传；
2. 可选填写公开署名字段；
3. 需要时记录轻量授权信息，全部可空；
4. 生成原比例轻量水印 variant；
5. 发布后进入 `/returns`；
6. 撤回时先移除公开投影，再删除公开 variant。

### 失败恢复

1. 页面显示失败阶段、错误码、媒体角色和对象业务标识；
2. 管理员手动重试处理、重新上传或重试公开清理；
3. 重新上传产生新会话和新私有 Key；
4. 新 variant 完整前保留旧已发布版本；
5. 不声称有自动 worker 或容器重启续跑。

## 5. Naming Conventions

| Concept | UI Label | Notes |
| --- | --- | --- |
| Publication state | 草稿 / 已发布 / 已下架 | READY 不是发布状态 |
| Media state | 待上传 / 私有上传中 / 校验中 / 私有 READY / 生成水印图 / 生成公开图 / 失败 | 反映双 Bucket 真实阶段 |
| Home hero | 首页轮播 | 每项横版/竖版配对；与精选作品分开 |
| Design sheet | 设定图 | 领养独有、横版完整画布、最多 1 张 |
| Studio photo | 出厂照 | 每件最多 5 张、作品卡/详情用途 |
| Return photo | 返图 | P1、原比例照片墙、轻量水印 |
| Watermark anchor | 水印位置 | 左上/右上/左下/右下；不能关闭必需水印 |
| Contact | 联系人（仅后台可见） | 不进入公开预览 |
| Optional consent | 授权记录（可选） | 来源、时间、备注均可空 |
| Price | 公开人民币价格 | 仅领养/掉落；清空后整区隐藏 |
| Site content | 文案配置：营业状态 / 委托说明与 FAQ / 关于与基本约定 / 联系渠道与防诈骗 | 首页媒体仍用专用编辑器；该入口不是万能“页面内容” |
| Retry | 重试处理 / 重新上传 / 重试公开清理 | 三种动作含义不同 |
| Publish check | 发布检查 | 不称审核流 |

## 6. URL and Privacy Strategy

- 管理路由统一 `/admin/**`，API 统一 `/api/admin/v1/**`。
- `/preview/**` 认证并 noindex。
- 路由参数使用稳定数据库 ID；不把联系人、标题、授权备注或 Object Key 放进 URL。
- 公开 Host 不转发后台/API/预览；应用中间件重复校验。
- 首页与作品公开 DTO 只包含公开 variant URL、alt、顺序和安全关联；不返回原图、私有 Key、水印源文件路径或内部 profile 参数。
