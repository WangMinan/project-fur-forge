# PLAN 交互原型 v5（历史）

这是阶段 2 的最终交互验证原型，不是生产前端，也不连接 SQLite、OSS 或邮件服务。目录名为兼容旧链接保留为 `prototype-v1`；当前保留的原型与截图均为 v5。

当前产品、技术与设计契约只以 `foundation/README.md`、`requirements/SPEC.md`、`planning/PLAN.md`、`.design/` 和 `implementation/TASKS.md` 为准。原型中的旧名称、20 MB 提示、单图 Hero、模拟登录、模拟上传/发布以及旧业务字段均不得进入生产实现。

## 保留目的

v5 已由用户通过 `PLAN:OQ-018` 确认为一期信息架构与交互基线，主要结论为：

1. 作品图片是第一视觉层级，Logo、文字与符号只做辅助；
2. 首页先展示全视口作品图和精选作品，再进入委托/领养入口；
3. 精选采用横向浏览，作品总表采用用途与装型交集筛选；
4. 关于与基本约定合并，委托页通过邮件继续沟通；
5. 后台与公开站分离，并区分新建、快速编辑、返图和站点内容职责。

生产实现已经在 T04–T08 重新完成视觉验证；v5 的颜色、素材和具体页面样式不再是生产依据。

## 当前契约覆盖

- 正式名称为“有点小狗工作室”，英文暂用 `dite dog`；
- 原图产品上限为 30,000,000 字节，超过 OSS 图片处理 20 MB 上限的合规原图先生成私有处理源；
- 媒体使用私有/公开双 Bucket，发布不切换 Object ACL；
- 首页为 1–5 项横版/竖版双源轮播；
- 设定图、出厂照、返图和首页图是独立媒体角色；
- 当前 Logo 源已提供；最终使用范围、图标与水印参数由 EXT-01 收口。

这些内容只用于解释原型与当前契约的差异；不要继续修改原型来表达后续任务。
