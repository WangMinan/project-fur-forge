# Design Brief：兽装工作室管理端

> **状态**：阶段 C 已落地并经用户浏览器人工验收；阶段 D 已确认返图管理与轻量展会掉落。
> **最后校准**：2026-08-07。

## Problem

景宸需要在不了解 SQLite、OSS、媒体身份和发布边界的情况下维护作品、返图、首页与站点内容。主要风险是：

- 误公开私有原图、联系人或返图授权记录；
- 把设定图、出厂照和返图混成一个“图片”概念；
- 把展会掉落做成独立且沉重的展会系统；
- 让返图错误继承作品水印；
- 用短暂 Toast 掩盖上传、公开生成或发布失败；
- 在已取消功能尚未实现时展示空入口。

## Solution

管理端保持“安静的内容工具”：

- 登录后直接进入作品管理，不设置 Dashboard；
- 按作品、返图、首页与委托 Hero、营业状态、文案和品牌水印等真实对象组织；
- 返图使用独立入口和一图一记录编辑；
- 展会掉落直接在作品编辑器中选择和填写，不建设展会后台；
- 保存、上传、处理、发布、失败和恢复状态持续可见；
- 私有原图、授权记录和公开衍生结果清楚区分。

## Experience Principles

1. **发布确定性高于操作速度**：草稿、处理中、READY、已发布、已下架和失败清楚区分。
2. **媒体角色高于通用上传器**：Hero 横/竖、设定图、出厂照、返图和 Logo 有明确用途。
3. **展示位置高于统一水印开关**：标准作品和领养使用活动水印；站点展示和返图无水印。
4. **一图一记录高于返图相册抽象**：首版返图编辑简单、可理解，不增加批次层级。
5. **复用领养高于展会平台**：掉落是领养的一种选择，只维护名称和时间。
6. **业务对象高于万能 CMS**：不使用页面树、任意 HTML 或通用字段编辑器。
7. **私有信息最小暴露**：浏览器以 assetId 操作；不显示私有 Object Key；授权记录不进入公开预览。
8. **原图保护高于视觉捷径**：公开预览代表真实衍生结果，不修改或直接公开原图。
9. **高频轻操作优先**：PC 完成复杂媒体工作；手机完成查看、短文本、单图和发布。
10. **长任务进度高于等待猜测**：上传、公开生成、发布、清理和恢复显示服务端真实状态。
11. **E2E 页面结果高于通过数量**：测试验证用户实际看到和操作的页面。

## Aesthetic Direction

- **Philosophy**：Quiet Editorial Tool。
- **Tone**：平静、清楚、可靠，不做企业销售化 Dashboard。
- **Canvas**：白色与浅灰工作区；品牌蓝只用于主行动、焦点和当前导航。
- **Media previews**：预览区用中性背景区分私有原图、作品水印结果和返图无水印结果。
- **Status**：状态使用文字、图标和颜色共同表达。

### Anti-references

- KPI、图表、消息中心和动态公告；
- 把公开站摄影叠字搬进后台；
- 全屏弹窗承载完整作品或返图编辑；
- 超长万能表单和多层 Card 套 Card；
- 把设定图、出厂照和返图塞进一个上传区；
- 用 CSS 伪造水印或无水印预览；
- 在返图页面显示水印参数；
- 建设“当前展会”Dashboard、展会封面或活动管理树；
- 显示回收站、更多内容或 Slug 历史空入口；
- 把授权记录自动当作公开署名。

## Navigation

### 当前与阶段 D 导航

顺序固定为**业务对象优先**，登录后直接落在作品管理：

1. 作品管理；
2. 返图（T35–T36 完整实现后出现）；
3. 首页与委托大图；
4. 文案配置；
5. 品牌水印；
6. 账户。

阶段 C 代码把作品管理排在大图、文案与水印之后，属于已登记的信息架构债，
在 T35 编码前修正为上述顺序。展会掉落继续在作品管理中维护，不增加展会导航。

不增加 Dashboard、当前展会、回收站、更多内容维护或 Slug 历史。

### 阶段 E

原图档案、导出和统计只在对应功能实现后出现。邮件找回是登录页能力，不是主导航。

## Key Interactions

### 作品与展会掉落

- 创建作品按小步保存草稿；现有作品使用快速编辑。
- 业务类型显示四个选项，选择展会掉落时内部映射为 adoption/event_drop。
- 选择展会掉落后显示展会名称、展会时间、领养状态、价格、设定图和出厂照。
- 切换离开展会掉落时，明确提示并清理展会字段。
- 展会时间是展示文本，不出现自动上架、倒计时或定时状态控件。
- 发布前保存当前修改、重读待办，再决定是否继续。
- 作品列表支持业务类型、装型、发布状态和文本筛选。

### 返图

- 返图入口在 T35–T36 完整实现后出现。
- 一条记录只上传一张 `return_photo`，不显示相册或批次控件。
- 必须选择关联作品；关联作品未发布时，发布检查明确说明。
- 授权来源、确认时间、备注全部可选，区域标题为“授权记录（仅后台可见）”。
- 私有原图预览与 `return-display-v1` 无水印公开预览清楚区分；公开预览区必须明确标注
  “无水印”，展示的就是访客在 `/returns` 看到的真实衍生结果。
- 返图页面不显示活动水印、Logo、位置、不透明度、缩放或水印开关。
- 作品编辑页只显示关联返图摘要和跳转，不嵌入返图编辑器。
- 作品下架后返图公开不可见，后台显示原因但不自动删除记录。
- 阶段 D 不显示“移到回收站”或“30 天内恢复”。

### 上传与 operation

- 上传状态按“计算摘要 / 私有上传 / 校验 / 公开生成 / READY / 失败”展示。
- 发布显示“生成并验证公开图片”，不显示“切换 ACL”。
- 总量已知时显示完成量/总量；未知时显示不定进度。
- 页面刷新后通过 operation ID 恢复状态。
- 失败持续可见并提供重试；重试不制造重复公开对象。

## Stage D Return Management

### 列表

- 作品筛选、状态筛选和**编号分页**；
- 每行一张返图；
- 显示缩略图、关联作品、发布状态和顺序；
- 不显示完整授权备注或私有 Key。

### 编辑

分区顺序：

1. 关联作品；
2. 返图图片；
3. alt 与排序；
4. 授权记录；
5. 无水印公开预览；
6. 发布与恢复；
7. 危险操作。

永久删除不是阶段 D 必做入口；完整支持下架。若实现草稿删除，必须说明不可恢复和媒体影响。

## Responsive Behavior

- 桌面 ≥1280px：侧栏 + 主工作区；编辑与预览/发布检查可以并列。
- 平板 768–1279px：折叠导航；编辑和预览上下排列或切换。
- 手机约390px：单列；登录、查看、状态、短文本、单图上传和发布可用。
- T36 手机上支持创建一条返图、选择作品、单图上传、alt、授权文字、发布/下架。
- T37 手机上支持业务类型、展会名称/时间、状态、价格和发布/下架。
- 批量上传、批量排序、复杂焦点和 Hero 横竖配对可以提示使用桌面。
- 对话框只处理确认和短流程，不承载完整编辑。

## Accessibility Baseline

- 标签、帮助、错误和字段程序化关联；
- 设定图/出厂照/返图必须有文字标签；
- 错误汇总可定位首个问题；
- 表格、菜单、上传、排序和对话框键盘可达；
- 状态同时使用文字、图标和颜色；
- 主要触控目标至少 44px；
- 授权记录的“私有”不能只用颜色表达；
- 展会名称和时间字段有清楚帮助文本，避免误认为自动日程。

## Out of Scope

订单、支付、排期、合同、客户生命周期、多管理员、RBAC、OAuth、二次验证、自动媒体队列、worker、任意 CMS、公开投稿、返图社交功能、返图水印、通用回收站、独立展会后台，以及手机端复杂裁切、批量排序和批量原图维护。
