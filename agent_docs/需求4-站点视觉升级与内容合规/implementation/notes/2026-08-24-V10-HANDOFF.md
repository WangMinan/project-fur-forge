## Locked Decisions

- Homepage Commission 和 `/commission` 共享 Editorial Scene Grammar，但不得机械复制：前者是单屏 Service Docket，后者是长页 Photographic Service Ledger。
- Homepage scene 标题字号继续与 Featured 一致；不靠放大“自设委托”破坏四幕标题层级。
- 摄影是第一媒体锚点，内容摄影统一复用 `--radius-image`；圆角只用于摄影，不把 scene 容器变成圆角卡片。
- Homepage Desktop 媒体与信息栏必须占据独立网格行；media/body gap 不得低于 16px。Mobile gap 不得低于 12px。
- CTA 颜色和最终 control geometry 不属于 V10，按凌巽要求留到 V14 UI/Controls。
- V10 是 Static phase：不新增 autoplay、directional motion、arrival choreography 或依赖。
- 现有业务内容、公开 DTO、营业状态、申请入口、QQ/Email、二维码、条款、横竖媒体、focal、媒体拓扑和 Shared View Transition 不变。
- Homepage Hero 品牌终态与一次性标题入场保持冻结；Footer 内容、布局、样式、响应式和交互完全冻结。

## Regression Risks

- Homepage Commission 使用后台现有横版媒体与 `cover`；未来替换焦点差异很大的摄影时，应先在后台 focal 能力内调整，不应重新引入 overlay card 或修改媒体拓扑。
- 宽屏短高曾因媒体 `height: 100%` 同时保留 `margin-top` 而溢出网格行。当前已移除外边距、增加独立 `row-gap`，并以 1280×800、1440×900、2048×1080 和自动 media/body gap 审计锁定；后续修改 scene 高度时必须保留该断言。
- `/commission` 联系区是长页且二维码来自后台；渠道数量或长账号变化仍应继续遵守现有自适应网格与 128px 可读性下限。
- 共享媒体切换依赖首页与内页继续使用同一 `home-commission-media` 名称；重命名任一端会使已有平滑切换退化，但不影响普通导航 fallback。
