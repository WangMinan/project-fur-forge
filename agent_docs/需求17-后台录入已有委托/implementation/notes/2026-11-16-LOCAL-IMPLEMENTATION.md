## 用户JPEG上传失败的追加修复

用户在本地演示申请中上传JPEG，停在核验阶段。只读检查隔离库的上传元数据，两次均为image/jpeg、大小与尺寸在限制内，失败码为UPLOAD_DIMENSIONS_INVALID、阶段IMAGE_INFO；没有读取或复制用户图片。

根因：测试PUT端点调用FakeMediaStorage.seedPrivate时未传真实imageInfo，默认按PNG头读取格式与尺寸。此前浏览器成功路径只使用PNG合成夹具，漏测JPEG/WebP。另一个界面问题是catch后没有清空正在核验的阶段文字。

修正：模拟PUT通过已有内嵌FFmpeg解码一帧并读取自动旋转后的尺寸，正确保存JPEG/PNG/WebP元数据；不写出完整PNG，避免大尺寸JPEG展开后撞到PNG输出上限。仍保留原上传摘要、MIME、尺寸及归属校验，不修改生产OSS存储实现。失败后清除阶段/进度，仅确有旧图时提示保留当前图片。

新增真实浏览器覆盖同尺寸合成JPEG、WebP、EXIF方向6的JPEG、注入核验失败后进度消失及再次上传成功。manual smoke 7项通过；类型检查和针对修改文件的lint通过；core与构建结果见STATE及本机image-formats-*.log。用户原文件未直接复测，未执行生产操作。
