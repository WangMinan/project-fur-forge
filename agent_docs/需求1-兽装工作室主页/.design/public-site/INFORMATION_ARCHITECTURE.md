# Information Architecture：兽装工作室公开站

## Site Map

- 首页 `/`
- 作品展示 `/works`
  - 作品详情 `/works/{slug}`
  - 旧 slug → 永久 301 到当前 canonical
- 自设委托 `/commission`
- 角色领养 `/adoptions`
  - `/adoptions/{slug}` → 永久 301 到 `/works/{slug}`
- 返图墙 `/returns`
- 关于我们（含联系）`/about`
  - `/contact` → 永久 301 到 `/about#contact`
- 服务条款 `/service`
  - `/terms` → 永久 301 到 `/service`
- 隐私政策 `/privacy`

后台、预览、API 和开发媒体路由不进入公开导航或 Sitemap。

## Navigation Model

- 主导航：首页、作品展示、自设委托、角色领养、返图墙、关于我们。
- “关于我们”在桌面以 Hover 和键盘 `focus-within` 二级导航列出关于我们、服务条款、隐私政策；父链接仍可直接进入 `/about`。工作室名/完整组合 Logo 回首页。
- 移动菜单直接展开“关于我们”的三项子链接，正确管理背景滚动和焦点，不依赖悬停。
- 公开站不显示后台、登录、原型切换或开发说明。
- 浏览器标签页、书签和移动主屏使用 Logo 图形标衍生的站点图标，不使用完整纵向组合标缩略图。

## Content Hierarchy

### 首页

1. 1–5 项站点级代表作品轮播；每项包含独立横版/竖版图片、alt、顺序和可选作品链接；
2. 工作室身份、最多一句口号、一个作品展示主行动和向下提示；四者使用页面安全边距，主行动不贴 Hero 底边；
3. 3–6 件精选作品；
4. 图片式自设委托/角色领养入口；
5. 委托与领养营业状态；
6. 有真实数据时显示当前领养推荐；
7. 页脚与关于/联系路径；页脚不重复联系方式，版权、服务条款、隐私政策和工信部备案入口位于右下信息区。

轮播公开规则：

- 横屏优先 16:9 横版 variant，竖屏优先 9:16 竖版 variant；每项必须两者齐备后才能启用。
- 首页与委托页横版大图烘焙不重叠的左右双水印，竖版大图烘焙单个居中水印；大小分别参照作品管理的设定图与作品卡，公开页面不以 CSS 临时叠加代替。
- SSR 直出第一项和两种 `<source>`；无 JavaScript 时第一项仍可浏览。
- 手动控制始终可用；自动轮播默认关闭，开启后必须可暂停并尊重减少动效。
- 首页轮播与作品“精选横向轨道”是两个独立对象。精选作品的最终形态已由用户于 2026-07-30（T08 最终验收）选定为横向轨道；落选的编辑型网格和实验开关已删除，轨道保持普通链接、人工顺序和无自动播放。

### 作品展示

1. 紧凑页名、用途 × 装型筛选和结果数；
2. 等大 3:4 人工排序网格，优先使用 `studio_photo`；
3. 只有设定图、尚无出厂照的领养作品不进入本页；它仍可从 `/adoptions` 进入统一详情；
4. 空筛选结果与恢复行动；
5. 当前个位数内容不强制分页，但 URL/API 不封死未来分页。

### 作品详情

1. 主图与角色名；
2. 领养作品先显示“设定图”横版完整画布，再显示“出厂照/作品图集”；普通作品直接显示出厂照图集；
3. 物种、装型、非空的角色主人公开值和适用业务事实；工作室作品显示“有点小狗工作室”，隐私作品显示“不公开”；
4. 0–8 条作品短属性；
5. 有值且适用时显示 CNY 价格；
6. 相关浏览与返回列表。

不显示联系人、返图授权记录、私有 Object Key、原图地址或交易控件。返图不混入出厂照图集。

### 自设委托

1. 代表作品宽图；
2. 营业状态和制作范围；
3. 邮件人工估价与复制邮箱；
4. 非穷尽联系提示；
5. 已确认 FAQ；
6. 服务条款入口。

委托说明、人工估价、邮件行动和 FAQ 都来自受限纯文本公开投影；FAQ 只包含“问题 + 回答”，服务条款入口固定为 `/service`，页面不渲染后台 HTML、Markdown 或富文本。

### 角色领养

1. 领养营业状态；
2. 横版水印设定图作为列表主图，完整展示角色设定；
3. 领养方式、状态、展会、作品短属性和有值 CNY 价格；
4. 卡片进入统一 `/works/{slug}`；详情继续区分设定图与出厂照；
5. 邮件/线下后续说明，无登记和支付。

### 返图墙

1. 页名和短说明；
2. 有内容时按原比例照片墙，无内容时真实空状态；
3. 每张返图关联作品；
4. 昵称、日期和主页只在有值时公开；
5. 授权来源、确认时间和备注永不公开；
6. P1 公开 variant 使用轻量品牌水印，不把返图裁成统一设定图或出厂照比例。

### 关于、联系与政策页

- 关于页：工作室事实、制作范围、邮件主行动、复制邮箱、QQ、抖音和防诈骗提示；正文容器放宽到约 52rem。
- 服务条款页：原“基本约定”纯文本独立展示，不与关于页混排。
- 隐私政策页：展示 `privacy_policy` 受限纯文本，默认内容只描述本站真实的信息处理边界。
- 未登记的工作室事实、服务条款、隐私政策或防诈骗文字不显示伪造业务事实；公开页 SSR 每次正常请求读取当前 SQLite 的公开安全投影，不消费版本、草稿标识、内部备注或作品联系人。

## Core User Flows

### 浏览制作能力

首页双源轮播 → 精选或作品展示 → 筛选 → `/works/{slug}` → 设定图/出厂照图集与事实 → `/about#contact` 联系或继续浏览。

### 自设委托

首页/导航 → 委托页 → 作品宽图与营业状态 → FAQ/服务条款 → 打开邮件或复制邮箱 → 网站外继续沟通。

### 角色领养

领养页 → 查看横版设定图、状态、展会和价格 → `/works/{slug}` → 继续查看设定图/出厂照 → 邮件或线下联系。网站不出现登记、定金或付款。

### 返图为空

`/returns` SSR 正常返回标题与说明；空数据展示真实空状态，不显示假照片或“后续开放”。

| `EmptyState` | 筛选、返图 | 文案与行动按页面职责变化 |

## Growth and URL Strategy

- 作品增长后可增加分页，不改变作品 ID、slug 或详情路径。
- 首页轮播始终 1–5 项，精选始终 3–6 件，两者分别人工排序，不随总量无限扩张。
- 返图未来可分页；一期不提供公开投稿或搜索。
- 领养只有真实数量增长后再讨论筛选。
- 关于/联系、服务条款、隐私政策、委托说明和 FAQ 不演进为万能页面树。
- 作品筛选不产生新的 canonical；内部导航使用普通 `NuxtLink`/`a`。
