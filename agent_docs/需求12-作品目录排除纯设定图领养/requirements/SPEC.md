# 规格说明：作品目录排除纯设定图领养

## 状态与来源

- 日期：2026-10-09。
- 来源：用户转述弗朗反馈，并明确授权直接在 main 修改文档、实现和启动 release-image 工作流。
- 目标：只有领养设定图、没有可用出厂照和横版封面的领养作品不出现在作品目录，继续在领养入口展示。
- 无未答 OQ；“作品不显示”限定为用户明确指定的 `/works` 目录，不取消领养所需的统一详情路由。

## 契约

1. `/works` 及 `GET /api/public/v1/works` 只收录沿原选图规则具有可用出厂照卡片或横版封面的作品，不再以设定图作为目录收录依据。筛选先于搜索结果统计和分页，中英文一致。
2. 有出厂照的作品继续沿用主图/竖图规则；无出厂照但有可用横版封面的领养仍展示。不以未 READY 或没有合格公开输出的素材充数。
3. 纯设定图领养仍按原规则进入 `/adoptions` 和首页当前领养（仅 available，首页最多三件）。`/works/:slug`、详情图集、站点地图和领养点击路径保持可达。已领养内容不恢复到 available 目录。
4. 旧构图与独立构图均遵守本规则。补齐或撤去可用出厂照/横版封面后，目录按当时公开投影判断；不新增展示开关。
5. 不改发布资格、领养封面来源、详情显隐、首页代表作品资格、公开 DTO、数据库或媒体配方；不删除原图/衍生图，不要求存量作品重新发布。随应用版本部署生效。

## 覆盖关系

本需求仅覆盖需求4 SPEC 的作品目录设定图兜底（目标14、OQ-016、目录条款及对应验收）和需求6 SPEC 第1/2节保留该兜底的条款。共享详情仍允许设定图卡片；需求6的旧媒体兼容与 READY 安全规则继续有效。

## 验收标准

- 纯设定图在作品目录/搜索中不存在，计数及分页不包含它；领养、首页当前领养和详情保持正常。
- 只有横版封面或有可用出厂照的作品仍进入作品目录；未就绪封面不恢复收录。
- 旧/新构图分别通过回归，手机和桌面浏览器验证领养到详情路径、图片加载及无溢出。
- 本轮只启动出包，不执行生产部署；工作流启动、镜像发布和生产生效分别记录。
