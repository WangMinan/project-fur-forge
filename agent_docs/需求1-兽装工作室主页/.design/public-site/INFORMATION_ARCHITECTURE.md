# 公开端信息架构

> **状态**：阶段 D 页面已落地并由用户验收；本文件描述阶段 E/F 继续保持的公开端结构。

## 1. 导航和品牌

桌面端、移动端抽屉和 Logo/品牌入口必须共享同一导航事实源：

1. 首页 `/`；
2. 作品展示 `/works`；
3. 返图墙 `/returns`；
4. 自设委托 `/commission`；
5. 角色领养 `/adoptions`；
6. 关于我们 `/about`，其下可进入服务条款与隐私政策。

导航条品牌文字固定为 **“有点小狗”**，不带“工作室”。这是一条公开导航显示规则，不要求把管理端名称、项目说明或备案主体称谓全局替换。

## 2. 页面层级

```text
公开站
├── 首页
├── 作品展示
│   └── 作品详情
├── 返图墙
│   └── 设定返图页
├── 自设委托
├── 角色领养
│   └── 作品详情
├── 关于我们
├── 服务条款
├── 隐私政策
└── 开源许可
```

### 首页

- 首屏大图是最高视觉层级；
- 轮播固定开启、10 秒一张，支持手动上一张/下一张、触控与键盘；
- `prefers-reduced-motion` 下停止自动切换，但保留手动操作；
- 精选作品使用人工 `sort_order`；其余公开列表不读取该顺序；
- 文字保持短、必要，不叠加状态面板或分析数据。

### 作品展示 `/works`

- 只显示已发布且公开衍生图 READY 的作品；
- 按发布时间倒序；
- 图片是卡片主体，名称和必要类别为辅助；
- 点击进入 `/works/{slug}`。

### 角色领养 `/adoptions`

- 提供“全部 / 常规领养 / 展会掉落”筛选，共用 `PublicFilterChips`；
- 按发布时间倒序；
- 展会掉落只增加展会名称和展会时间文本，不创建展会层级；
- 展会时间不自动改变领养状态。

### 返图墙 `/returns`

- 每张已发布返图独立进入瀑布流；同一设定可出现多张；
- 每次服务端请求随机打乱，不设置人工排序；
- 横图与竖图自然混排，不裁成统一卡片；
- 墙面不显示设定名、关联作品、昵称、授权来源或 caption；
- 点击任一照片进入其设定页 `/returns/{slug}`；
- 空状态只用一句简短中文，不增加投稿、搜索或社交入口。

### 设定返图页 `/returns/{slug}`

- 显示设定名称、圆形主图和该设定的已发布返图；
- 可显示经确认的公开 `@昵称`；
- 关联作品存在时可以提供简短入口，但不是展示或发布前提；
- 不公开授权来源、确认时间、内部备注、私有原图地址或对象键；
- 设定删除后为 404；关联作品删除采用 `set null`，返图页仍可独立存在。

## 3. 可见性和排序

| 对象 | 公开条件 | 排序 |
| --- | --- | --- |
| 作品 | 已发布且公开变体 READY | `/works`、`/adoptions` 按发布时间倒序；首页精选按 `sort_order` |
| 返图设定 | 设定公开且至少有一张可公开照片 | 设定页内部不提供人工排序承诺 |
| 返图照片 | 照片已发布、公开变体 READY | `/returns` 每次请求随机 |
| 首页/委托大图 | 对应展示位已启用且变体 READY | 显式位置/顺序 |

返图公开条件不读取关联作品是否存在或已发布。

## 4. 阶段 F 媒体投影

- 浏览器只获得 CDN 自定义域名下约 24 小时有效的鉴权 URL；
- HTML、公开 DTO 和响应头不得暴露 OSS Bucket 域名、原图地址、Object Key 或 AK/SK；
- 同一衍生图的鉴权参数变化不应制造多份缓存；CDN 在鉴权后忽略并不回源透传签名参数；
- 下架接口成功后，公开查询立即不再返回对象；随后服务端按精确 CDN URL 强制刷新，目标约 5～6 分钟完成边缘撤销；
- 已下载、浏览器本地缓存、截图或第三方转存不在可撤销承诺内。

## 5. 阶段 E 访问统计

公开端不出现统计 UI。服务端仅记录 SPEC 允许的第一方事件；不注入第三方跟踪脚本，不设置跨站标识，不让统计失败阻断页面或媒体加载。

## 6. 验收清单

- `390×844`、`768×1024`、`1440×900` 三视口；
- 桌面与移动导航均显示“有点小狗”，顺序和当前页状态一致；
- 首页轮播 10 秒、手动操作、键盘、焦点和 reduced motion 正确；
- 作品/领养发布时间倒序，首页精选顺序独立；
- 返图墙无文字、每图可达设定页、请求间顺序可变化，关联作品下架不隐藏返图；
- 图片横竖请求、解码和坏图状态真实；
- 公开 Host `127.0.0.1` 与管理 Host `localhost` 不混用；
- console/network 无私有 DTO、OSS 原站地址和敏感参数泄漏。
