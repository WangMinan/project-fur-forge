### UI-03 · 动态参数变化

- **修改前**：`/works/[slug]` 与 `/admin/works/[id]` 只在 setup 初次读取参数；同组件实例内参数变化时内容、图集、价格、SEO、related works、表单均不更新。
- **修改后（两条不同路径，按页面语义选择）**：
  - **公开详情 `/works/[slug]`：响应式派生**。`work`/`dto`/价格/related works 改为基于 `route.params.slug` 的 computed，`useSeoMeta` 同步响应式；首次直达（SSR）不存在 slug 仍抛 fatal 404（契约不变），客户端同组件内切换到不存在 slug 由 `watch` 经 `showError` 进入同一 HTML 错误页；模板根节点 `v-if="work"` 防过渡帧。选择此方案是因为页键重挂载在"切换到不存在 slug"时无法正确进入错误分支（探测复现：页面残留旧内容、SEO 错乱）。
  - **后台编辑 `/admin/works/[id]`：明确 page key**（`key: route => route.path`）。该页对未知 ID 本就渲染内联缺失态（不抛错），重挂载可整体重建表单、dirty 基线与发布检查，是最简且可测试的方案。
- **测试**：详情→奶盖→蓝莓→芝麻（真实 related 链接点击）断言 URL/标题/H1/`data-work-slug`/价格区出现与消失/缩略图行出现与消失/related 排除自身/og:title；详情→不存在→有效（应用内 router.push）断言进入并恢复 404 分支；后台蓝莓→弄脏表单→栗子→缺失→蓝莓（popstate 同实例切换）断言表单值、dirty 基线重置、领养字段随用途显隐、发布阻断随素材状态更新。

### UI-04 · dirty 覆盖全部可编辑字段

- **修改前**：`isDirty` 遗漏领养方式、业务状态、价格；短属性用 `join('')` 比较。
- **修改后**（`app/pages/admin/works/[id].vue`）：
  - 新增领养字段基线（`baseline.adoptionMethod/businessStatus/priceYuan`），用途为领养时逐项参与 dirty；用途非领养时字段被隐藏，其保留值**不参与** dirty（明确处理：避免隐藏字段被误当作待提交更改），切回领养时保留原值且与基线一致则不误判。
  - 短属性改为长度 + 逐元素比较，不再用 `join('')`。
  - **顺带发现的既有真实 bug**：`initialTags` 与 `tags` 共享同一数组引用，`v-model` 就地改写基线，导致短属性的任何修改从未触发 dirty（`join` 比较双方同步变化）。已修复为两份独立拷贝，并补注释。
  - 切换作品 ID 由 page key 重建基线；保存接口未接入，保存按钮只提示、不清除 dirty（诚实提示语义不变）。
- **测试**：领养方式/业务状态/价格逐项触发并恢复；`['纯海绵头','内置风扇'] → ['纯海绵头内','置风扇']` 的 `join('')` 冲突用例；新增（含空条目）/删除恢复；蓝莓→委托→领养的用途切换用例。

### UI-05 · 金额校验与服务端一致

- **修改前**：`parseFloat` + `Math.round`，接受指数（`1e4`）、尾随字符（`12abc`），并对两位以上小数静默四舍五入；非法输入按"未录入"放行发布。
- **修改后**：
  - 新增 `app/utils/price.ts` `parseCnyYuanInput`：空值 = 不公开（`undefined`）；非空须匹配 `^\d+(?:\.\d{1,2})?$`，BigInt 换算后必须 > 0 且 ≤ `Number.MAX_SAFE_INTEGER`，换算结果恒为整数最小货币单位，与服务端 `priceCnyMinor`（可选；正整数最小货币单位）同一接受集合。拒绝负数、零、指数、尾随字符、两位以上小数与不安全整数，不做静默四舍五入。
  - 编辑页：非法输入显示 `role="alert"` 错误文案，输入框 `aria-invalid` + `aria-describedby` 同时关联提示与错误节点；发布检查的价格项同步标记 blocked、`publishable=false`，发布按钮禁用。合法或清空即时恢复。
- **测试**：`tests/unit/price.test.ts` 10 条（空值/合法集合/零负/指数/尾随字符/多位小数/不完整小数点/安全整数边界/整数性）；E2E 非法集合 `0`、`-1`、`1e4`、`12abc`、`1.234` 逐条断言错误、aria 关联、发布阻断，及 `8800.50` 与留空恢复。
- 未引入新币种或支付能力。

### UI-06 · reduced-motion 横向轨道

- **修改前**：`FeaturedTrack` 按钮与键盘路径强制 `behavior: 'smooth'`；JS 的 `behavior` 参数覆盖 CSS `scroll-behavior`，全局 reduce 规则无法生效。
- **修改后**：组件挂载时读取并监听 `prefers-reduced-motion`，`reduce` 时按钮与方向键路径改用 `behavior: 'auto'`（即时滚动），正常偏好保持 smooth。
- **测试**：`addInitScript` 包裹 `Element.prototype.scrollBy` 记录 behavior 实参；CDP 强制 reduce 断言全部为 `auto`，正常偏好断言为 `smooth`。
