# Design Brief：兽装工作室管理端

## Problem

景宸需要在不了解数据库、OSS、SEO 和发布权限细节的情况下维护作品、图片、营业状态与站点内容。主要风险不是操作慢，而是把草稿或敏感资料公开、误删原图、错配领养方式/状态、在媒体处理中断时不知道下一步，或者被一个含义模糊的万能 CMS 表单淹没。PC 需要完整能力，手机又必须能完成高频轻量更新。

## Solution

把管理端设计为“安静的内容工具”：登录后直接进入作品管理，不设置空洞数据看板；每个页面围绕一个明确对象和一组可逆操作组织。新建作品采用四步门禁，已存在作品走快速编辑；图片上传、处理、预览、发布与失败重试展示真实服务器状态。桌面端用列表、编辑区和预览/发布检查形成清楚工作面，手机端只保留登录、查看、状态、文字、单图与发布等已确认能力。

## Experience Principles

1. **发布确定性高于操作速度** —— 清楚展示草稿、READY、已发布、已下架与失败状态；重要操作先说明影响与可恢复边界。
2. **按业务对象组织高于万能 CMS** —— 使用“作品、返图、营业状态、首页、委托说明、基本约定”等直白名称，不用含义模糊的“页面内容”总括一切。
3. **高频轻操作优先，复杂操作主动分流** —— PC 完成批量、裁切、排序、原图档案；手机完成状态、文字、单图与发布，并明确提示复杂操作回到桌面。

## Aesthetic Direction

- **Philosophy**：Quiet Editorial Tool，安静、可靠、内容优先。
- **Tone**：平静、清楚、专业，但不做企业 SaaS 的销售化仪表盘。
- **Reference points**：
  - v5 已锁定的独立登录、四步新建、快速编辑、返图专用流、“首页与页面”职责和完整导出。
  - 外部概念稿中“表单 + 预览 + 发布检查”的工作面，只借鉴编辑反馈关系。
  - Nuxt UI 的表单、表格、文件上传、对话框、Toast 与可访问性基础。
- **Anti-references**：
  - 把公开站的大字、摄影叠加和装饰动效搬进后台；
  - 默认 Dashboard 模板、无意义 KPI、图表和“动态公告”等未纳入范围的导航；
  - 纯弹窗承载完整作品编辑、超长万能表单、所有控件都用胶囊；
  - 使用模拟成功提示掩盖 OSS、数据库或发布失败。

## Existing Patterns

- 当前没有业务源码或可复用 Vue 组件。
- v5 只验证流程与页面职责；弹窗式快速编辑和几何缩略图不是生产布局。
- 公开站与管理端共享语义色和品牌识别，但不共享展示字体、图片覆盖导航和装饰组件。
- 管理端优先使用 Nuxt UI 基础组件，再用项目 Token 统一密度、状态与发布语义。

## Key Interactions

- 未认证时只渲染登录/找回页面；登录成功后直接进入作品管理。
- 新建流程每一步保存草稿并显示下一步条件；关闭浏览器后可恢复已保存草稿，不把未完成上传显示为成功。
- 现有作品使用快速编辑页；状态、展会、精选和图片均可直达，不强迫重走四步。
- 发布前展示完整性检查；媒体未 READY、必填缺失或“展会出售中”无展会时阻止发布并定位问题。
- 已发布作品修改会影响公开站时明确提示；slug 默认只读，显式改址进入独立确认流。
- 上传逐项展示“计算摘要 / 上传 / 校验 / 处理 / READY / 失败”；失败由管理员手动重试，不展示自动恢复倒计时。
- 重要删除、下架、重新打开已完成交付、永久删除原图均使用影响说明和二次确认。
- 手机遇到批量排序、复杂裁切或原图档案时显示清楚的桌面端提示，不提供不可兑现的半成品操作。

## Responsive Behavior

- **桌面 ≥ 1280px**：固定或可折叠侧栏；内容区支持列表/表单与预览/发布检查并列；复杂媒体操作保留足够画布。
- **平板 768–1279px**：侧栏收起；表单和预览改为可切换区；表格允许列优先级裁减。
- **手机约 390px**：单列；登录、查看、状态、文字、单图上传和发布完整可用；主要操作固定在可达位置；不要求复杂裁切、拖拽批量和永久档案管理。
- PC 页面不使用全屏弹窗承载常规编辑；对话框只处理确认和短流程。

## Accessibility Requirements

无障碍专项不作为一期独立验收，但后台表单必须具备：

- 标签、帮助、错误和字段之间的程序化关联；
- 错误汇总可定位到首个问题，不能只改变边框颜色；
- 表格、菜单、步骤器、上传、对话框和排序操作具备键盘可达路径；
- 对话框打开/关闭正确管理焦点；破坏性操作有可读名称和影响说明；
- 状态同时使用文字、图标和颜色；
- 触控目标适合手机使用，减少动效设置得到尊重。

## Out of Scope

- 数据看板、经营 KPI、公告、订单、支付、排期甘特图、合同、客户生命周期。
- 多管理员、RBAC、注册、OAuth、二次验证和设备管理。
- 万能 CMS、任意 HTML/脚本、公开访客投稿。
- 自动媒体队列、后台 worker、自动重试、容器重启自动续跑。
- 手机端复杂裁切、批量拖拽、批量原图下载和永久档案完整维护。
