# 居中可配置品牌水印设计增量（2026-08-01）

> **角色**：这是 `.design` 在水印视觉与管理体验范围内的当前增量设计契约。冲突时覆盖既有公开站/管理端文件中的“四角安全锚点、小型角标、T51 再决定位置与透明度”等条款；其他设计原则不变。

## 公开站视觉结果

- `brand-centered-v2` 应呈现为大尺寸、低不透明度的背景式品牌标识：普通作品图与首页图居中，横版设定图左右各一枚等大水印；不使用左上小角标。
- 默认透明度 50%，默认缩放 60%；在真实照片上既要一眼可辨识品牌轮廓，也不能把角色眼睛、面部、设定图文字或首页主要行动完全遮住。
- 水印覆盖在公开像素内，因此直接打开图片 URL 时仍然可见；不得只在页面组件上临时叠加。
- 3:4 卡片、原比例详情、16:9 首页横图、9:16 首页竖图和横版设定图均使用同一活动 profile；`recipe-v2` 的实际图形边长为上一版的 1.6 倍，设定图另需复核左右双水印不重叠且不破坏三视图和色板。
- 大型居中水印是已确认方向，不再把“水印不得放大成画面主体”作为约束。水印仍服务于作品归属识别，不能替代作品主体或页面文字。
- P1 返图沿用独立轻量 profile，避免把访客返图统一压成大型中心标识；该策略在 T36 再做视觉门禁。

## 管理端信息架构

新增 P0 路由：

```text
/admin/site/branding
```

导航名称为“站点品牌”，能力实现并通过 GATE-07 后显示。它与 `/admin/site/home` 分开：前者维护全站 Logo 水印源和 profile，后者维护首页轮播内容。

页面层级：

1. 当前活动水印摘要；
2. 已验证 Logo 候选；
3. 上传新候选；
4. 透明度和缩放受限控件；
5. 固定“居中”位置说明；
6. 3:4、原比例、16:9、9:16 四类真实 OSS 预览；
7. 受影响作品/首页项和 variant 数量；
8. “应用并重新生成”确认；
9. 生成、验证、切换和清理进度；
10. 失败恢复与上一活动 profile 状态。

## 组件

| 组件 | 责任 |
| --- | --- |
| `BrandWatermarkEditor` | 管理活动/草稿 profile，不允许任意路径或脚本 |
| `WatermarkSourcePicker` | 上传或选择受保护候选，只以 assetId 工作 |
| `WatermarkParameterControls` | 透明度 10–90、缩放 20–90；显示默认 50/60；位置固定居中 |
| `WatermarkPreviewMatrix` | 显示四种真实 OSS 结果；CSS 预览只能作为加载占位 |
| `WatermarkImpactSummary` | 说明将重新生成的作品、首页项和公开 variant 数量 |
| `WatermarkApplyProgress` | 显示生成/验证/切换/清理，失败状态持续可见 |

## 交互规则

- 上传候选与应用 profile 是两个动作；刚上传 Logo 不会立即改变公开站。
- 选择候选或参数变化后，界面标记为草稿，并要求先生成预览。
- 没有成功的真实 OSS 预览时，“应用并重新生成”保持阻断。
- 应用前确认框明确说明：会生成新公开图片、上一版本在切换前继续使用、完成后旧对象进入清理。
- 应用期间不允许重复启动第二个水印迁移；允许离开页面，重新进入后从服务端恢复进度。
- 失败后仍清楚显示当前公开站使用的上一活动 profile，不给人“已经部分生效”的错觉。
- 作品编辑器中原有“四角水印安全角”控件在 v2 下移除。单件作品页面只显示“当前活动水印：居中 / 50% / 60%（或当前参数）”和真实公开预览，不允许覆盖全站 profile。
- 手机可以查看活动配置和进度，但上传候选、四比例预览和应用迁移明确建议使用桌面；不得显示不可用的半成品复杂控件。

## 可访问性与响应式

- 参数使用带数值输出的滑块和数字输入，标签、范围、错误程序化关联；
- “50%”必须明确是水印不透明度，不使用含糊的“透明度”反向语义；
- 预览通过文字标注 3:4、原比例、横屏、竖屏，不能只靠外观区分；
- 活动、草稿、应用中、失败、已清理同时使用文字、图标和颜色；
- 进度变化使用 `role=status` 或等价可播报机制；
- 390、768、1440 三个固定视口无横向溢出；
- `prefers-reduced-motion` 下不使用闪烁或自动切换预览。

## 视觉门禁

GATE-07 必须留下：

- 当前小角标与新居中 profile 的同图对比；
- 3:4、原比例、16:9、9:16 的真实 OSS 结果；
- 当前 Logo 与一次替换候选的切换证据；
- 透明度 50%、缩放 60%、居中的默认结果；
- 三视口管理页面截图；
- 角色脸部、设定文字和首页主要行动可辨识的人工检查结论。
