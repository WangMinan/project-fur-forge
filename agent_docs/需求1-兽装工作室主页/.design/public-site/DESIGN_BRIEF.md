# Design Brief：兽装工作室公开站

## Problem

访客需要在几秒内判断工作室的制作气质与完成能力。他们应先看到兽装作品，而不是品牌长文、蓝色营销面板或复杂交易界面；同时仍能清楚进入作品、委托、领养、返图、约定与联系路径。当前业务还包含三类形态差异明显的图片：横版领养设定图、竖版出厂照/作品照和原比例返图；首页又需要横屏与竖屏分别使用专门构图，不能继续由一个通用图片组件和一个“主图”概念吞并。

## Solution

把公开站设计为图片大底/白底的编辑型摄影作品集。首页由 1–5 项横版/竖版配对的代表作品轮播占据首个主要视口，后续通过有节奏的图片和极少必要文字完成浏览。`/adoptions` 以横版设定图为主，`/works` 以竖版出厂照为主，详情页明确分区，返图墙保持原比例。所有公开衍生图按角色应用版本化品牌水印；所有行动必须真实：委托通过邮件，领养通过邮件或线下，网站不模拟登记、报价或支付。

## Experience Principles

1. **作品证据高于品牌装饰**：图片能说明的内容不重复写成长文；Logo、标题和动效与作品冲突时先弱化辅助元素。
2. **正确图片角色高于统一卡片**：设定图、出厂照、返图和首页横竖图各自保留适合的信息密度与比例，不以统一 3:4 裁切换取组件整齐。
3. **白底与摄影高于品牌色铺陈**：蓝色负责识别、行动和焦点，不承担页面主体面积。
4. **连续浏览高于组件炫技**：用比例、留白和图片节奏构成体验，不堆卡片、统计、毛玻璃或视差。
5. **真实截图高于组件预设**：轮播、轨道、设定图宽卡和照片墙必须通过三视口截图比较，不因已有组件名而锁死。
6. **清楚路径高于多重转化**：每页只保留与职责一致的主要行动，未实现能力不显示为控件。

## Aesthetic Direction

- **Philosophy**：Editorial Fursuit Portfolio。
- **Tone**：干净、年轻、亲近、克制，不做高冷奢侈品，也不做企业 SaaS。
- **Canvas**：白色和极浅中性色；作品摄影承担主要色彩。
- **Brand blue**：明显蓝色常态占单页视觉面积 5%–10%，15% 为硬上限。
- **Brand assets**：完整组合标用于页头；从同一 Logo 源受控导出的图形标用于 favicon、触控图标与图片水印。水印用于归属识别，不放大成海报主角。
- **Reference**：借鉴渔屋等站点的“图片第一印象、白底作品浏览、横版设定展示与克制业务入口”，不复制 Logo、字体、卡片和专有构图。

### Anti-references

- 深色赛博朋克、黑黄工业、霓虹、毛玻璃、随机渐变、3D 球体；
- 连续蓝底区块、蓝色卡片墙、蓝色渐变大按钮；
- “半张作品图 + 半张蓝色说明面板”的通用营销首屏；
- 标题 + 三张同款圆角功能卡 + 统计数字；
- 每屏大标题、胶囊按钮、视差和 AI 拼装装饰；
- 直接复制宣传海报的斜切构图、大字价格或重复纹样；
- 把横版设定图强裁成竖卡，或用一张横图在手机上只改焦点冒充竖版首屏；
- 用 CSS 临时叠 Logo 代替公开衍生图水印；
- 把 v5 几何 SVG、现有字体和弹窗布局升级为生产 UI。

## Color Use

- `#324DAF`：主要行动、链接、可见焦点；
- `#293C84`：Hover、深强调；
- `#1D2D5A`：极少量反白区域、受控遮罩；
- `#6274BB`：只作大字号或装饰，不承担白底小正文；
- `#CED3E5`：弱背景、边界、占位；
- 页面主体仍由 `#FFFFFF`、中性灰和作品图构成。

禁止把“15%”当作必须填满的目标。多数页面应更接近 5%–10%；作品列表甚至可以只在链接、焦点和当前筛选中出现蓝色。

## Typography

- 展示衬线字体只是候选，用于工作室名、角色名和少数一级标题；正式 Logo/作品图到位后与更亲近的无衬线方案做 A/B。
- 正文、按钮、筛选和状态使用稳定无衬线。
- 不依赖中国大陆访问不稳定的远程字体服务；自托管字体必须确认许可和体积。

## Key Interactions

- 首屏第一项内容存在于服务器 HTML；入场动效不延迟主图、标题或行动。
- 浏览器根据方向/媒体条件选择一份首屏资源，不能通过两个重叠 `<img>` 同时下载横版和竖版。
- 首页轮播始终提供上一张/下一张、分页指示、触控和键盘；自动轮播默认关闭。开启时切换间隔不少于 6 秒，提供可见暂停，Hover/焦点进入暂停，`prefers-reduced-motion` 下停止。
- 无 JavaScript 时第一项仍完整可用；其主要行动为普通链接。
- 精选作品不自动播放；横向轨道支持箭头、键盘和触控。
- 作品筛选保持人工顺序；卡片使用普通链接进入 `/works/{slug}`。
- 领养页使用横版设定图，详情页把设定图与出厂照分开；返图不进入作品图集假装出厂照。
- 图片失败时保留比例、角色名和媒体角色，不造成大面积空洞或布局跳动。
- 价格只在适用作品有已发布 CNY 金额时出现；无值时删除整个区域。
- FAQ、移动导航、轮播和图集覆盖层正确管理焦点。
- `prefers-reduced-motion` 下取消非必要位移、缩放、自动切换和自动过渡。

## Responsive Behavior

- 390px 竖屏：首页使用 9:16 竖版首屏；折叠菜单；作品两列；领养设定图单列横向完整显示；详情单列；无横向溢出。
- 768px：根据实际方向选择横版或竖版首屏；作品三列，控件不依赖 Hover。
- 1440px 横屏：首页使用 16:9 横版首屏；作品四列；设定图宽卡可突破正文容器；文字宽度受控。
- 首页横版/竖版是不同 asset；出厂照焦点仍可分别保存桌面/手机数据，但焦点不能替代双源首屏。
- 水印在三视口均可辨识但不遮挡脸部、文字色板和关键设定；每张图可选择四角安全锚点。

## Accessibility Baseline

- 语义标题、导航、链接、按钮；
- 轮播使用可命名区域，当前页状态可播报，控制按钮有清楚名称；
- 正文与交互文本满足可读对比，图片覆盖文字逐图检查；
- 导航、筛选、FAQ、精选、轮播和图集支持键盘与可见焦点；
- alt 来自后台或安全回退；装饰图使用空 alt；
- 状态不只依赖颜色或动画。

## Out of Scope

在线估价、站内委托表单、领养登记、访客账号、订单、支付、评论、多语言、首屏视频、声音、WebGL、暗色主题、自动推荐，以及由后台任意上传脚本或替换品牌 Logo。
