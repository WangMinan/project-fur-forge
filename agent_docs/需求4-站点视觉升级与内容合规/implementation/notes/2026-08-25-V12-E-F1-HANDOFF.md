## Regression Risks

- 系统字体在不同操作系统上字面会略有差异；只有未来出现明确跨平台一致性要求时，才评估最小、自托管且许可证清晰的中文子集。
- 后续新增公开组件必须直接选择语义角色，不能把普通 metadata 再写成 Code/monospace。
- 修改 preload、`font-display` 或 Hero 品牌选择器时，必须重跑字体审计，防止字体闪动和 CLS 回退。
