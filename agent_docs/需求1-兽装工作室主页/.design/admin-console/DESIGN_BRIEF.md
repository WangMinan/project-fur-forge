# 管理端设计简报

> **状态**：阶段 D 内容管理已落地并由用户验收；阶段 E 开发必要的统计和生产反馈，阶段 F 只做正式环境复验。

## 目标

让非开发管理员用清楚中文完成作品、返图、大图、文案和水印管理，并理解发布、下架与失败恢复。后台追求可判断、可恢复，不追求复杂仪表盘。

## 原则

1. 业务对象优先：作品与返图在导航最前。
2. 返图以“设定 + 多张照片”为模型，不退回一图一记录。
3. 关联作品可选；不能用作品发布状态阻断返图。
4. 私有原图、公开衍生图和 ESA 边缘缓存撤销状态必须分清。
5. 管理员不需要理解数据库、Object Key、recipe、AK/SK 或内部任务号。
6. 访问统计是低频只读入口，不改造成后台首页。

## 导航

`作品管理 → 返图管理 → 大图管理 → 文案配置 → 全局水印 → 访问统计（阶段 E） → 修改密码`

未实现入口不得提前显示。公开导航的“有点小狗”显示规则不要求管理端品牌去掉“工作室”。

## 关键组件

| 组件 | 职责 |
| --- | --- |
| `AdminShell` | 统一导航、会话和窄屏行为 |
| 共享列表骨架 | 作品/返图的页头、查找条、表格和分页 |
| `WorkEditor` | 作品资料、媒体、领养/展会字段、精选和发布 |
| `ReturnCharacterTable` | 一行一个设定，显示主图与照片数量 |
| `ReturnCharacterEditor` | 设定资料、多张返图、圆形主图、可选作品和私有授权 |
| `SiteMediaEditor` | 首页/委托大图、低分辨率风险确认和预览 |
| `AnalyticsView` | 只读趋势、热门页面和粗粒度来源概况 |
| `PublicationStatus` | 发布处理、失败恢复和 ESA 边缘缓存撤销的中文状态 |

## 返图交互

- 新建时先保存设定基本信息，再上传一张或多张照片；
- 任一照片可被选为 `is_primary`，作为设定页圆形主图；
- 授权来源、确认时间和备注按设定保存，并明确标注“仅管理端可见”；
- 关联作品可留空，之后删除或下架作品不影响返图；
- 照片不提供排序输入；
- 删除设定在列表执行，确认框说明级联记录、公开对象清理和私有原图保留。

## 作品与展会掉落

- 管理端可区分“委托作品 / 常规领养 / 展会掉落 / 纯展示”；
- 底层仍只有既有 purpose，展会掉落复用 `adoption` + `event_drop`；
- 展会名称和时间是轻量文本，不新增展会管理；
- 首页精选与 `sort_order` 可在已发布状态直接调整。

## 阶段 E 统计

- 默认范围和指标名称必须清楚；
- 图表数量保持少，提供对应数值或列表；
- 标出数据更新时间和不采集的内容；
- 无数据、延迟和失败状态真实；
- 不展示个人访问轨迹或声称精确识别独立个人。

## 阶段 E 生产反馈开发

- 发布与下架页面只显示管理员需要采取的动作；
- 下架成功后页面立即不可见，随后显示“正在撤销 ESA 边缘缓存”等短状态；
- 撤销完成时间由 T53 在目标环境实测，不预写固定时限；失败可重试并保留任务状态和证据；
- 不把“请求已提交”写成“所有副本已删除”，也不声称能够删除客户端已经保存的副本；
- 凭证、OSS 原站和缓存刷新参数只在服务端与运维文档中存在。

## 验收

- 三视口布局、键盘、焦点、表单错误和重载；
- 列表共用样式，无标题、按钮和表头漂移；
- 返图多图与可选作品的完整成功/失败路径；
- 已发布内容修改、冲突、下架、撤销和恢复；
- 统计页面无数据/失败状态；
- console/network 与 DTO 无私有字段、Object Key、OSS 原站或凭证泄漏。
