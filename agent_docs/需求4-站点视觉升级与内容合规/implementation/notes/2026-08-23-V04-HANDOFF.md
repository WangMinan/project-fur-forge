# V04 · Homepage Mobile / Responsive Structural Pass Handoff

日期：2026-08-23  
范围：首页四幕在 390/430/768/1023/1024 的结构、输入和偏好边界；不修改 Footer。

## Completed

- 复核并保留 V01～V03 已形成的独立移动构图：Hero 全屏媒体、Featured 单列媒体优先、Commission 媒体在上、Adoption 完整设定图。
- Hero 箭头、暂停和分页命中区使用 `max(2.75rem, 44px)`，避免字体缩放环境把 2.75rem 压到 44px 以下；图标视觉尺寸不变。
- 768/1023 继续自然纵向流；1024 切换为固定 Header 下的 staged wheel，边界没有双重拦截。
- Featured 背景 Typography 保持静止，移动构图没有复制桌面负空间；业务幕继续遵守 V02 媒体策略。

## Locked Decisions

- Mobile 是同一 Art Direction 下的独立纵向构图，不使用桌面 grid 的压缩版。
- 1023 及以下不得拦截 wheel；1024 及以上 staged wheel。
- Hero 中文品牌终态不变；Footer 保持冻结。

## Open Issues

- safe area、软键盘、真实手机与完整 prefers-* 在 V11 统一复核。
- 当前开发库 Featured 只有一项；双项移动堆叠仍由最多两项结构支持。

## Regression Risks

- 用纯 rem 恢复 Hero 命中区会在字体缩放环境回到 44px 以下。
- 把 1024 breakpoint 改为 1023 会吞掉平板宽度的原生滚动逃生路径。
- 把桌面 Featured 负空间直接缩放到移动端会遮挡标题或媒体。
