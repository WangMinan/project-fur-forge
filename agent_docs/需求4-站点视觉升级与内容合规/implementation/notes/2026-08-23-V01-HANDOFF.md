## Completed

- Hero 收口为 Quiet / Cinematic Opening：媒体先建立场景，品牌标题随后一次性入场，DITE DOG 与 slogan 再跟随，控制器最后落位。

- Mobile 独立重排控制器与连续提示；不复制 Featured 的 B + M3 版式。

- `eslint`（Hero + evidence script）通过；`vue-tsc --noEmit` 通过。
- 1440×900、390×844、430×932：真实图片解码，无正向水平溢出。

## Locked Decisions

- Hero 保持 Quiet / Cinematic Opening，不复制 B + M3 的 Featured 版式。
- 品牌中文标题终态冻结；仅允许一次性入场。
- 控制器保持低权重、按输入唤起；分页保留 44px 命中区和细线视觉。
- 不新增依赖，不做 drag、全局 reveal、持续呼吸或 Footer 动效。
