1. **OQ-120 未答前不得勾选 T26/T27**，也不得把验证用临时文案当作正式内容。
2. 委托页代表作品取公开首页第一启用轮播项；无启用项时宽图整区隐藏（不伪造占位图）。

4. 复制邮箱优先 `navigator.clipboard`，失败回退 `execCommand`；嵌入式无焦点环境可能仍失败并显示手动复制提示。
