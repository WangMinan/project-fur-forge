# Information Architecture：兽装工作室公开站

## Site Map

- 首页 `/`
- 作品展示 `/works`
  - 作品详情 `/works/{slug}`
  - 旧 slug → 永久 301 到当前 canonical
- 自设委托 `/commission`
- 角色领养 `/adoptions`
  - `/adoptions/{slug}` → 永久 301 到 `/works/{slug}`
- 返图墙 `/returns`
- 关于我们与基本约定 `/about`
  - `/terms` → 永久 301 到 `/about#terms`
- 联系 `/contact`

后台、预览、API 和开发媒体路由不进入公开导航或 Sitemap。

## Navigation Model

- 主导航：首页、作品展示、自设委托、角色领养、返图墙、关于我们。
- 联系作为独立强调入口；工作室名/Logo 回首页。
- 移动菜单包含全部一级页面，正确管理背景滚动和焦点。
- 公开站不显示后台、登录、原型切换或开发说明。

## Content Hierarchy

### 首页

1. 全幅代表作品图、工作室身份、一个主行动；
2. 3–6 件精选作品；
3. 图片式自设委托/角色领养入口；
4. 委托与领养营业状态；
5. 有真实数据时显示当前领养推荐；
6. 页脚与联系路径。

精选作品的最终形态已由用户于 2026-07-30（T08 最终验收）选定为**横向轨道**；落选的编辑型网格和实验开关已删除。轨道必须保持普通链接、人工顺序和无自动播放。

### 作品展示

1. 紧凑页名、用途 × 装型筛选和结果数；
2. 等大 3:4 人工排序网格；
3. 空筛选结果与恢复行动；
4. 当前个位数内容不强制分页，但 URL/API 不封死未来分页。

### 作品详情

1. 主图与角色名；
2. 有序图集；
3. 物种、装型、角色主人公开值和适用业务事实；
4. 0–8 条作品短属性；
5. 有值且适用时显示 CNY 价格；
6. 相关浏览与返回列表。

不显示联系人、返图授权记录、私有 Object Key、原图地址或交易控件。

### 自设委托

1. 代表作品宽图；
2. 营业状态和制作范围；
3. 邮件人工估价与复制邮箱；
4. 非穷尽联系提示；
5. 已确认 FAQ；
6. 基本约定入口。

### 角色领养

1. 领养营业状态；
2. 水印设定图/作品图；
3. 领养方式、状态、展会、作品短属性和有值 CNY 价格；
4. 卡片进入统一 `/works/{slug}`；
5. 邮件/线下后续说明，无登记和支付。

### 返图墙

1. 页名和短说明；
2. 有内容时照片墙，无内容时真实空状态；
3. 每张返图关联作品；
4. 昵称、日期和主页只在有值时公开；
5. 授权来源、确认时间和备注永不公开。

### 关于与联系

- 关于页：工作室事实、制作范围、官方渠道和基本约定。
- 联系页：邮件主行动、复制邮箱、QQ、抖音和防诈骗提示。

## Core User Flows

### 浏览制作能力

首页代表作品 → 精选或作品展示 → 筛选 → `/works/{slug}` → 图集/事实 → 联系或继续浏览。

### 自设委托

首页/导航 → 委托页 → 作品宽图与营业状态 → FAQ/约定 → 打开邮件或复制邮箱 → 网站外继续沟通。

### 角色领养

领养页 → 查看图片、状态、展会和价格 → `/works/{slug}` → 邮件或线下联系。网站不出现登记、定金或付款。

### 返图为空

`/returns` SSR 正常返回标题与说明；空数据展示真实空状态，不显示假照片或“后续开放”。

## Component Reuse Map

| Component | Used on | Notes |
| --- | --- | --- |
| `PublicHeader` | 全部公开页面 | 首页覆盖态，内页白底态 |
| `ResponsiveAsset` | 首页、作品、领养、返图、委托 | 只消费 OSS 预生成公开 variant |

| `WorkCard` | 首页、作品、相关浏览 | 普通链接；图片第一层级 |
| `WorkFacts` | 详情、领养 | 按适用性显示短属性和 CNY 价格 |
| `BusinessStatus` | 首页、委托、领养 | 视觉语法共享，状态值独立 |
| `ContactChannels` | 委托、联系、页脚 | 委托突出邮件，联系展示全部渠道 |
| `EmptyState` | 筛选、返图 | 文案与行动按页面职责变化 |

## Growth and URL Strategy

- 作品增长后可增加分页，不改变作品 ID、slug 或详情路径。
- 首页精选始终 3–6 件并人工排序，不随总量无限扩张。
- 返图未来可分页；一期不提供公开投稿或搜索。
- 领养只有真实数量增长后再讨论筛选。
- 关于、联系、委托说明和 FAQ 不演进为万能页面树。
- 作品筛选不产生新的 canonical；内部导航使用普通 `NuxtLink`/`a`。
