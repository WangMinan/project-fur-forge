# Information Architecture：兽装工作室管理端

## 1. 路由与阶段可见性

后台使用独立 Host；生产后台 Host 的 `/` 重定向到 `/admin/login`。路由可以提前保留实现位置，但导航只展示当前阶段已经可用的页面。

### P0 可见

- 登录 `/admin/login`；
- 作品管理 `/admin/works`；
  - 新建作品 `/admin/works/new`；
  - 编辑作品 `/admin/works/{id}`；
- 营业状态 `/admin/business-statuses`；
- 必要站点内容 `/admin/site/**`；
- 账号 `/admin/account`；
- 草稿预览 `/preview/{resource}/{id}`（认证、noindex，不在主导航）。

P0 密码重置通过受保护命令完成，不要求公开 `/admin/forgot-password`。

### P1 实现后可见

- 返图管理 `/admin/returns`；
- 当前展会 `/admin/events`；
- 回收站 `/admin/trash`；
- 更完整站点内容编辑。

### P2 实现后可见

- 找回密码 `/admin/forgot-password`；
- 重设密码 `/admin/reset-password`；
- 永久原图档案 `/admin/original-archive`；
- 完整导出 `/admin/exports`；
- 访问统计 `/admin/analytics`。

一期不设置 `/admin/dashboard`、订单、客户、排期、支付、多账号或消息中心。

## 2. Navigation Model

- 登录成功进入 `/admin/works`。
- P0 主导航：作品、营业状态、站点内容。
- P1 增加：返图、当前展会、回收站。
- P2 增加：数据与恢复、统计；邮件找回只作为登录页辅助入口，不进入主导航。
- 工具入口：账号、退出。
- 手机优先作品、状态、站点内容、账号；低频/复杂功能明确提示桌面使用。

## 3. Content Hierarchy

### 登录

1. 后台身份与工作室名称；
2. 用户名/邮箱、密码；
3. 统一错误或锁定时间；
4. 只有 T43 完成后才显示邮件找回。

### 作品列表

1. 新建作品；
2. 作品名、用途、发布状态、业务状态、媒体完整性；
3. 领养/掉落作品的 CNY 价格摘要；
4. 快速编辑、预览、发布/下架；
5. 人工排序与首页精选。

不显示定金、付款备注或私有 Object Key。

### 作品编辑

1. 保存状态与主要动作；
2. 基础信息、必填的角色主人公开值、后台私有联系人；工作室作品填写“有点小狗工作室”，隐私作品填写“不公开”，不得以留空表达作品归属；
3. 用途、状态、0–8 条短属性、适用 CNY 价格；
4. 图片来源、上传/处理状态、顺序、主图和真实用途裁切；
5. 公开预览和发布检查。

私有联系人明确标注“仅后台可见”。CNY 价格清空后公开端整区隐藏。

### 媒体工作区

1. 浏览器计算摘要并直传私有 Bucket；
2. 展示校验、私有 READY、生成公开图片和失败状态；
3. 页面以 `assetId` 工作，不展示完整私有 Key；
4. 发布动作描述为“生成并验证公开图片”，不出现“切换 ACL”；
5. 原图下载通过受控动作获取短时 URL。

### 返图（P1）

1. 关联已有作品；
2. 上传与排序；
3. 可选公开字段：昵称、日期、主页；
4. 可选私有字段：授权来源、确认时间、简短备注；
5. 三个授权字段全部为空仍可发布；
6. 发布前只校验作品关联与媒体完整性。

### 营业状态与站点内容

- 委托/领养营业状态独立维护；
- 首页、委托 FAQ、关于/约定、联系/SEO 按对象组织；
- 只允许受限字段，不允许任意脚本/HTML。

### P2 数据与恢复

原图档案、导出、统计只在实际实现后出现；不得用空表、禁用按钮或“敬请期待”占位。

## 4. Core User Flows

### 第一件作品垂直切片

1. 初始化唯一管理员并登录；
2. 新建非领养作品；
3. 填写基础字段、联系人和短属性；
4. 上传出厂照到私有 Bucket；
5. 校验并生成所需公开 variant；
6. 发布检查通过后提交公开状态；
7. 新访客在 `/works/{slug}` 看到 SSR 页面；
8. 下架后公开投影消失并清理公开 variant。

### 领养作品

1. 选择领养用途，维护方式、状态、展会、短属性和可选 CNY 价格；
2. 上传设定图并生成水印 variant；
3. 发布后 `/adoptions` 进入统一 `/works/{slug}`。

### 返图（P1）

1. 关联作品并上传；
2. 可选填写公开署名字段；
3. 需要时记录轻量授权信息，全部可空；
4. 发布后进入 `/returns`；
5. 撤回时先移除公开投影，再删除公开 variant。

### 失败恢复

1. 页面显示失败阶段、错误码和对象业务标识；
2. 管理员手动重试处理、重新上传或重试公开清理；
3. 重新上传产生新会话和新私有 Key；
4. 新 variant 完整前保留旧已发布版本；
5. 不声称有自动 worker 或容器重启续跑。

## 5. Naming Conventions

| Concept | UI Label | Notes |
| --- | --- | --- |
| Publication state | 草稿 / 已发布 / 已下架 | READY 不是发布状态 |
| Media state | 待上传 / 私有上传中 / 校验中 / 私有 READY / 生成公开图 / 失败 | 反映双 Bucket 真实阶段 |
| Contact | 联系人（仅后台可见） | 不进入公开预览 |
| Optional consent | 授权记录（可选） | 来源、时间、备注均可空 |
| Price | 公开人民币价格 | 仅领养/掉落；清空后整区隐藏 |
| Site content | 首页内容 / 委托说明与 FAQ / 关于与基本约定 / 联系与 SEO | 不用万能“页面内容” |
| Retry | 重试处理 / 重新上传 / 重试公开清理 | 三种动作含义不同 |
| Publish check | 发布检查 | 不称审核流 |

## 6. URL and Privacy Strategy

- 管理路由统一 `/admin/**`，API 统一 `/api/admin/v1/**`。
- `/preview/**` 认证并 noindex。
- 路由参数使用稳定数据库 ID；不把联系人、标题、授权备注或 Object Key 放进 URL。
- 公开 Host 不转发后台/API/预览；应用中间件重复校验。
