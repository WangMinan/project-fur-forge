# 公开端设计简报

> **状态**：阶段 D 已落地并由用户人工验收；阶段 E 完成剩余公开端开发，阶段 F 只复验，不改变图片优先体验。

## 目标

让访客先看到兽装作品与返图，再获得必要的品牌、委托和领养信息。公开端应轻、安静、可连续浏览，不能因管理能力、访问统计或生产安全机制增加视觉负担。

## 核心原则

1. 图片是唯一主体；Logo、文字、符号和控件只做辅助。
2. 公开导航品牌使用 **“有点小狗”**，不带“工作室”。
3. 文字短而真实；空字段不占位，不编造未确认文案。
4. 所有公开图片统一使用 `--radius-image`，不在页面内复制圆角规则。
5. 生产媒体安全对访客透明：只看到 ESA HTTPS 媒体，不看到 OSS、回源鉴权策略或撤销任务。
6. 同层级标题必须使用同一排版规则；三个公开目录页的搜索控件复用相同组件、圆角和字体尺度，不能因页面不同产生视觉漂移。

## 页面体验

| 页面 | 主要视觉 | 必要交互 |
| --- | --- | --- |
| 首页 | 横竖适配大图、精选作品与最近三条动态 | 固定 10 秒轮播、手动控制、键盘、触控、reduced motion；动态位于当前领养后 |
| 作品展示 | 大尺寸作品图片 | 按设定名称搜索、按发布时间倒序浏览并进入详情 |
| 返图墙 | 纯净随机瀑布流 | 按设定名称限定照片集合；每张照片直达设定页，无名称/caption |
| 设定返图页 | 圆形主图与多张返图 | 浏览同一设定照片；可选进入关联作品 |
| 自设委托 | 委托大图与必要说明 | 了解状态和联系路径 |
| 掉落领养 | 设定图/出厂照 | 按设定名称搜索；全部、常规领养、展会掉落筛选；元信息使用紧凑可换行信息带 |
| 最新动态 | 类型、标题、时间与纯文本正文 | 只读浏览已发布动态，不提供详情页、搜索或富文本 |

## 组件边界

- `PublicNav`：桌面/移动共用导航项目，品牌显示规则一致；
- `HomeHeroCarousel`：1–5 项横竖双源、SSR 首图、固定 10 秒自动切换；
- `HomeLatestUpdates`：在当前领养后显示最近三条 published 动态，标题排版与其它首页模块一致；
- `PublicCatalogSearch`：作品、领养、返图共用的原生 GET 目录搜索，输入、提交和清除使用统一圆角与字体尺度；
- `PublicFilterChips`：作品和领养筛选的统一触控/键盘语言；
- `AdoptionCard`：名称/状态保持清楚，物种、展会、时间和价格收敛为紧凑信息带，避免同一行卡片高度差放大下一行间距；
- `ReturnWall`：无 caption 的随机瀑布流；
- `ReturnCharacterPage`：设定名称、圆形主图、多张返图和可选作品入口；
- `PublicUpdateList`：published-only 动态的纯文本列表；
- `PublicImage`：统一圆角、占位、解码失败和 ESA HTTPS 媒体 URL 消费边界。
- `PublicFooter`：宽屏按品牌、中间导航/备案、右侧法务三块均衡排布；导航在备案上方，右侧只保留版权行与法务/设计署名行。

不得新增公开统计面板、返图者主页、点赞、评论、公开投稿、全站搜索或回收站入口。三个目录页的设定名称搜索只限定当前资源列表，不是全站搜索入口。

## 状态与文案

- 加载、空、失败状态都应短、可理解；
- ESA 媒体加载失败时使用普通图片失败/重试路径，不显示回源鉴权、Object Key 或内部错误；
- 下架后页面立即移除对象，不向访客展示边缘缓存撤销状态；
- 展会时间只作文本说明，不自动推断开始、结束或售罄。

## 验收重点

- 图片在三视口占据正确层级，不被文字或控件压制；
- 导航品牌、顺序、抽屉、焦点和键盘一致；
- 首页各模块标题字号、字重、行高和基线一致；三个目录搜索的输入、按钮、圆角和字体尺度一致；
- 返回墙无说明文字，点击目标正确，设定与作品解耦；
- 首页自动轮播固定 10 秒并尊重 reduced motion；
- 最新动态位于当前领养后；草稿和下架动态不公开；
- 网络面板只出现 ESA 公开媒体地址，不出现 OSS 原站地址、私有字段或第三方跟踪；
- 公开页 SSR、重载和失败恢复均可用。
- 宽屏页脚左右间距均衡，ICP 位于中间区且链接正确；公安备案未配置时不显示假占位，窄屏无横向溢出。
