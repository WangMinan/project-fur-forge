# Design Brief：兽装工作室公开站

> **状态**：阶段 C 已落地并经用户浏览器人工验收；返图墙是阶段 D 的优先候选，尚未实现。
> **最后校准**：2026-08-07。

## Problem

访客需要在几秒内判断工作室的制作气质与完成能力。他们应先看到兽装作品，而不是品牌长文、蓝色营销面板或复杂交易界面；同时仍能清楚进入作品、委托、领养、约定与联系路径。

当前媒体形态差异明显：横版领养设定图、竖版出厂照、首页横竖双源 Hero，以及阶段 D 可能加入的原比例返图。它们不能被一个通用“主图”和统一 3:4 裁切吞并。

## Solution

把公开站设计为图片大底与白底结合的编辑型摄影作品集。首页由 1–5 项横版/竖版配对的代表作品轮播占据首个主要视口，后续通过有节奏的图片和极少必要文字完成浏览。

当前公开行为：

- `/adoptions` 以横版设定图为主；
- `/works` 以出厂照为主；
- 作品详情明确区分设定图和出厂照；
- 首页 Hero、委托 Hero 和两个首页业务入口使用无水印站点展示图；
- 作品、领养和详情使用活动品牌水印；
- 委托通过邮件，领养通过已声明渠道，网站不模拟登记、报价或支付。

返图墙如进入阶段 D，应保持原比例或经过真实样本验证的有限裁切，并使用独立轻量水印配方；它不是社交动态流。

## Experience Principles

1. **作品证据高于品牌装饰**：图片能说明的内容不重复写成长文；Logo、标题和动效与作品冲突时先弱化辅助元素。
2. **正确图片角色高于统一卡片**：设定图、出厂照、返图和首页横竖图各自保留合适比例与信息密度。
3. **展示位置决定保护方式**：站点展示位无水印，作品档案位使用活动水印；新返图用途必须有独立配方。
4. **白底与摄影高于品牌色铺陈**：蓝色负责识别、行动和焦点，不承担页面主体面积。
5. **连续浏览高于组件炫技**：用比例、留白和图片节奏构成体验，不堆卡片、统计、毛玻璃或视差。
6. **真实截图高于组件预设**：轮播、轨道、设定图宽卡和返图墙必须通过三视口真实截图比较。
7. **清楚路径高于多重转化**：每页只保留与职责一致的主要行动，未实现能力不显示为控件或导航。

## Aesthetic Direction

- **Philosophy**：Editorial Fursuit Portfolio。
- **Tone**：干净、年轻、亲近、克制，不做高冷奢侈品，也不做企业 SaaS。
- **Canvas**：白色和极浅中性色；作品摄影承担主要色彩。
- **Brand blue**：明显蓝色常态占单页视觉面积约 5%–10%，15% 为硬上限而非填充目标。
- **Brand assets**：完整组合标用于页头；从受控 Logo 源导出的图形标用于 favicon、触控图标和需要水印的媒体。水印用于归属识别，不放大成海报主角。
- **Reference**：借鉴优秀工作室站点的图片第一印象、白底作品浏览、横版设定展示与克制业务入口，不复制 Logo、字体、卡片或专有构图。

### Anti-references

- 深色赛博朋克、黑黄工业、霓虹、毛玻璃、随机渐变、3D 球体；
- 连续蓝底区块、蓝色卡片墙、蓝色渐变大按钮；
- “半张作品图 + 半张蓝色说明面板”的通用营销首屏；
- 标题 + 三张同款圆角功能卡 + 统计数字；
- 每屏大标题、胶囊按钮、视差和 AI 拼装装饰；
- 直接复制宣传海报的斜切构图、大字价格或重复纹样；
- 把横版设定图强裁成竖卡，或用一张横图只改焦点冒充竖版首屏；
- 用 CSS 临时叠 Logo 代替已验证的公开衍生图；
- 把返图墙做成点赞、评论、头像和时间线组成的社交页面；
- 在功能未实现时展示返图、回收站或展会空入口。

## Color Use

- `#324DAF`：主要行动、链接、可见焦点；
- `#293C84`：Hover、深强调；
- `#1D2D5A`：极少量反白区域、受控遮罩；
- `#6274BB`：只作大字号或装饰，不承担白底小正文；
- `#CED3E5`：弱背景、边界、占位；
- 页面主体由 `#FFFFFF`、中性灰和作品图构成。

作品列表可以只在链接、焦点和当前筛选中出现蓝色。

## Typography

- 展示衬线字体只作为工作室名、角色名和少数一级标题的候选；
- 正文、按钮、筛选和状态使用稳定无衬线；
- 不依赖中国大陆访问不稳定的远程字体服务；
- 自托管字体必须确认许可和体积。

## Key Interactions

- 首屏第一项存在于服务器 HTML；入场动效不延迟主图、标题或行动。
- 浏览器根据方向/媒体条件选择一份首屏资源，不能通过两个重叠 `<img>` 同时下载横版和竖版。
- 首页轮播提供上一张/下一张、分页指示、触控和键盘；自动轮播默认关闭。开启时不少于 6 秒，提供可见暂停，Hover/焦点进入暂停，`prefers-reduced-motion` 下停止。
- 无 JavaScript 时第一项仍完整可用；主要行动为普通链接。
- 精选作品不自动播放；横向轨道支持箭头、键盘和触控。
- 作品筛选保持人工顺序；卡片使用普通链接进入 `/works/{slug}`。
- 委托引导区只消费委托页独立集合中排序最前的一组已发布无水印资源；无可用图片时隐藏 Hero，不回退首页，正文与邮件行动仍可用。
- 领养页使用横版设定图，详情页把设定图与出厂照分开；返图不得进入作品图集假装出厂照。
- 图片失败时保留比例、角色名和媒体角色，不造成大面积空洞或布局跳动。
- 价格只在适用作品有已发布 CNY 金额时出现；无值时删除整个区域。
- FAQ、移动导航、轮播和图集正确管理焦点。
- `prefers-reduced-motion` 下取消非必要位移、缩放、自动切换和自动过渡。

## Stage D Return Wall Direction

返图墙只有在 T35–T36 完成后进入导航。推荐体验：

- 页面以真实返图图片墙为主；
- 每条返图只显示作品关联、必要短说明和可选公开来源显示；
- 使用独立轻量水印公开变体；
- 横图、竖图和方图通过真实样本验证网格或 masonry；
- DOM 阅读顺序与视觉顺序一致；
- 作品详情可提供少量返图预览或入口，但与出厂照清楚分区；
- 不显示授权来源、确认时间、内部备注或私有联系人；
- 不提供公开投稿、点赞、评论、访客账户或推荐算法。

## Responsive Behavior

- 390px 竖屏：首页使用 9:16 竖版首屏；折叠菜单；作品两列或经验证单列；领养设定图单列完整显示；详情单列；无横向溢出。
- 768px：根据实际方向选择横版或竖版首屏；作品三列；控件不依赖 Hover。
- 1440px 横屏：首页使用 16:9 横版首屏；作品四列；设定图宽卡可以突破正文容器；文字宽度受控。
- 首页横版/竖版是不同 asset；出厂照焦点不能替代双源首屏。
- 活动水印固定为当前居中 profile 几何，不再提供每图四角锚点；站点无水印位置不得错误叠加 Logo。
- 返图墙布局必须在三个固定视口使用真实混合方向样本核对。

## Accessibility Baseline

- 使用语义标题、导航、链接和按钮；
- 轮播使用可命名区域，当前页状态可播报，控制按钮有清楚名称；
- 正文与交互文本满足可读对比，图片覆盖文字逐图检查；
- 导航、筛选、FAQ、精选、轮播和图集支持键盘与可见焦点；
- alt 来自后台或安全回退；装饰图使用空 alt；
- 状态不只依赖颜色或动画；
- 返图墙的视觉重排不得破坏键盘和屏幕阅读顺序。

## Out of Scope

在线估价、站内委托表单、领养登记、访客账号、订单、支付、评论、多语言、首屏视频、声音、WebGL、暗色主题、自动推荐、公开返图投稿，以及由后台任意上传脚本或替换品牌 Logo。
