## Completed

- 表单按“申请信息 / 设定图 / 提交前确认 / 提交操作”组织；768px 起常规字段双列，身高与体重保持成对布局。
- 电话、身高、体重的单位在控件内，输入与上传预览行动均为至少 44px。
- 上传区、确认项、提交状态与成功/不可用回执采用稳定分隔结构；空错误节点仅在有错误时渲染，避免无意义空白与 ARIA 引用。
- 上传、核验、提交、失败重试和成功回执继续复用现有客户端会话；提交失败保留表单和设定图预览。
- 证据脚本在每次全页截图前回到页面顶部，避免 `setInputFiles()` 滚动后的 sticky Header 拼接伪影。
