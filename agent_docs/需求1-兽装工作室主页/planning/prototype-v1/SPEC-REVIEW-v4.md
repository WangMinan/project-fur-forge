## 自审发现与修正

1. 首轮视觉检查发现登录表单与找回密码表单因 CSS 覆盖原生 `hidden` 行为而同时显示。已增加登录壳层内的强制隐藏规则，并补自动回归断言。
2. 旧版公开页脚的后台入口和右下角原型切换浮条已从 DOM 删除；不只做视觉隐藏。
3. “Minimal Analytics”卡已从 DOM 删除。轻量统计的收集边界继续保留在 SPEC/PLAN，不以醒目营销卡形式展示。
4. FAQ 参考的是折叠式信息结构，不复制渔屋问题答案；尚未确认的业务结论保持不出现。
5. 当前几何 SVG、虚构作品名和模拟登录行为仍是规划占位；正式实现必须替换素材并接真实认证。

## 原型阶段边界

- hash 路由只用于本地评审；生产由 Spring MVC 和后台子域名提供稳定路由、认证与浏览器历史语义。
- 登录、找回、上传、处理、发布、导出和下载均为交互模拟，不连接 MySQL、OSS 或 SMTP。
- 几何 SVG 是比例与色彩占位图，正式上线前必须替换为获授权素材。
- 基本约定和 FAQ 只验证信息结构；正式公开文本仍需景宸确认，必要时完成适用性与法律审阅。
