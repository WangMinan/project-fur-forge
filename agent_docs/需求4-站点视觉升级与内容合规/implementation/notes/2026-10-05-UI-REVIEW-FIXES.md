## 前后端契约

- 公开目录接口、排序与 READY 投影不变；客户端失败不能推断为接口返回零条记录。
- 委托服务端原有事务会创建申请并消费上传会话，响应丢失不等于事务未提交。前端 POST 明确禁用自动重试并设置等待上限；未知结果不新建上传或重新提交。
- 已知手机号 pending 冲突、上传版本/状态失效仍使用既有 409 处理。未知结果仅保留在当前页内存，不承诺刷新后恢复，不向 URL、日志或持久浏览器存储写入 PII。
- 无公开申请查询接口，因此不新增“查结果”按钮；最终由现有联系路径人工核对。
- 模态与普通错误表现调整不绕过后端权限、版本校验或删除强确认。冲突重新载入明确说明放弃本地修改，并允许保留输入。
