## T02：运行配置与安全边界

| 路径 | 作用 |
| --- | --- |
| `config/runtime.example.json` | 版本化声明完整配置键、类型、环境变量映射和安全本地 fallback |
| `.env.example` | 只声明变量名，不保存任何真实值 |
| `server/utils/runtime-config.ts` | 唯一服务端加载器；按环境变量、活动文件、fallback 的顺序解析并在启动时校验 |
| `server/plugins/00.runtime-config.ts` | Nitro 启动即加载配置，生产缺项快速失败 |
| `server/utils/host-policy.ts` | 公开 Host、后台 Host、健康检查与未知 Host 的纯策略 |
| `server/middleware/01.host-boundary.ts` | 在真实请求链重复执行 Host 隔离 |
| `server/error.ts` | 输出固定 `{ error: { code, message } }` 信封，不回显内部错误 |
| `server/utils/safe-log.ts` | 对凭据、签名 URL、原图 Key 和客户敏感字段递归脱敏 |

本地活动文件默认使用已忽略的 `config/runtime.local.json`，也可通过 `APP_CONFIG_FILE` 指向容器只读挂载文件。生产环境不使用地址、数据库、OSS、Session 或 SMTP fallback，所有相关项必须显式、完整地注入。
