# T08/T09 · 公开搜索界面与浏览器验证

## 范围

- 新增共用 `PublicCatalogSearch` 原生 GET 表单，接入作品、领养与返图三页。
- 查询、筛选与分页保留有效 `q`；新搜索自然移除 `page`，返图新搜索不携带旧 `seed`。
- 区分无内容、无匹配、非法查询和越界页，提供保留当前筛选的清除入口。
- 不新增依赖、搜索服务、公开 DTO 字段或 analytics 记录。

## 实现

- 页面把原始 `route.query.q` 透传给 API；数组、对象和超长值不会被折叠成合法字符串。
- 搜索输入最多 100 字，服务端回显 trim 后的有效值；作品与领养筛选链接继续携带 `q`，返图分页携带 `q + seed`。
- 原生 GET 表单不写隐藏 `page`；返图表单也不写隐藏 `seed`，无 JavaScript 时仍可使用。
- E2E 返图种子保留 25 张独立公开记录和完整 READY SourceSet，只复用一份本地小 PNG 字节，避免无意义的高成本测试像素生成。
