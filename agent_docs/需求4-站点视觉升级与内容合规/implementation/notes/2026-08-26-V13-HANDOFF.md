# V13 Handoff · Signature Motion / Carousel / Scene Continuity

状态：V13、V13-A、V13-B implementation、Desktop/Mobile/Reduced Motion Evidence、公开页入场矩阵、五条 shared-media forward/fallback/reduced 与两条目录 reverse Evidence 均已完成。当前停在 V13 Handoff；未获凌巽确认前不得开始 V14。

## Completed

- Hero、Featured 与 Homepage Adoption 均使用 4s autoplay，支持 pause/resume、页面隐藏暂停、next/previous 真正反向、连续点击中断后的单一可靠终态；Reduced Motion 停止自动播放并直接进入终态。
- Featured 保留媒体与标题/物种的 directional transition，删除名称高度变化造成的信息组布局位置补间；Desktop 名称固定单行，Mobile 继续允许自然换行。CTA 与切换 controls 在不同名称间保持固定终态。
- Homepage Adoption 为媒体、名称、facts 与 action 建立逐级减小的方向位移，图片和详情行动始终指向当前角色。
- 普通公开路由使用一次短暂 opacity 入场；shared-media 路由关闭普通入场，避免双重动画。
- shared-media forward 严格限制为五条：首页委托、首页代表作品、首页领养、Works Card、Adoption Card 到各自目标；Works/Adoptions Detail 返回只与同 slug 来源卡片反向衔接。
- 未新增依赖、Schema、迁移、路由或业务字段。

## Locked Decisions

- Featured 不再根据角色名称高度平滑移动整个信息区；Desktop 名称为单行，Mobile 可换行。
- Featured 背景 `SELECTED WORKS`、右下编号与 Footer 不参与轮播运动。
- Motion hierarchy 继续保持 Media 最大、Title 次之、Meta 更小、CTA 最小；静态终态不因动画改变。
- Hero 品牌文字终态、一次性首次入场、font flash 修复与 4s 基准不回退。
- 白名单外不增加 shared-media morph；不支持 View Transition、Reduced Motion 或 hydration 前的点击直接进入可靠目标页。

## Regression Risks

- Featured 名称样式、信息栈 grid 或 transition wrapper 改动时，必须回归 Desktop 单行及 CTA/controls 切换前后零位移。
- 修改 carousel timer、visibility listener 或 Reduced Motion 分支时，必须同时回归 Hero、Featured、Adoption 三套 pause/resume 和单一终态。
- 修改 Nuxt route transition middleware、详情返回 query 或卡片点击绑定时，容易造成普通页面渐入与 shared-media 叠加，或把多个卡片误设为 source。
- shared-media 在 hydration 前按普通导航可靠回退；不得为了强制首帧 morph 引入阻塞 SSR 或额外依赖。
