# 公开站信息架构

> **角色**：当前公开页面结构、内容顺序、组件关系和响应式行为。
> **状态**：阶段 C 已落地；阶段 D 目标已确认，尚待 T35–T37 实现。
> **最后校准**：2026-08-07。

## 1. 全局框架与导航

公开站统一使用 skip link、品牌页头、桌面/移动导航、主内容、紧凑页脚和 HTML 404/500 错误页。

阶段 D 完成后一级导航包含：

```text
首页
作品
领养
返图
委托
关于
```

“返图”固定指向 `/returns`。它只在 T35–T36 完整实现后进入导航，不提前显示空入口。

管理入口不出现在公开导航。展会掉落不增加“展会”一级导航，也不增加展会详情页。

## 2. 首页

页面顺序固定为：

```text
Hero
精选作品
统一业务入口
当前领养
页脚
```

### 2.1 Hero

- 无水印横版或竖版代表作品；
- 工作室名称、一句口号和作品入口；
- 多项时提供上一张、下一张、分页和暂停；
- SSR 直出第一项，只加载当前项图片；
- 自动轮播默认关闭，开启时不少于 6 秒；
- 悬停、焦点、页面隐藏和减少动效时暂停；
- 不在中心叠 Logo，不重复下方业务状态。

### 2.2 精选作品

使用带活动水印的作品卡片图。最多 6 件，按人工顺序。无精选时隐藏；局部接口失败不得导致 Hero 和业务入口整体 500。

### 2.3 统一业务入口

桌面两列、移动单列：

- 自设委托：`/commission`；
- 角色领养：`/adoptions`。

两张卡使用独立无水印入口图，包含标题、营业状态、短说明和单一主链接。缺图时使用受控无图状态，不借用私有原图或任意作品。

### 2.4 当前领养

最多展示 2 件已发布领养，可以包含常规领养和展会掉落。

普通卡片显示角色名、状态和可选价格；展会掉落额外显示：

- “展会掉落”标签；
- 展会名称；
- 展会时间。

不增加独立“当前展会”区块。

## 3. 作品列表

`/works` 结构：

```text
页面标题与短说明
用途筛选
装型筛选
结果数量
作品网格 / 空状态
页脚
```

要求：

- 筛选使用普通链接，SSR 和无 JS 可用；
- 用途和装型取交集；
- 非法参数显示明确空态和清除入口；
- 作品卡使用 3:4 焦点裁剪和活动水印；
- 只显示角色名、物种、装型和用途等必要信息；
- 只有设定图、没有出厂照的领养不进入 `/works`。

展会掉落底层仍是 adoption，可以在用途筛选的“领养作品”中出现；无需增加第四种作品用途筛选。

## 4. 作品详情

结构：

```text
返回作品展示
角色名与基础元信息
媒体列 + 事实侧栏
前后浏览
继续浏览
```

### 4.1 媒体分区

领养作品：

1. 设定图；
2. 出厂照 / 作品图集。

其他作品只显示出厂照图集。所有作品媒体继续使用活动水印。

**作品详情不增加返图 Tab，不嵌入返图墙或关联返图缩略图。** 返图只存在于一级 `/returns`，返图项可以单向链接到作品详情。

### 4.2 图集方向布局

- 横图可以使用媒体列宽度；
- 竖图舞台收窄并居中，不显示铺满媒体列的灰色左右翼；
- 不裁掉图片主体；
- 缩略图当前项使用清楚边框和 `aria-pressed=true`；
- 路由复用或切换作品后重置到有效索引；
- 图片声明固有宽高，避免 CLS。

### 4.3 事实侧栏

包含物种、装型、用途、角色主人公开显示、领养方式、当前状态、短属性和可公开价格。

展会掉落增加：

- 展会掉落标签；
- 展会名称；
- 展会时间。

不显示私有联系人、返图授权记录、展会地点、摊位或主办方。

## 5. 领养页

`/adoptions` 同时展示常规领养和展会掉落，使用适合横版设定图阅读的列表或网格。

页面提供：

```text
全部
常规领养
展会掉落
```

每张卡显示带活动水印的设定图、角色名、当前状态、可选价格和统一详情入口。

展会掉落额外显示类型标签、展会名称和展会时间。时间过长时受控折行，不遮挡图片或挤掉价格/状态。

空状态只表达真实数据：

- 全部为空：当前没有公开领养；
- 常规为空：当前没有公开常规领养；
- 掉落为空：当前没有公开展会掉落。

不建设展会列表、展会专题页、地点地图、展会归档或活动时间线。

## 6. 独立返图墙 `/returns`

### 6.1 页面目的

返图墙回答“作品交付后真实穿着和活动效果如何”，与标准作品档案分开。它不是社交动态流，也不是作品详情局部图库。

### 6.2 页面结构

```text
紧凑页面标题与短说明
无水印原比例返图 masonry / 真实空状态
分页或受控“加载更多”
页脚
```

页面不增加复杂筛选、搜索栏、返图者档案、热门排行或统计数字。

### 6.3 瀑布流

- 横图、竖图和方图按固有宽高比排列；
- 不统一强裁为 3:4；
- 图片加载前保留尺寸，避免布局大幅跳动；
- DOM 顺序、Tab 顺序和屏幕阅读顺序稳定；
- 列数按视口受控变化，不使用会导致顺序混乱的纯视觉乱序；
- 使用分页或用户主动“加载更多”，不自动无限滚动；
- 追加内容后不抢走焦点；
- 单图加载失败显示受控占位，不让整页 500。

### 6.4 返图项

每项包含：

- 无水印返图；
- 必要 alt；
- 关联作品名称或简短入口；
- 普通链接到 `/works/{slug}`。

不显示独立标题、长说明、返图者昵称、主页、授权渠道、确认时间、内部备注或私有联系人。避免图片链接与作品链接嵌套；整项可以选择一个清楚的主交互。

### 6.5 媒体与隐私

- 只显示返图与关联作品均已发布的记录；
- 只消费 READY `return-display-v1`、`protection_mode=none` SourceSet；
- 不回退到私有原图、作品出厂照或水印变体；
- 公开响应和图片不包含敏感 EXIF、原文件名、授权记录或私有 Key；
- 活动作品水印 profile 切换不影响返图。

### 6.6 空态与错误

- 无返图：显示真实空态，不编造“即将更新”；
- 关联作品已下架：对应返图不进入结果；
- 分页失败：保留已加载图片并提供重试；
- 单条数据或图片异常：局部降级，不影响导航和其他返图。

## 7. 自设委托

`/commission` 使用独立无水印横竖 Hero，展示营业状态、制作范围、人工估价、邮件行动、FAQ 和服务条款入口。

无可用委托 Hero 时隐藏图片引导区，不回退首页图；正文和联系入口继续可用。

## 8. 关于与政策页

### 关于

展示工作室事实、制作范围、官方渠道和防诈骗提示。使用适合阅读的正文宽度，不做社交平台大按钮墙。

### 服务条款与隐私政策

使用独立标题、约 52rem 阅读宽度、合理分段和页脚法律入口。兼容旧路径永久重定向。

## 9. SEO 与分享边界

- `/returns` 有独立 title、description 和 canonical；
- Sitemap 在 `/returns` 实现后包含页面本身，不为单张返图生成 URL；
- 展会掉落继续使用作品详情 canonical；
- 当前版本不建设分享海报、二维码或 slug 改址历史；
- 分享与长期 URL 策略见未来迭代备忘录，不得提前生成空控件。

## 10. 响应式

### 390×844

- Hero 使用竖版图；
- 业务入口单列；
- 作品网格两列或经验证单列；
- 领养设定图单列完整显示；
- 返图瀑布流使用适合触控和清晰度的受控列数；
- 展会名称/时间不横向溢出；
- 详情侧栏进入媒体后。

### 768×1024

- Hero 根据实际方向选择资源；
- 业务入口可以两列；
- 返图列数避免巨大空洞和过小缩略图；
- 领养筛选可换行但保持清楚选中态。

### 1440×900

- Hero 使用横版；
- 业务入口两列；
- 详情媒体与侧栏双列；
- 返图墙控制最大内容宽度和列密度；
- 竖图详情舞台限宽。

## 11. 视觉验收

阶段 D 公开端至少确认：

- “返图”是一级导航 `/returns`，作品详情没有返图 Tab；
- 返图全部无水印，混合方向真实样本保持原比例；
- 返图布局 DOM/键盘顺序稳定，加载更多可操作；
- 私有原图、敏感 EXIF 和授权记录不进入 DOM、网络响应或缓存；
- `/adoptions` 三种筛选状态正确；
- 展会掉落在首页、卡片和详情显示同一名称与时间；
- 常规领养和展会掉落继续使用活动水印；
- 无返图、单图、多图、坏图、分页失败和关联作品下架状态真实；
- 三固定视口无异常裁切、横向溢出、文字遮挡或不可达操作；
- 焦点、键盘、触控和减少动效正常。
