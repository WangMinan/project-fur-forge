## 2. T05 方案对比：横向精选轨道 vs 编辑型图片网格

两方案均已实现并可由 `?featured=track` / 默认（网格）切换，三视口对比截图同目录。

| 维度 | 编辑型网格（A） | 横向轨道（B） |
| --- | --- | --- |
| 第一眼信息 | 6 件全部可见，错落节奏 | 桌面约 3.4 件、手机约 1.4 件，其余藏于滚动 |
| 交互成本 | 零交互、零 JS | 箭头/键盘/触控 + 边缘状态 JS |
| 编辑型气质 | 强（错位、留白、图片节奏） | 弱（更接近通用 carousel） |
| 横向溢出风险 | 无 | 需额外约束 rail，回归成本高 |
| 无 JS / 水合前 | 完整可用 | 可原生滚动，但箭头与边缘态失效 |
| 与“连续浏览高于组件炫技” | 一致 | 有组件感 |

**本轮候选默认选择：编辑型网格（A）。** 理由：首眼全量展示更符合“图片第一层级”和编辑型作品集定位；无 JS 依赖使 SSR 直出即可完整浏览；无横向滚动容器，三视口溢出回归更简单。轨道组件与开关保留至 T08，由用户按截图做最终确认后删除落选方案。

7. **“现有 1 位角色可领养”为夹具文案**：真实数量应由公开投影计算，T20+ 接入。
