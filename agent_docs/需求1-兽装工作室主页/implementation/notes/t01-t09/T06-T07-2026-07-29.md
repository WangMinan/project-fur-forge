## 2. 关键决策与理由

1. **样张图片仅作内部开发样张**：`mediaOrigin` 显式标注 `sample-photo`/`fixture-svg`，alt 文案带"内部开发样张"后缀；首页 T05 基线本轮不动，T20 统一接入真实投影后再替换。
2. **卡片 3:4 @1200、详情原比例**：与 `recipe-v1` 一致；`ResponsiveAsset` 只消费预生成 URL，不追加任何动态处理参数；样张照片的桌面/手机焦点人工逐张设定（蓝猫 50% 26%/24%，奶油猫 20%/18% 起）。
3. **筛选用普通链接 + query**：SSR 直出筛选结果、可分享 URL、无 JS 也完整可用；非法枚举值忽略并按未筛选处理。
4. **价格区整体可空**：仅领养作品且有 `priceCnyMinor` 时渲染；蓝莓 ¥15,600（分 → 元）带"网站不接受登记、定金或付款"声明。
5. **后台诚实提示策略**：保存/发布/上传/重试/删除/设主图全部只显示"接口尚未接入（T13–T18）"说明；发布按钮在检查未通过时禁用并给出原因；无 Toast 假成功、无 P1/P2 导航项、无 Dashboard。
6. **发布检查随表单即时求值**：编辑器把当前表单（用途切换、价格输入）映射进检查求值，演示真实联动；媒体状态仍来自夹具（上传未接入）。
7. **历史废止字段处理**：T06/T07 当时为兼容旧 Schema 将付款类废止字段置空且不提供控件；T09 已从 Schema、DTO、mapper、夹具和测试中彻底删除。
8. **对比度实测微调两个管理端 Token**：`--admin-status-success #2f7b5c→#2a6e52`、`--admin-status-warning #946124→#8a5a1e`（原值在 soft 底上实测 4.44/4.49:1，未达 AA 4.5；调整后均 ≥5:1）。公开站筛选结果数颜色由 tertiary 提为 secondary（实测 3.14:1 → 达标）。
