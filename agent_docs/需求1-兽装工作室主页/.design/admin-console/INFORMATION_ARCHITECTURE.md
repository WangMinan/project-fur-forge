# 管理端信息架构

> **角色**：当前管理端导航、页面分区、Card 边界、长任务反馈和响应式规则。
> **状态**：阶段 C 已落地；阶段 D 目标已确认，尚待 T35–T37 实现。
> **最后校准**：2026-08-07。

## 1. 设计方向

管理端是安静、清晰、低误操作的编辑工具，不复制公开站的摄影叠字和大幅展示布局。

原则：

- 一个 Card 对应一个业务对象或保存边界；
- 页面标题说明“在这里维护什么”，不展示内部任务号；
- 状态、冲突、失败和恢复靠文字与结构表达，不只依赖颜色；
- 危险操作明确说明影响和不可恢复边界；
- 长任务显示真实服务端状态；
- 未实现或已取消的功能不显示可点击假入口；
- 不把展会掉落拆成独立后台，不把返图塞进出厂照区。

## 2. 全局导航

阶段 C 当前导航：

- 作品管理；
- 首页与委托大图；
- 文案配置；
- 品牌水印；
- 账户。

T35–T36 完整实现后增加：

- 返图。

不增加：

- 当前展会；
- 更多站点文字内容；
- 回收站；
- Slug 历史。

展会掉落在“作品管理”中维护。Slug 分享与长期链接策略属于未来备忘录，不成为当前导航。

移动导航可以折叠，但不得隐藏当前长任务、冲突或未保存状态。

## 3. 作品管理

### 3.1 列表

结构：

```text
标题与新增作品
查找、筛选、分页
作品表格或卡片列表
排序与精选控制
```

每件作品显示：

- 角色名、slug；
- 对用户友好的业务类型；
- 装型和发布状态；
- 领养/掉落状态与价格摘要；
- 设定图/出厂照摘要；
- 排序和精选；
- 编辑入口。

业务类型筛选可以显示：

```text
全部
委托作品
常规领养
展会掉落
纯展示
```

内部仍映射到三种 purpose 与 adoption_method，不向管理员展示底层组合。

### 3.2 编辑页

按业务分区：

- 基础字段；
- 业务类型；
- 领养与展会掉落字段；
- 设定图；
- 出厂照；
- 关联返图摘要；
- 发布状态和阻断项；
- 危险操作。

### 3.3 业务类型选择

显示四项：

- 委托作品；
- 常规领养；
- 展会掉落；
- 纯展示。

选择“展会掉落”时显示：

- 展会名称；
- 展会时间；
- 领养状态；
- 可选价格；
- 设定图和出厂照。

切换离开展会掉落时：

- 明确提示展会字段将被清理；
- 保存后两项不保留僵尸值；
- 不跳转到另一页面或新建展会对象。

发布检查将缺失展会名称/时间列为明确阻断。展会时间只作展示，不显示“自动上架”或定时状态控件。

### 3.4 关联返图摘要

阶段 D 实现后，作品编辑页只显示：

- 关联返图数量；
- 已发布/草稿摘要；
- 前往返图列表并按当前作品筛选的普通入口。

不在作品页嵌入返图图片上传、授权记录或完整编辑器，也不把返图混入出厂照区。

## 4. 独立返图管理

### 4.1 返图列表

`/admin/returns` 结构：

```text
标题与新增返图
作品筛选、发布状态筛选
返图缩略图 / 关联作品 / 发布状态 / 顺序
分页
编辑入口
```

一条记录就是一张返图，不显示“图片数”或相册概念。

列表不显示私有 Object Key、完整授权备注或可长期复用签名 URL。缩略图可以使用受控管理预览或当前 READY 公开变体，并明确来源。

### 4.2 新建与编辑

页面分区：

1. 关联作品；
2. 返图图片；
3. alt 与排序；
4. 授权记录（可选，仅后台可见）；
5. 无水印公开预览；
6. 发布检查、发布、下架和 operation；
7. 危险操作边界。

规则：

- 必须选择已有作品；
- 一条记录只允许一张 `return_photo`；
- 图片明确标注“返图”，不使用“出厂照”文案；
- 授权来源、确认时间、备注可以全部为空；
- 授权 Card 明确说明不会公开，也不写入图片元数据；
- 私有原图预览和无水印公开预览有清楚标签；
- 不显示 Logo、水印位置、不透明度、缩放或“关闭水印”开关；
- 只有关联作品已发布且公开变体 READY 时允许发布；
- 作品下架导致公开不可见时，页面显示原因，但不擅自删除返图记录。

### 4.3 发布与持续状态

返图上传、核验、公开生成、发布和下架显示：

- 当前阶段；
- 已完成/总数或不定进度；
- operation ID 的受控摘要；
- 失败阶段和可理解动作；
- 刷新后的恢复状态；
- 重试入口；
- 清理待办。

不得只显示按钮 Spinner 或最终 Toast。重复重试不得产生重复公开记录。

### 4.4 冲突

所有写入携带版本。409 后：

- 保留当前本地输入；
- 加载最新服务端版本摘要；
- 允许用户重载或人工比较；
- 不自动递增版本或静默重发旧 payload。

### 4.5 删除边界

阶段 D 不提供回收站。完整支持下架。

永久删除不是阶段 D 的必做入口；若实现仅草稿删除，确认框必须明确不可恢复和媒体清理影响，不能显示“30 天内可恢复”。

## 5. 首页与委托大图

首页和委托使用不同 placement，共用组件但请求、数据、反馈和 operation 隔离。

每项显示横版源、竖版源、alt、顺位、可选作品关联、启用状态、无水印站点变体状态、低分辨率适配状态和恢复入口。

管理预览明确：公开 Hero 无水印；预览不是永久公开原图；放大适配不会创造细节。

## 6. 文案配置

当前页面按独立 Card 维护：

1. 营业状态；
2. 官方联系方式；
3. 委托基础文案；
4. 委托 FAQ；
5. 关于工作室；
6. 服务条款；
7. 隐私政策。

每个 Card 独立 dirty/save/saved/conflict/error。页面其他 Card 保存时不禁用当前 Card；同一 Card 冲突保留草稿。

T38 已取消：不新增“更多内容”Card、页面树、任意 HTML、脚本或页面搭建器。

## 7. 品牌水印

品牌页继续管理：

- Logo 候选；
- profile 参数；
- 真实作品水印预览；
- 影响摘要与应用。

影响摘要必须说明：

- 标准作品、常规领养和展会掉落会重新生成；
- 首页、委托页和首页入口无水印，不受影响；
- 返图墙无水印，不受影响。

品牌页不得把返图列为待重建对象，也不得提供返图水印开关。

## 8. 账户

账户页提供当前用户名、修改密码、Session 失效说明和离线重置命令提示。不在浏览器生成或显示初始密码。

## 9. 全局状态与错误

### Loading

- 首次加载使用页面级状态；
- Card 保存使用局部状态；
- 长任务使用持续状态；
- 不用全屏 Spinner 阻塞无关区域。

### Empty

- 无作品、无 Hero、无 Logo 候选和无返图均有真实下一步；
- 不使用虚假样例填满页面；
- 不显示空展会管理页。

### Validation

- 行内显示并聚焦首个错误；
- 服务端 400 不丢失输入；
- 展会掉落缺少名称/时间时明确说明；
- 返图关联作品未发布时明确说明。

### Conflict

- 使用稳定业务 reason；
- 说明哪一资源发生变化；
- 只重载对应资源；
- 保护当前草稿。

### Operation failure

- 显示失败阶段和可操作建议；
- 内部错误码只用于映射和支持；
- 清理失败、重试和恢复状态刷新后仍可见。

## 10. 响应式与手机能力

### 桌面

- 侧栏固定；
- 内容最大宽度受控；
- 编辑与预览可以并列；
- 复杂媒体和长任务 Card 全宽；
- 操作按钮靠近所属分区。

### 平板

- 侧栏可折叠；
- 两列只在字段不拥挤时保留；
- 预览与编辑可以上下排列。

### 手机

T36 至少支持：

- 查看返图列表和状态；
- 新建一条返图；
- 选择关联作品；
- 单图上传；
- 编辑 alt 和可选授权文字；
- 发布、下架和查看恢复状态。

T37 至少支持：

- 选择展会掉落；
- 编辑展会名称、展会时间、状态和价格；
- 查看发布阻断；
- 发布和下架。

不建设独立 T41，也不为手机强行实现批量上传、批量排序、复杂焦点或横竖 Hero 配对。

所有手机页面必须无横向溢出，标签和错误不截断，Dialog 不超出视口，保存/冲突/任务状态不会因折叠丢失。

## 11. 管理端验收

阶段 D 至少确认：

- “返图”只在完整实现后进入导航；
- 返图一图一记录，关联作品、图片、alt、授权记录和发布状态分区清楚；
- 授权记录不进入公开预览、公开网络响应或日志；
- 公开预览无水印且与 `/returns` 实际对象一致；
- 作品编辑器四个业务选项映射正确；
- 展会掉落只显示两项展会字段，不出现独立展会入口；
- 品牌 profile 影响摘要排除站点展示和返图；
- 400、409、429、500、刷新、登录过期和进程恢复有可操作状态；
- 390×844、768×1024、1440×900 可完成约定操作。
