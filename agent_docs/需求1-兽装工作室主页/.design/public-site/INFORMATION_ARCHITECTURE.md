# 公开站信息架构

> **角色**：当前公开页面结构、内容顺序、组件关系和响应式行为。
> **状态**：阶段 C.1 目标；现有代码需按 T34-F1/F2 迁移。

## 1. 全局框架

公开站使用统一：

- 跳转到正文的 skip link；
- 品牌页头；
- 桌面与移动导航；
- 主内容；
- 紧凑页脚和法律入口；
- HTML 404/500 错误页。

页头导航只展示已经实现的公开页面。管理入口不出现在公开导航。

## 2. 首页

页面顺序固定为：

```text
Hero
精选作品
统一业务入口
当前领养
页脚
```

### 2.1 Hero

内容：

- 无水印横版或竖版代表作品；
- 工作室名称；
- 一句口号；
- “查看这套作品”或“浏览作品展示”；
- 多项时的上一张、下一张、分页和暂停。

行为：

- 横屏消费横版 SourceSet；
- 竖屏消费竖版 SourceSet；
- SSR 直出第一项；
- 只渲染当前项图片；
- 自动轮播默认关闭；
- 悬停、焦点、页面隐藏、减少动效暂停；
- 文字安全区由渐变保护，但不以渐变掩盖整张图片。

禁止：

- 在 Hero 上烘焙品牌水印；
- 在图片中心叠加大 Logo；
- 在 Hero 下立即重复相同状态和行动信息。

### 2.2 精选作品

标题与“查看全部作品”位于同一行，下面是横向轨道或等价响应式列表。使用带活动水印的作品卡片图。

无精选时整区隐藏。接口异常时允许该区降级隐藏，不能导致 Hero 和业务入口不可访问。

### 2.3 统一业务入口

替代旧的“大图入口区 + 当前状态区”。

桌面：两列等宽；移动：单列。每张卡包含：

```text
无水印入口图
业务标题
状态点 + 状态标签
一行状态说明
箭头或行动文字
```

卡片 1：

- 标题：自设委托；
- href：`/commission`；
- 图片：`home-entry-commission`；
- 状态：委托营业状态。

卡片 2：

- 标题：角色领养；
- href：`/adoptions`；
- 图片：`home-entry-adoption`；
- 状态：领养营业状态。

视觉要求：

- 两卡使用同一比例、圆角、留白和叠字方式；
- 图片和状态的视觉权重低于 Hero、高于普通文字；
- 状态不能另起一整块灰底工具面板；
- 整卡是一个主链接；
- 状态 detail 过长时最多显示受控行数，完整内容在目标页面可读；
- 缺图片时使用白底/浅灰受控占位和文字，不任意借用其他作品；
- 缺状态时仍可显示入口，但不编造“开放中”。

### 2.4 当前领养

最多两件，使用带活动水印的领养设定图。标题和“查看全部”位于同一行。无领养时隐藏。

## 3. 作品列表

结构：

```text
页面标题与短说明
用途筛选
装型筛选
结果数量
作品网格 / 空状态
页脚
```

要求：

- 筛选是普通链接，SSR 和无 JS 可用；
- 当前选中态清晰；
- 用途和装型取交集；
- 非法参数显示明确空态和清除入口；
- 作品卡统一 3:4，使用焦点裁剪和活动水印；
- 卡片只显示必要信息：角色名、物种、装型、用途；
- 不在卡片堆叠完整属性和联系方式。

## 4. 作品详情

结构：

```text
返回作品展示
角色名与基础元信息
媒体列 + 事实侧栏
前后浏览
继续浏览
```

### 4.1 媒体分区

领养作品：

1. 设定图；
2. 出厂照 / 作品图集。

其他作品：

1. 出厂照 / 作品图集。

所有图片继续使用活动水印。

### 4.2 图集方向布局

主图组件根据当前图片尺寸设置：

- `landscape`：媒体舞台可使用媒体列宽度；
- `portrait`：舞台收窄并居中，宽度由图片比例和最大高度共同决定；
- `square`：介于两者之间。

竖图要求：

- 页面背景保持白色；
- 不显示铺满媒体列的灰色左右翼；
- 不裁切图片主体；
- PC 端限制最大高度，图片可在一屏内理解；
- 移动端使用可用宽度，不制造横向滚动。

缩略图：

- 方形裁剪只用于导航；
- 当前项有清晰边框和 `aria-pressed=true`；
- 切换作品或 gallery 后重置到 0 或有效索引；
- active item 缺失时不保留虚假的选中态。

### 4.3 事实侧栏

包含：

- 物种；
- 装型；
- 用途；
- 角色主人公开显示；
- 领养方式和业务状态；
- 短属性；
- 可公开人民币价格及“不提供网站交易”的提示。

不显示私有联系人。

## 5. 常规领养

`/adoptions` 使用更适合设定图阅读的列表或网格：

- 带活动水印的设定图；
- 角色名；
- 状态；
- 可选价格；
- 统一详情入口。

只有 READY 设定图、合法常规领养字段和 published 状态的作品可见。

## 6. 自设委托

结构：

```text
页面名称
无水印委托 Hero
Hero 内营业状态、短说明和行动
制作范围
估价与联系
FAQ
服务条款入口
```

Hero 与首页 Hero 共享摄影优先风格，但不是首页轮播：

- 一组当前代表图；
- 横竖响应；
- 无水印；
- 可关联作品详情；
- 状态与 CTA 不遮挡关键主体。

制作范围、估价和 FAQ 使用阅读型排版，不把每段文字都做成彩色 Card。

## 7. 关于、服务条款和隐私政策

### 关于

- 工作室事实；
- 制作范围；
- 官方渠道；
- 防诈骗提示。

正文最大宽度适合阅读。官方渠道使用简洁列表和复制/邮件行动，不做社交平台大按钮墙。

### 服务条款与隐私政策

- 独立标题；
- 52rem 左右阅读宽度；
- 空行分段；
- 逐条内容有足够行距；
- 页头二级导航和页脚法律入口均可到达；
- 兼容旧路径永久重定向。

## 8. 空态与错误态

公开页面只表达真实状态：

- 无作品：作品正在整理中；
- 无常规领养：当前没有公开领养；
- 无委托 Hero：显示页面标题、状态和正文，不借用首页图；
- 无入口图片：入口仍可用，但使用受控占位；
- 404：作品不存在或尚未发布；
- 500：简洁错误页，不暴露 request body、Object Key 或堆栈。

## 9. 响应式

### 390×844

- Hero 使用竖版图；
- 业务入口单列；
- 作品网格两列或经视觉验证的单列；
- 详情侧栏进入媒体后；
- 所有按钮和卡片链接有足够触控区域。

### 768×1024

- Hero 依据实际 orientation 选择竖版；
- 业务入口可两列，但文字不能挤压；
- 详情可以单列或过渡布局；
- 导航和页脚无横向溢出。

### 1440×900

- Hero 使用横版；
- 业务入口两列；
- 详情媒体与侧栏双列；
- 竖图舞台限宽，侧栏不被极高图片推到不可理解的位置。

## 10. 视觉验收

必须用真实媒体而不是纯色 fixture 核对：

- 首页 Hero 无水印；
- 委托 Hero 无水印；
- 两个首页入口无水印且视觉一致；
- 精选、作品和领养仍有活动水印；
- 竖图详情无灰色左右翼；
- 业务状态在入口卡内只出现一次；
- 长标题、长状态、无图、无状态均不破版；
- 焦点、键盘、触控和减少动效正常。
