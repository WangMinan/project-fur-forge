# PLAN 原型 v2 · SPEC 自审

> 历史记录：本文件保留 v2 当时的自审结论；当前审查应以 [SPEC-REVIEW-v5.md](./SPEC-REVIEW-v5.md) 为准。

## 结论

本轮原型在交付前按锁定的 `requirements/SPEC.md` 做了页面、交互、数据边界和后台职责复核。自审发现的偏差已在 v2 中修正；当前没有发现会要求修改 SPEC 的设计决策。`PLAN:OQ-018` 仍保持待答，是否接受这套视觉和交互方向由用户审查决定。

## 自审中发现并修正的问题

1. v1 把“基本约定”并入关于摘要，缺少独立一级页面；v2 已增加独立页面、导航和七类内容。
2. 第一版返图上传稿误加“已获授权”勾选，违反 OQ-103；v2 已删除。
3. 快速编辑的业务状态曾使用非锁定枚举，且没有显式表示展会约束；v2 已换成六种锁定状态并补领养方式/当前展会。
4. 完整导出的图片清单曾错误暗示导出对象标识与校验值；v2 已按 OQ-112/OQ-117 改成最低字段，并明确排除内部对象键。
5. 将“原图档案”改名为“完整导出”后，一度缺少永久档案的检索/重新关联职责；v2 已在导出中心恢复该入口。
6. v1 大面积黑/米白和高饱和强调色不符合本轮设计意见；v2 已改为白色主底和低饱和辅助色，后台侧栏、向导页头与页脚同步提亮。

## 原型阶段明确不冒充已实现的内容

- 原型使用 hash 切换模拟多页；生产站仍必须由 Spring MVC 提供稳定、可索引的独立 URL、标题/描述、站点地图和分享元数据。
- 右侧“切换到后台原型”只用于评审，不代表公开站会暴露后台入口；生产后台使用独立子域名、真实登录、会话与权限隔离。
- 上传、处理、发布、导出与原图下载均为交互模拟，不连接 OSS、MySQL 或 SMTP；生产实现必须完成真实失败恢复、尺寸读取、最长边校验、二次确认、鉴权和 E2E。
- 几何 SVG 只用于规划阶段验证比例、密度和色彩；正式上线前必须替换为工作室授权的 Logo、出厂照和设定图。
- “基本约定”正文目前只验证信息结构，不是最终法律文本；上线内容仍需工作室确认及适用性/法律审阅。
