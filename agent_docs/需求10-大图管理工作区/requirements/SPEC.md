# 规格说明：大图管理工作区

## 来源与目标

- 2026-10-08 用户明确要求优化 `/admin/site/home` 的首页/委托页大图 UI，减少双层 selector 与多层背景卡片。
- 继承 [需求4 Hero 契约](../../需求4-站点视觉升级与内容合规/requirements/SPEC.md)，本需求仅覆盖第9.2节的双层 Tab 展示方案。

## 工作区契约

- 只保留“大图管理”页标题。使用页面下拉与横/竖画幅切换处于同一工具栏；窄屏自然换行。
- 两个画幅入口同时显示启用数量/容量，以及真实加载、读取失败或长任务状态。
- 下方直接展示当前集合图片，不再用灰色工作区包裹白色卡片；每图一层卡片，预览使用轻描边。
- 宽屏预览与编辑操作并列，窄屏按预览、焦点、字段、操作顺序阅读。已启用项展示说明与停用入口，隐藏不可编辑的表单。
- 图片排序界面显示第1–5张，提交时仍映射到原0–4 sortOrder；委托单槽不提供排序控件。
- 新增草稿可取消，返回新增按钮焦点；上传或持久操作期间不允许取消。取消不执行资产删除。
- 现有 placement/orientation 与旧 tab 深链接继续有效；切换页面保留当前画幅，同一页面横竖切换保留未保存草稿。
- 四集合的独立 CAS、上传 owner、焦点保存、适配/发布前自动保存、删除/撤销、任务进度、私有同源预览与真实画框比例保持。

## 组件边界

- 页面组织选择器与摘要；`HeroCollectionEditor` 管集合状态和已有操作。
- `HeroCollectionItemCard` 管单图草稿与表单；`HeroFocalPicker` 保留预览/焦点，slot 承载同一侧栏的单图字段与操作。
- 复用 `AdminSelect`、`AdminAction`、`AdminStatusBadge` 和 `AdminTaskProgress`。

## 非目标

- 不新增图库、自动配对、批量发布、服务端能力或依赖；不改变公开大图效果，不做生产数据操作。

## 验收

- 四集合切换/摘要/草稿保持和新增取消正确，横竖画幅真实比例不变。
- 保存失败不发布、发布/适配保存焦点、排序映射和删除/停用链路保留。
- 桌面/窄屏、键盘/触控、偏好、图片 decode、无页面溢出与错误检查通过；lint/typecheck、受影响 core 与构建通过。
- 用户观感、真实手机和发布部署分别记录，不以自动测试代签。

## 开放问题

无。

## 追加：后台页头与画幅文字对齐（2026-10-08）

- 用户要求画幅切换文本居中、统一字号，并统一后台所有导航 tab 的标题字号、偏移与分割线。
- 作品管理、委托申请、大图管理、站点配置、访问概览、修改密码六页共用 `AdminPageHeader`。标题统一28px、600字重、44px标题行，页面起始坐标一致；按钮与辅助计数不再改变标题位置。
- 各页顶部只保留共用页头底部的一条分割线，统一左右边界与纵向位置；移除列表筛选栏及大图工具栏的额外分割线。表格边界、分页线、卡片边框与选中画幅下划线保留各自语义。
- 各页正文保持相应阅读宽度，窄表单不因页头对齐而拉伸；访问统计的时区说明移到统一页头下方。
- 画幅名称、设备比例、计数与处理中状态统一14px并在切换项内居中；窄屏可换行，保留焦点与选中反馈。
