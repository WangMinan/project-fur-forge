## 本轮修正

1. 在公开导航中增加“首页”，避免只能点击 Logo 返回。
2. 统一公开文案为“作品展示 / 自设委托 / 角色领养 / 返图墙”。
3. 作品页取消错落卡片，改为桌面四列、手机两列的等大 3:4 网格，并补两组真实可点击筛选。
4. 将作品、委托、领养、返图、关于和联系的内页页头改为短标题；作品筛选仍属于必要操作，不再用冗余描述占据首屏。
5. 合并关于与基本约定，同时保留七类约定和隐私说明的完整信息结构。
6. 将后台“页面内容”改名为“首页与页面”，并在页头说明其职责是维护不属于单件作品的站点级内容。
7. 修正页脚与联系页的白底文字对比；生产素材到位后仍需对真实图片上的覆盖文字做逐图校准。

## 原型阶段边界

- hash 路由只用于本地评审；生产由 Spring MVC 提供稳定 URL、SEO、`/terms` 兼容跳转与浏览器历史语义。
- 上传、处理、发布、导出和下载均为交互模拟，不连接 OSS、MySQL 或 SMTP。
- 几何 SVG 是比例与色彩占位图，正式上线前必须替换为获授权素材。
- 基本约定只验证信息结构，正式文案仍需工作室确认及适用性/法律审阅。
