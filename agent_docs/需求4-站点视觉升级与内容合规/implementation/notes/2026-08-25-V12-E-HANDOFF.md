# V12-E Handoff · Error / Empty / Media Failure Static States

状态：V12-E implementation、Desktop/390/430 Evidence 与 Design Review 已完成。强制停止，V12-E-F1 未开始。

## Completed

- `PublicEmptyState.vue` 统一普通 empty、搜索 no result 与错误状态的规则线、标题、说明、恢复行动和淡色工作室 Logo 水印。
- `error.vue` 增加 brand-only Header，404/500 保留真实状态码和安全通用文案；500 不投影底层异常信息。
- `ResponsivePicture.vue` 在原媒体比例内加入同款水印和失败文字；无 JavaScript 路径继续输出原始图片。
- `WorkCard.vue` 只在作品目录卡片内补偿底部身份渐变占位，使失败文字与水印共同处于可见媒体区域的视觉中心。
- 五类状态均输出 1440×900、390×844、430×932 独立截图；另有 404 键盘焦点证据。

## Locked Decisions

- 水印只复用 `/brand/logo-mark.png`，保持低对比度灰度、轻微旋转、绝对定位、`aria-hidden`；不得影响布局或读屏。
- `PublicEmptyState` 继续是公开空态/无结果/错误的共享视觉入口，`ResponsivePicture` 继续是图片失败的唯一媒体入口。
- 500 只显示通用恢复说明；不得显示 `statusMessage`、邮箱、内部路径、私有媒体信息或异常详情。
- 不新增占位图、自动重试、接口、状态机、依赖或 Motion；Footer、搜索逻辑、媒体 DTO 和安全边界保持不变。

## Regression Risks

- 后续修改 Logo 画布或透明边界时，应重新检查状态面裁切和失败卡片中的视觉尺寸。

- 图片失败层位于作品卡渐变下方；后续重做卡片 overlay 时必须保留失败文字对比度。
