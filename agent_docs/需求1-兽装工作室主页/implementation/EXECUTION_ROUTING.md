## 7. 路由维护规则

- `TASKS.md` 继续只描述产品任务、依赖、验收和完成状态，不在每个任务标题中写模型名。
- 当前批次或模型发生变化时，先更新本文件，再同步 `STATE.md` 的当前阶段与下一步。
- `artifacts/ARTIFACTS.md` 只登记本文件的存在与当前效力，不把执行路由提升为产品契约。
- 模型能力、订阅或工作方式变化不触发 SPEC/PLAN 变更；只有业务、数据、接口或体验契约变化才走上游文档流程。
