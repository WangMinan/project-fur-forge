# Design Brief：兽装工作室公开站

## Problem

访客需要在几秒内判断工作室的制作气质与完成能力。他们应先看到兽装作品，而不是品牌长文、蓝色营销面板或复杂交易界面；同时仍能清楚进入作品、委托、领养、返图、约定与联系路径。

## Solution

把公开站设计为图片大底/白底的编辑型摄影作品集。首页由代表作品占据首个主要视口，后续通过有节奏的图片和极少必要文字完成浏览。所有行动必须真实：委托通过邮件，领养通过邮件或线下，网站不模拟登记、报价或支付。

## Experience Principles

1. **作品证据高于品牌装饰**：图片能说明的内容不重复写成长文；Logo、标题和动效与作品冲突时先弱化辅助元素。
2. **白底与摄影高于品牌色铺陈**：蓝色负责识别、行动和焦点，不承担页面主体面积。
3. **连续浏览高于组件炫技**：用比例、留白和图片节奏构成体验，不堆卡片、统计、毛玻璃或视差。
4. **真实截图高于组件预设**：横向轨道、编辑型网格等方案必须通过三视口截图比较，不因已有组件名而锁死。
5. **清楚路径高于多重转化**：每页只保留与职责一致的主要行动，未实现能力不显示为控件。

## Aesthetic Direction

- **Philosophy**：Editorial Fursuit Portfolio。
- **Tone**：干净、年轻、亲近、克制，不做高冷奢侈品，也不做企业 SaaS。
- **Canvas**：白色和极浅中性色；作品摄影承担主要色彩。
- **Brand blue**：明显蓝色常态占单页视觉面积 5%–10%，15% 为硬上限。
- **Reference**：借鉴渔屋等站点的“图片第一印象、白底作品浏览、克制业务入口”，不复制 Logo、字体、卡片和专有构图。

### Anti-references

- 深色赛博朋克、黑黄工业、霓虹、毛玻璃、随机渐变、3D 球体；
- 连续蓝底区块、蓝色卡片墙、蓝色渐变大按钮；
- “半张作品图 + 半张蓝色说明面板”的通用营销首屏；
- 标题 + 三张同款圆角功能卡 + 统计数字；
- 每屏大标题、胶囊按钮、视差和 AI 拼装装饰；
- 直接复制宣传海报的斜切构图、大字价格或重复纹样；
- 把 v5 几何 SVG、现有字体和弹窗布局升级为生产 UI。

## Color Use

- `#324DAF`：主要行动、链接、可见焦点；
- `#293C84`：Hover、深强调；
- `#1D2D5A`：极少量反白区域、受控遮罩；
- `#6274BB`：只作大字号或装饰，不承担白底小正文；
- `#CED3E5`：弱背景、边界、占位；
- 页面主体仍由 `#FFFFFF`、中性灰和作品图构成。

禁止把“15%”当作必须填满的目标。多数页面应更接近 5%–10%；作品列表甚至可以只在链接、焦点和当前筛选中出现蓝色。

## Typography

- 展示衬线字体只是候选，用于工作室名、角色名和少数一级标题；正式 Logo/作品图到位后与更亲近的无衬线方案做 A/B。
- 正文、按钮、筛选和状态使用稳定无衬线。
- 不依赖中国大陆访问不稳定的远程字体服务；自托管字体必须确认许可和体积。

## Component Inventory

| Component | Notes |
| --- | --- |
| `PublicHeader` / `PublicMobileNav` | 首页图片覆盖态与内页白底态；七个一级页面可达 |
| `HeroMedia` | 全视口代表作品图、独立桌面/手机焦点、安全区、一个主行动 |
| `FeaturedWorks` | 横向轨道（用户 2026-07-30 T08 最终验收确认），不自动轮播 |
| `ImageRouteCard` | 委托/领养图片入口；短标题、短事实、真实行动 |
| `ResponsiveAsset` | 只消费 OSS 预生成公开衍生图；输出 picture/srcset/sizes、尺寸与 alt |
| `WorkFilterBar` | 作品用途 × 装型交集、结果数、清楚选中态 |
| `WorkGrid` / `WorkCard` | 3:4 图片网格；不把整页包成同款重卡片 |
| `WorkDetailGallery` | 主图、原比例图集、必要事实、短属性、适用 CNY 价格；PC 端主图限高，纵向图片一屏内完整可见、不裁切 |
| `BusinessStatus` | 委托/领养营业状态，不与单件作品状态混用 |
| `FaqAccordion` | 只展示已确认事实，支持键盘和焦点恢复 |
| `ReturnMasonry` / `ReturnEmptyState` | 真实照片墙或真实空状态 |
| `ContactChannels` | 邮件主行动、复制邮箱、QQ、抖音和反诈 |

## Key Interactions

- 首屏内容存在于服务器 HTML；入场动效不延迟主图、标题或行动。
- 精选作品不自动播放；选择横向轨道时支持箭头、键盘和触控。
- 作品筛选保持人工顺序；卡片使用普通链接进入 `/works/{slug}`。
- 图片失败时保留比例和作品名，不造成大面积空洞或布局跳动。
- 价格只在适用作品有已发布 CNY 金额时出现；无值时删除整个区域。
- FAQ、移动导航和图集覆盖层正确管理焦点。
- `prefers-reduced-motion` 下取消非必要位移、缩放和自动过渡。

## Responsive Behavior

- 390px：全视口首屏、折叠菜单、作品两列、详情单列、无横向溢出；
- 768px：作品三列，控件不依赖 Hover；
- 1440px：作品四列，图片可突破正文容器，文字宽度受控；
- 主图和文字安全区分别保存桌面/手机数据，不只依赖居中裁切。

## Accessibility Baseline

- 语义标题、导航、链接、按钮；
- 正文与交互文本满足可读对比，图片覆盖文字逐图检查；
- 导航、筛选、FAQ、精选和图集支持键盘与可见焦点；
- alt 来自后台或安全回退；装饰图使用空 alt；
- 状态不只依赖颜色或动画。

## Out of Scope

在线估价、站内委托表单、领养登记、访客账号、订单、支付、评论、多语言、首屏视频、声音、WebGL、暗色主题和自动推荐。
