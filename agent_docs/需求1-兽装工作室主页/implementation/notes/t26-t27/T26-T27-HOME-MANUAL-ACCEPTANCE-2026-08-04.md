# T26/T27 下班后人工核对清单

> 适用范围：T26 委托页与营业状态、T27 关于/基本约定/联系页，以及 T26-F1 委托页独立大图。
> 状态边界：T26/T27 已完成独立 Review；本清单是用户补验。T26-F1 仍需独立 Review/用户验收，不能因本地能打开页面就自动勾选。
> 内容边界：OQ-120 最终文字未确认前，不要为了测试把候选稿或临时文案留在开发库；空值区块应当隐藏。

## 1. 启动

在 PowerShell 执行：

```powershell
cd D:\code\project-fur-forge
pnpm db:migrate
pnpm dev --host 0.0.0.0 --port 3000
```

- 管理端只用 `http://localhost:3000`；
- 客户端只用 `http://127.0.0.1:3000`；
- 两个 Host 不可互换。忘记管理员密码时，先停止开发服务，再执行 `pnpm auth:reset-password --confirm RESET_SINGLE_ADMIN_PASSWORD`。

## 2. T26 与 T26-F1：委托页和营业状态

### 2.1 管理端文案与状态

1. 打开 `http://localhost:3000/admin/site/content` 并登录。
2. 检查“委托状态”和“领养状态”是两张独立卡片；分别修改其中一张时，另一张不应跟着变化。
3. 只填写你确认可以公开的标签、说明和页面文案；保存后刷新，值应保持。
4. 在输入中临时键入 `<script>` 时，页面应提示只允许安全纯文本并阻止保存；随后删掉该测试内容。
5. OQ-120 尚未确认的字段保持空白；公开端对应区块应整块隐藏，而不是出现占位文案。

### 2.2 委托页独立大图

1. 打开 `http://localhost:3000/admin/site/home?tab=commission`，确认选中“委托页大图”，且看不到首页口号/自动轮播设置。
2. 先上传横版至少 `1920×1080`、竖版至少 `1080×1920` 的候选图，填写简短准确的图片说明，创建并启用；尺寸满足时不应出现放大提示。
3. 再准备一组方向正确但低于上述尺寸的测试图。上传和保存应成功，槽位应显示当前尺寸与黄色清晰度提示；点击启用时应出现确认框，明确说明 FFmpeg Lanczos 插值不会恢复细节。先取消一次，确认没有开始处理；再次确认后，卡片应持续显示“正在放大适配”，完成后继续既有水印/公开图进度并成功启用。
4. 若准备两项，使用“上移/下移”调整顺序；客户端应只显示排序第一的已启用项。
5. 切回“首页大图”，确认首页原有图片、顺序和启用状态没有变化。
6. 回到委托 Tab，停用全部委托图后，客户端委托页背景区应隐藏，且不得出现首页图片。

### 2.3 客户端委托页

打开 `http://127.0.0.1:3000/commission`：

- 大屏显示委托集合的横版图，手机窄屏显示同一项的竖版图；图片能完整解码，无破图；
- 当前委托状态与管理端一致；
- 制作范围只显示已确认事实，不出现统一公开价目、自动报价或站内提交表单；
- “打开邮件客户端”和“复制邮箱”可操作，复制后有明确成功提示；
- FAQ、估价说明和邮件说明仅在管理端有真实内容时显示；
- “基本约定”链接进入 `/about#terms`。

## 3. T27：关于、基本约定和联系页

1. 在 `http://localhost:3000/admin/site/content` 检查“关于我们”“基本约定”“联系我们”固定字段；不要录入未确认的品牌故事或竞品原文。
2. 打开 `http://127.0.0.1:3000/about`：工作室事实与制作范围只在有内容时显示，官方渠道正确。
3. 打开 `http://127.0.0.1:3000/about#terms`：页面应滚动到“基本约定”；空值时如实提示尚未发布，不生成虚构条款。
4. 打开 `http://127.0.0.1:3000/contact`：邮箱、QQ、抖音正确；防诈骗字段为空时隐藏；页面没有站内联系表单或模拟成功。
5. 使用键盘按 Tab：首个焦点应为“跳到主要内容”，Enter 后焦点进入正文；移动导航可用 Enter 打开、Escape 关闭并归还焦点。

## 4. 可选：双窗口 409 冲突恢复

此项会写开发库；先记下原值，结束后恢复原值或最终确认值。

1. 同时打开两个 `http://localhost:3000/admin/site/content` 标签页 A、B，两页都不要刷新。
2. A 修改一个已确认字段并保存。
3. B 修改同一字段后保存，应出现“操作未完成”，说明站点内容已在其他地方变化并已重新加载。
4. 点击“知道了”，确认 B 的输入仍保留；核对最新基线后再次保存，应成功。
5. 刷新管理页和对应公开页，确认最终只显示最后一次明确保存的值。
