## 人工验收

入口：[作品管理](http://localhost:3000/admin/works)，公开站：[本地公开站](http://127.0.0.1:3000)。

1. 打开领养作品，先在线切换“自动／横版封面／设定图”，分别关闭详情封面与设定图；确认目录来源和详情显隐互不影响。无出厂照时不能隐藏最后一张图。
2. 对要修改像素的作品先下架。每张出厂照点“详情缩略图”框选头部，应用后保存出厂照；重新打开检查选区，再取消一次修改，确认保存值不变。
3. 主出厂照分别修改“作品目录”“首页代表作品”，或切换完整显示；两类领养图片可分别编辑“领养目录”“首页当前领养”。切换图片顺序、主图或说明后构图应保留。
4. 重新发布，检查目录4:5、代表作品3:4与详情1:1小图，各用途互不影响；点击小图后的完整大图不裁切。
5. 用真实手机检查裁切手柄、页面滚动、弹窗可达性、构图观感及单图/多图切换。

裁切弹窗“应用”只修改当前页面状态，需保存所在图片区域；详情展示设置单独在线保存。跨区域调整若被“最后一张图”或“指定来源不可用”阻止，请先保存新增图片或开启附加图，再移除原图片。

## Regression Risks

- 旧作品首次主动启用构图会按新模式重新生成该作品所需用途；不存在全站批量升级。替换成新资产使用新默认，未修改的当前主图按旧crop/gravity初始化一次。
- 极小或极端长宽比选区可能超过既有12000像素处理上限，保存/预检会提示调整；不会用无限放大“恢复细节”。
- 下架/发布沿现有持久操作执行，来源文件缺档时不会静默切换其他指定角色。
- 新数据库/配方不保证旧二进制可以直接读取；需要回退时按目标版本备份和恢复文档处理，不改历史迁移。
