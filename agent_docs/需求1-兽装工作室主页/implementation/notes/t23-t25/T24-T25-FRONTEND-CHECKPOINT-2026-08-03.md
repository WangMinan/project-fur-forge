## 已实现

- 管理编辑器按领养设定图与出厂照分区；设定图最多 1 张且只在领养作品显示，出厂照最多 5 张并维护顺序、唯一主图、alt 与卡片焦点。
- 私有原图通过 `assetId` 同源认证路由预览；活动 `brand-centered-v2` 水印预览由服务端临时生成并立即清理，不向浏览器返回 Object Key 或签名 URL。
- 上传卡片呈现摘要、PUT 百分比、服务端核验、处理失败与重试，并通过上传会话 ID 在重载后恢复；关系保存后采用服务端新版本重建媒体基线，同时保留其他分区未保存输入。
- 作品列表显示设定图有无、出厂照数量、主图缩略图、发布阻断摘要和分区直达，不提供批量媒体操作。
- `/adoptions` 使用完整横版设定图、状态、短属性和适用人民币价格；点击进入统一 `/works/{slug}`。统一详情仅为领养作品呈现设定图区，并将出厂照作为独立图集。
- 无 regular adoption 时呈现真实空状态；未接入登记、定金、支付、站内申请、展会实体或完整展会掉落 UI。
