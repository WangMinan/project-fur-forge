# 居中可配置品牌水印规格增量（2026-08-01）

> **角色**：这是 `SPEC.md` 的局部增量规格。仅在水印来源、位置、透明度、尺寸、管理流程和发布验收方面覆盖旧条款；其余需求继续以 `SPEC.md` 为准。

## 1. 目标结果

景宸需要在不接触服务器路径、OSS Key 或部署文件的情况下维护公开图片使用的品牌水印。公开作品图和首页图使用大尺寸、半透明、居中的 Logo；横版领养设定图使用左右两枚等大 Logo，覆盖更完整的横向画布，而不是左上角的小型角标。

## 2. 标准水印 profile

P0 新的活动目标为 `brand-centered-v2`：

- 位置：普通 P0 图片固定居中；`design-sheet` 由配方固定为左右双水印；
- 默认透明度：50%；
- 默认缩放：目标输出图片的 60%；
- 可调透明度：10%–90%；
- 可调缩放：20%–90%；
- 私有原图和私有预处理源：永远无水印；
- 适用角色：`studio_photo`、`design_sheet`、`home_hero_landscape`、`home_hero_portrait`；
- P1 `return_photo` 继续使用独立的轻量 profile，不在本轮被强行改成同样的大型水印。

从 `recipe-v2` 起，水印图形的实际边长统一为 `recipe-v1` 的 1.6 倍；横版设定图的左右两枚水印不得重叠。该渲染规则属于配方身份，不原位修改已经生成的 v1 对象；新版本完整前允许公开投影继续读取完整 v1 集合，完整后整体切到 v2。

位置不作为日常可调项。管理端不能关闭 P0 强制水印、不能恢复四角角标，也不能把设定图的左右双水印改成逐图选点。

## 3. 水印源管理

新增管理路由 `/admin/site/branding`，提供受限的“品牌水印”编辑器：

- 上传新的透明 PNG 水印候选；
- 查看已验证候选的缩略图、尺寸、摘要尾段、创建时间和当前使用状态；
- 选择一项作为 profile 草稿的水印源；
- 调整透明度和缩放比例；
- 在代表性的竖版出厂照、3:4 卡片、横版首页图和竖版首页图上查看真实 OSS 生成预览；
- 显示受影响的已发布作品和公开 variant 数量；
- 显式执行“应用并重新生成”；
- 显示生成、验证、切换和清理进度；失败信息持续可见并可重试。

管理端不得提供任意文件路径、任意 OSS Object Key、外链 URL、脚本或 HTML 输入。候选源只能来自经过认证上传、服务端格式/摘要/尺寸校验并保存在私有 Bucket 的站点级品牌资产。浏览器只接收 `assetId` 和安全预览 URL。

当前随应用提供的 Logo 应迁移为第一项已验证候选，以保证空库初始化后存在可用默认值；它不再是服务端硬编码的唯一来源。

## 4. 草稿、预览与应用

- 保存水印设置先形成不可变草稿 profile，不立即改变公开页面。
- 预览必须由 OSS 按草稿参数生成到私有预览前缀，再通过短时签名 GET 返回；CSS 叠加可以辅助交互，但不能作为验收证据或发布结果。
- 点击“应用并重新生成”后，系统为所有仍需公开的 P0 图片生成当前 profile 的完整 WebP + fallback variant。
- 生成和 HEAD/图片信息/匿名 GET 验证全部完成后，才在一个短 SQLite 事务中切换活动 profile 和公开引用。
- 切换前公开页面继续使用上一活动 profile；任何失败都不能产生同一作品或同一轮播项横竖两侧混用不同 profile 的状态。
- 切换后旧 profile variant 进入精确清理清单；清理失败不回滚已验证的新活动 profile，但必须保留可重试记录。
- 同一配置重复应用应幂等；配置内容变化必须产生新的 profile ID/版本和新的确定性对象 Key。

## 5. 数据与隐私边界

公开 DTO 只返回当前活动 profile 对应的公开 variant URL，不返回：

- 水印源私有 Key；
- 私有签名 URL；
- Logo 原始摘要全文；
- 草稿 profile；
- 内部处理参数或运维错误正文。

管理 DTO 可以返回候选 `assetId`、安全预览、活动/草稿状态、受限参数和资源版本，但不得返回私有 Object Key 或 Bucket 信息。

## 6. 向后兼容

- `brand-standard-v1` 及其四角锚点记录继续作为历史 identity 保留，旧对象不原位覆盖。
- GATE-07 应把当前已发布内容迁移到 `brand-centered-v2`。在原子切换前，旧页面仍可正常读取 v1；切换后公开投影和发布检查只接受活动 v2 profile。
- 现有单图“水印安全角”控件在 v2 下失去业务效力，应从管理界面移除；底层旧字段可以暂时保留用于识别历史 variant，后续迁移不得把它误当成当前配置入口。

## 7. 验收

`GATE-07` 通过至少需要：

1. 管理员上传或选择水印候选，不接触路径或 Key；
2. 默认 profile 为居中、50% 透明度、60% 缩放；
3. 参数边界和不能关闭水印的服务端校验通过；
4. 真实 OSS 预览与最终公开结果一致；
5. 更换 Logo 或参数会生成新 identity 和新 Key；
6. 已发布作品和首页横竖 variant 完整再生成后原子切换；
7. 失败时上一活动 profile 继续可用；
8. 公开 HTML、DTO、日志和错误无私有水印源信息；
9. 三个固定视口下水印达到大尺寸居中效果，且关键角色脸部、作品说明和首页文字仍可辨识；
10. 用户确认视觉结果后，T19 才能开始。
