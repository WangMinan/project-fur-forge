# 规格说明：在线文本维护

## 状态与来源

- 2026-10-11 用户明确授权；基于前一轮代码评审与用户截图。
- 目标：普通文字修正不造成公开内容下线或媒体重新生成。

## 契约

- 已发布作品允许直接保存角色名、物种、画师、价格、领养状态和公开地址；保持发布状态及原发布时间。公开地址沿用现有格式/唯一性检查与旧链接影响提示，不新增跳转。
- 用途的数据库调整沿用业务校验：commission/showcase 可互换；已有领养媒体时不能切到非领养；在线切入领养因需要配置领养媒体，提示先下架处理。
- 作品出厂照、领养封面和设定图的说明可在线保存；只更新当前作品已有图片的文字，不允许借此换图、删图、改焦点或构图。
- 大图替代文字可在 enabled 状态独立保存，包括首页某画幅唯一启用图；启用状态、资源、焦点、顺序和公开图片地址保持。横竖／首页委托四集合独立版本继续有效。
- 继续使用显式保存。已发布内容保存后在下一次公开读取生效；不增加访客页面实时推送。失败保留输入，版本冲突不静默覆盖，任务进行中拒绝相关保存。
- 本需求的在线文字保存不生成发布任务，不调用 OSS/ESA，不清理私有预览。图片资产编辑和删除仍走既有受限接口与下架流程。
- 委托删除弹框仅删除用户指定的 dry-run 脱敏说明句；预检、计数、确认和删除保护保持。
- 根 README 面向 GitHub 访客，介绍产品能力、技术栈、媒体设计、开发验证和文档导航；不承载 Agent 操作规程或过时阶段限制。

## 覆盖关系

- 覆盖需求1 SPEC 中“已发布事实字段先下架”和“大图说明停用后修改”条款；需求3 models 的事实字段只读条款同步失效。
- 覆盖需求10 SPEC 的已启用大图只读说明展示；需求6的构图下架、在线显隐及媒体完整性继续保留。
- 不改变需求13价格/画师公开位置，不扩大公开 DTO 的字段范围。

## 保存接口

| 接口 | 本轮变更 |
| --- | --- |
| `PUT /api/admin/v1/works/:id` | 已发布作品允许原有基础信息 payload，保留用途与唯一性校验。 |
| `PUT /api/admin/v1/works/:id/presentation` | 增加可选 `mediaDescriptions: [{ assetId, alt }]`，仅更新此作品现有图片说明；1–7项、ID不重复、说明去首尾空白后1–500字符。 |
| `PUT /api/admin/v1/site/hero-collections/:placement/:orientation/items/:id` | 增加严格的 `{ alt }` payload；已启用项只能使用此文字分支，包含资产字段的原编辑分支仍拒绝启用项。 |

以上继续携带 `expectedVersion`；作品使用作品版本，大图使用对应集合版本。文字分支不携带资产版本，不改变处理源或派生图身份。

## 验收

- 已发布作品保存、清空文字及变更领养状态后公开数据正确；旧版本、错误字段和跨作品图片说明写入被拒绝。
- 已启用大图保存说明不触发预览清理、发布或停用；最后一张保护和媒体编辑保护仍有效。
- 比较保存前后资产、派生记录、图片地址与发布时间；模拟存储调用不增加。
- 桌面/窄屏真实浏览器验证成功、失败、冲突、刷新还原与图片编辑锁定；使用合成内容，不复制真实申请 PII。
- lint/typecheck、相关 core、build 通过；README 链接和文档覆盖关系一致。
