# T14–T18 前端阻塞修复（2026-08-01）

## 用户确认范围

用户明确授权 Codex 在当前 Kimi 接线分支处理六项阻塞：刷新后图片预览、原生按钮/上传排版、真实发布水印失败、favicon、作品删除、编辑页字号与发布状态横排；随后补充要求隐藏原生 file uploader，分离选择与上传动作。

## 实施结果

- 新增认证管理接口 `GET /api/admin/v1/media/assets/{assetId}/preview`，浏览器只提交 `assetId`，服务端返回 5 分钟短时签名 GET；刷新后两张真实私有原图均完成解码显示。
- 编辑器共享按钮样式提升到管理端全局作用域；文件控件隐藏，改为“选择照片”+ 文件名 +“上传出厂照”的两步控件。
- 真实 OSS 定向重跑两张资产的缺失公开 variant，当前每张均为 12 张，发布检查恢复“可以发布”；未对真实作品执行发布。
- 使用现有 `/brand/logo-full-dark.png` 声明 favicon；正式多尺寸导出仍由 EXT-01/T30 收口。
- 新增只允许未发布作品的版本化删除；先清理公开对象/variant，再删除作品，永久私有原图保留；列表复用现有影响确认对话框。
- 统一页头字号；“发布 / 草稿 / 可以发布”进入同一横排行；真实列表出现删除入口。
