## 实现清单

### T19 作品详情（`app/pages/works/[slug].vue`）

- SSR 消费 `GET /api/public/v1/works/{slug}`，Zod transform 校验公开 DTO。
- 渲染：角色名、物种、套装类型、用途、所有者展示、主图与出厂照图集
  （`WorkDetailGallery` 改吃 DTO media）、作品属性短标签、领养作品的人民币
  价格（`formatCnyMinorUnits`）、「继续浏览」相关作品（`WorkCard` 改吃 DTO）。
- 404/500 走 Nuxt 原生 HTML 错误页：API 错误经 `resolveErrorStatus` 防御性提取
  （FetchError/H3Error/普通对象三种表示），`createError({ fatal: true })` 抛出；
  客户端同组件内切换 slug 时经 `watch(error)` + `showError` 进入同一错误页。
- **useFetch 不设显式 key**：Nuxt 4 中静态 key 会让重挂载的详情页复用旧 slug
  缓存（`status === 'success'` 跳过 initialFetch）；自动 key 含 URL，slug 变化
  即重新拉取，组件复用与重挂载两条路径都覆盖（本轮修复的真实 bug）。
- 领养作品的「设定图/工厂照」只留结构注释位：公开 DTO 不含该类媒体，
  不渲染占位、不造假数据。
- 页面不输出联系方式、私有 Key、签名 URL、草稿对象（有对应 e2e 断言）。

### T19 服务端契约修复（`server/api/public/v1/works/[slug].get.ts`）

- 修复既有 bug：`createApiError(404)` 原先在 `try` 内抛出，被 `asSafeApiError`
  吞成 500，偏离「不存在为 404」契约；改为 try 外抛出。代码偏离契约即 bug，
  此处为契约已锁定、实现错误，未改契约本身。

### T20 作品列表（`app/pages/works/index.vue` 等）

- 真实已发布投影 SSR；人工顺序由服务端投影保证；筛选（用途/套装类型/
  营业状态）经 `WorkFilterBar` + `app/utils/work-filters.ts` 纯函数；
  结果计数、纯链接卡片（3:4）、空态、非法查询参数回落默认。
- 删除 `shared/fixtures/visual-works.ts` 与 `public/fixtures/samples/` 样图，
  列表/详情/精选不再使用任何生产 fixture。

### T20 精选轨道（`app/components/FeaturedWorks.vue` / `FeaturedTrack.vue`）

- SSR 消费 `/api/public/v1/works/featured` 真实精选投影；无精选时整区隐藏。
- 保留 T08 全部交互结论：横向轨道、人工顺序、不自动播放、箭头/键盘/触摸、
  reduced-motion 降级；不与首页轮播合并。
- 删除 `FeaturedWorkItem.vue`（fixture 时代组件），轨道直接渲染 `WorkCard`。

### T20 首页双源轮播（`app/components/HomeHeroCarousel.vue`）

- SSR 消费 `/api/public/v1/home`；首项 SSR 直出且无 JS 可访问。
- `picture/source` 按方向选择独立资产：横屏 16:9、竖屏 9:16；
  隐藏方向的图片不下载（有请求拦截 e2e 断言）。
- 首项 `fetchpriority=high`、后续项懒加载；固定宽高比容器，CLS≈0
  （有布局偏移断言）。
- 上一张/下一张、分页点、键盘方向键、触摸滑动；自动轮播默认关
  （间隔 6–300s，最小 6s），开启时可见暂停按钮、hover/focus 暂停、
  reduced-motion 停止自动播放。
- 轮播文本区避开居中水印安全区；水印图由服务端公开 variant 提供。
- 纯逻辑抽在 `app/utils/hero-carousel.ts`（方向/循环/自动播放状态机）与
  `app/utils/public-sources.ts`（picture source 选择），均有单测；
  `ResponsivePicture.vue` 为双源渲染原语。

### T20 首页管理（`/admin/site/home`）

- `app/composables/useAdminHome.ts`：home 快照为唯一状态基线；设置/轮播项
  CRUD/排序/停用共用 `runHomeMutation`（成功替换快照、409 重载）；
  启用为异步发布操作：返回操作记录后轮询至 DONE/FAILED，按 `failureCode` +
  `failureStage` 给中文反馈，FAILED 可重试；`loadPreview` 调真实活动水印预览。
- `app/composables/useHeroAssetUpload.ts`：单槽位上传状态机
  （digesting/uploading/validating/done/failed），条件直传 + 服务端核验，
  复用 `signed-put.ts`。
- `app/components/admin/HomeHeroSlotField.vue`：横/竖单槽位（prop 名
  `orientation`，避开 Vue 废弃的 `slot` 属性冲突），本地未保存预览 /
  已存资产尺寸 / 进度 / 失败文案。
- `app/components/admin/HomeSlideCard.vue`：轮播项编辑卡（替代文本、顺位、
  关联作品下拉——未发布作品选项禁用、横竖槽位、保存/删除/启停/排序/
  活动水印预览/发布重试）；启用后字段锁定并显示锁定提示；dirty 基线随
  props.slide 正确推进。
- `app/pages/admin/site/home.vue`：设置表单（口号/自动轮播/间隔秒，
  6–300s 本地校验）+ 轮播项列表 + 草稿卡；`layout: admin`、`ssr: false`、
  `noindex`。`settingsBaseline` 初始化为当前快照（此前初始 `''` 与 JSON
  快照永不相等，导致首次加载被误判 dirty、表单不回填——本轮修复）。
- `app/components/AdminShell.vue`：导航新增「首页」→ `/admin/site/home`
  （作品与站点品牌之间），`current` 增加 `'home'`。
- 新端点 `POST /api/admin/v1/site/home/slides/{id}/preview`：返回横 768×432、
  竖 480×853 的活动居中水印真实私有预览（同源短时 URL，5 分钟），
  无活动 profile 时 409；UI 只渲染返回的 URL，DOM 不泄漏私有 Key。
