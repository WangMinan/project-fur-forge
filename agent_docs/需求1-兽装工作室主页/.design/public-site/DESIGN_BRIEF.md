# Design Brief：兽装工作室公开站

> **状态**：阶段 C 已落地并经用户浏览器人工验收；阶段 D 的 `/returns` 与轻量展会掉落方向已经确认。
> **最后校准**：2026-08-07。

## Problem

访客需要在几秒内判断工作室的制作气质与完成能力。他们应先看到兽装作品和真实返图，而不是品牌长文、蓝色营销面板、复杂交易界面或内部运营状态。

媒体形态差异明显：横版领养设定图、竖版出厂照、首页横竖双源 Hero，以及横竖混合的真实返图。它们不能被一个通用“主图”和统一 3:4 裁切吞并。

展会掉落需要让访客看懂“在哪里、什么时候掉落”，但当前业务规模不值得建设独立展会专题、地点地图或活动运营系统。

## Solution

公开站是图片大底与白底结合的编辑型摄影作品集：

- 首页用横竖双源 Hero、精选作品、统一业务入口和当前领养形成主线；
- `/works` 展示标准作品；
- `/adoptions` 展示常规领养与展会掉落；
- `/returns` 作为一级导航独立展示无水印原比例返图瀑布流；
- 作品详情区分设定图和出厂照，不增加返图 Tab；
- 展会掉落复用领养卡和作品详情，只增加类型、展会名称和时间；
- 网站不模拟登记、抽选、报价、支付或社交互动。

## Experience Principles

1. **作品和返图证据高于品牌装饰**：图片能说明的内容不重复写成长文。
2. **正确图片角色高于统一卡片**：设定图、出厂照、返图和 Hero 各自保留合适比例与信息密度。
3. **展示位置决定保护方式**：站点展示和返图无水印，标准作品与所有领养使用活动水印。
4. **标准作品与真实返图分开**：返图不进入出厂照图集，不伪装为工作室棚拍。
5. **轻量掉落高于展会系统**：在领养上下文展示必要展会信息，不另造活动平台。
6. **白底与摄影高于品牌色铺陈**：蓝色只负责识别、行动和焦点。
7. **连续浏览高于组件炫技**：用比例、留白和图片节奏构成体验，不堆统计、毛玻璃或视差。
8. **真实截图高于组件预设**：瀑布流、领养卡和详情必须用真实混合方向图片做三视口评审。
9. **清楚路径高于多重转化**：每页只保留与职责一致的主要行动，未实现能力不显示。

## Aesthetic Direction

- **Philosophy**：Editorial Fursuit Portfolio。
- **Tone**：干净、年轻、亲近、克制，不做高冷奢侈品，也不做企业 SaaS。
- **Canvas**：白色和极浅中性色；作品摄影承担主要色彩。
- **Brand blue**：明显蓝色常态约占 5%–10%，15% 是硬上限而非目标。
- **Brand assets**：完整组合标用于页头；图形标用于 favicon、触控图标和需要水印的作品保护媒体。返图不叠加 Logo。
- **Reference**：借鉴图片第一印象、白底作品浏览、横版设定图和真实返图瀑布流，不复制其他站点的 Logo、字体、卡片或专有构图。

### Anti-references

- 深色赛博朋克、霓虹、毛玻璃、随机渐变和 3D 装饰；
- 连续蓝底区块、蓝色卡片墙和大面积营销面板；
- 标题 + 三张同款功能卡 + 统计数字；
- 把横版设定图强裁成竖卡；
- 用 CSS 临时叠 Logo 代替真实公开衍生图；
- 给返图增加水印、统一强裁或社交时间线；
- 把返图者昵称、主页或授权备注自动公开；
- 建设独立展会首页、专题页、封面或管理入口；
- 在功能未实现时展示返图、展会或回收站空入口。

## Key Interactions

- 首屏第一项存在于服务器 HTML；动效不延迟主图、标题或行动。
- 浏览器只下载与当前方向匹配的一份 Hero 资源。
- 首页轮播提供上一张/下一张、分页、触控和键盘；自动轮播默认关闭，开启时不少于 6 秒并可暂停。
- 精选作品不自动播放；作品卡使用普通链接。
- 委托 Hero 无可用图时隐藏图片区，不借用首页图。
- 作品详情把设定图与出厂照分开；返图不进入作品详情。
- `/returns` 使用底部编号分页（含上一页/下一页），不自动无限滚动，也不以“加载更多”为默认方案；分页是普通链接，换页后焦点落在页面主区。
- 返图项提供清楚的关联作品入口，避免嵌套链接。
- 图片失败时保留比例和可理解占位，不造成大面积坍塌。
- `/adoptions` 筛选是普通链接或等价 SSR 可用控件；展会掉落时间不会触发页面倒计时或自动状态。
- 价格只在适用且有值时显示；无值时删除整个区域。
- `prefers-reduced-motion` 下取消非必要位移、缩放和自动切换。

## `/returns` Direction

- 公开路由固定为 `/returns`；
- 一级导航名为“返图”，顺序为**首页 → 作品展示 → 返图 → 自设委托 → 角色领养 → 关于我们**；
- 页面结构固定为紧凑 `PublicPageIntro` → 原比例瀑布流 → 底部编号分页 → 页脚；
- 不设置大 Hero、搜索框、筛选、统计数字或热门排行；
- 页面以无水印真实返图为最高层级；
- 横图、竖图、方图按原比例 masonry 排列；
- 列数按视口受控变化：≥1280px 四列、768–1279px 三列、340–767px 两列、<340px 单列；
- 列间距手机 12px、平板 16px、桌面 20px；图片圆角约 10–14px；
- 默认无厚边框、无强阴影、无彩色卡片外壳、无渐变叠字；
- caption 位于图片下方约 8px，只显示关联作品名称/链接；
- DOM、键盘和屏幕阅读顺序稳定；
- 图片声明固有宽高，加载前预留空间；
- 只显示关联作品名称或入口等必要信息；
- 不显示独立返图标题、返图者昵称、个人主页、授权记录或拍摄位置；
- 不建设返图详情、搜索、点赞、评论、投稿、推荐算法或用户账户。

## Event Drop Direction

- event_drop 与 regular 共用领养视觉系统；
- 卡片增加小型“展会掉落”标签、展会名称和时间；
- 详情在事实侧栏显示同样字段；
- 首页当前领养可以显示 event_drop；
- 不增加展会 Hero、展会封面、地点图、摊位卡或活动时间线；
- 展会文字过长时受控折行，不遮挡设定图、状态或价格。

## Responsive Behavior

- 390px：Hero 使用竖版；返图使用经真实样本验证的受控列数；领养设定图单列完整显示；展会文字不横向溢出。
- 768px：根据实际方向选择 Hero；返图列数避免过小缩略图和巨大空洞；筛选不依赖 Hover。
- 1440px：Hero 使用横版；作品四列；返图内容宽度和列密度受控；详情媒体与侧栏双列。
- 返图墙必须在三个固定视口使用真实混合方向样本核对。

## Accessibility Baseline

- 语义标题、导航、链接和按钮；
- 轮播、筛选、返图墙编号分页和图集支持键盘与可见焦点；
- 状态不只依赖颜色或动画；
- alt 来自后台；装饰图使用空 alt；
- masonry 不破坏阅读和焦点顺序；
- 触控目标至少接近 44 px；
- 展会标签、名称和时间具有可理解文本，不只靠图标。

## Out of Scope

在线估价、站内委托表单、领养登记、展会抽选、访客账号、订单、支付、评论、多语言、首屏视频、声音、WebGL、暗色主题、自动推荐、公开返图投稿、返图者主页、返图水印、独立展会专题，以及由后台任意上传脚本或替换品牌 Logo。
