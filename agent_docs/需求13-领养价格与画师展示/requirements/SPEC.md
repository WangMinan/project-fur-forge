# 规格说明：领养价格与画师展示

## 状态与资料来源

- 2026-10-09 用户两轮讨论及五张截图；随后明确授权新分支、模板需求目录和编码。
- 规格已确认。继承需求6图片契约、需求7中英切换、需求12目录收录规则。

## 目标与非目标

展示领养作品已填写的价格和设定图画师署名。不增加画师账号、链接、多语言姓名、汇率换算或新的交易能力。

## 契约

| 位置 | 价格 | 画师 |
| --- | --- | --- |
| 首页及其卡片 | 无 | 无 |
| /adoptions 卡片 | 无 | 已填写则显示 |
| /works 目录 | 无 | 无 |
| 领养作品 /works/:slug 详情 | 已填写则显示 | 已填写则显示，信息表第一行 |
| 非领养作品详情 | 无 | 无 |

- 两字段独立显隐，留空隐藏整行且无占位；是否已领养、进入来源、是否显示设定图均不改变字段规则。沿用公开资格和已领养咨询禁用。
- 详情信息表顺序：画师、物种、内容类型、领养状态、价格。
- 横卡左图右信息：角色名和物种在上，署名在查看行动上方；竖卡上图下信息：左侧角色名及署名、右上物种，下方查看行动。署名为普通文字，无按钮边框。长内容允许换行，不遮挡序号或产生横向溢出。
- 2026-10-09验收补充：领养卡片物种仅显示原文，移除横卡/竖卡的前导圆点；后台预览的价格行沿用其他信息行的字体和两列对齐。
- 后台中文界面在领养属性下提供可选“画师”，说明其为绘制设定图的公开署名；保存、回填、预览、未保存提醒均覆盖。最多100字符，去首尾空白，空值归一为未填写；历史作品默认未填写，不猜测图片中的署名。
- 切换为非领养属性时清空领养专属画师字段，遵守原有切换媒体约束。
- 中文标签“画师”“价格”，英文“Artist”“Price”；卡片“画师：{name}”/“Artist: {name}”。姓名不翻译。中文金额如 ¥8,800，英文如 CNY 8,800，保留已填小数精度至分。
- SSR 与语言切换均遵守上述规则，URL、返回来源及当前图片不因切换重置。
- 首页与作品目录接口及 payload 不带画师或价格；领养列表只增加画师，价格仅详情接口投影，不通过 CSS 隐藏。

## 覆盖关系

局部覆盖 [需求7 SPEC §6、§8及AC-07](../../需求7-公开站中英切换/requirements/SPEC.md) 的“所有公开详情无价格”；其首页、目录无价格约束继续有效。新增公开署名字段不改变工作室个人信息匿名化规则，不将署名当作内部个人联系方式。

## 验收标准

- AC-01：新旧作品均可保存/清空画师，非领养拒绝该字段，前向迁移保留原价格与媒体。
- AC-02：价格与画师分别覆盖有/无四种组合，available/adopted 均正确，非领养不展示。
- AC-03：首页、领养列表、作品目录、详情 API/SSR 投影严格符合矩阵。
- AC-04：中英标签、署名、CNY、原文姓名及同页切换正确。
- AC-05：横卡/竖卡、长名称/署名、窄屏、键盘焦点、触控、图片decode及无溢出；无控制台/水合异常。
- AC-06：lint、typecheck、相关core、build与浏览器回归；真实手机、人工审美及生产分别记录，不代签。
