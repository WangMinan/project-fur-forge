# Design Brief：兽装工作室公开站

## Problem

从抖音、二维码、朋友分享或搜索引擎进入的访客，需要在几秒内判断工作室的制作气质与完成能力，并顺畅浏览个位数作品。他们不应先读长篇品牌介绍、理解内部术语或穿过复杂交易界面，才能看到兽装本身；同时又必须能辨认委托、领养、返图、约定和联系路径，避免把展示站误解成可以在线估价、登记或支付的平台。

## Solution

把公开站设计为一个移动端优先、可索引的编辑型摄影作品集：代表作品占据首屏，后续仍以连续图片建立节奏；文字只负责作品识别、真实状态、必要规则和下一步行动。委托与领养各有清楚入口，但不复制商城或 SaaS 的信息密度。每件作品拥有可分享的稳定详情，标准出厂照、领养设定图与真实返图以不同版式承担不同证据职责。

## Experience Principles

1. **作品证据高于自我介绍** —— 图片能说明的内容不重复写成长文；任何装饰、Logo、标题或动效与兽装主体冲突时，先弱化辅助元素。
2. **清楚路径高于多重转化** —— 每个页面只有与当前职责一致的主要行动；委托走邮件、领养走邮件或线下，未实现能力不显示为可点击控件。
3. **连续浏览高于组件炫技** —— 用稳定的图片比例、留白、节奏与轻量反馈支撑浏览，不使用滚动劫持、重型开场、通用卡片墙或无业务意义的视觉效果。

## Aesthetic Direction

- **Philosophy**：白底编辑型摄影作品集（Editorial Fursuit Portfolio）。
- **Tone**：干净、克制、年轻、亲近、轻量，不过度商业化。
- **Reference points**：
  - 渔屋截图 13、57、61–64：全幅摄影第一印象、白底规整作品网格、标准作品与返图墙职责分离。
  - 万物通行截图 01、42–44：全幅作品开屏、编辑感标题和快速扫图的作品浏览。
  - v5：全幅首屏后的内容顺序、图片式委托/领养入口、双筛选、FAQ 和七个公开页面职责。
- **Anti-references**：
  - 赛博朋克深色、黑黄工业风、霓虹、毛玻璃、随机渐变或 3D 装饰；
  - “标题 + 三张同款圆角功能卡 + 统计数字”的通用 SaaS 落地页；
  - 每屏都有大标题、胶囊按钮和视差的 AI 拼装页面；
  - 复制竞品 Logo、摄影、文案、卡片造型或高度可识别的构图；
  - 把 v5 几何 SVG、现有字号与后台弹窗样式直接升级为生产 UI。

## Existing Patterns

- **Typography**：v5 使用中文衬线大标题与系统黑体正文，仅作为层级验证；生产字体需在正式 Logo/作品素材下重新校准，并优先自托管或使用稳定系统字体栈。
- **Colors**：白色主底；`#1D2D5A`、`#293C84`、`#324DAF`、`#6274BB`、`#CED3E5` 组成从深色覆盖到浅色表面的受控蓝色阶。`#6274BB` 与 `#CED3E5` 只作大字号/背景层次，不承担小字号正文。
- **Spacing**：v5 的留白方向可参考，具体尺度由 `DESIGN_TOKENS.md` 重建。
- **Components**：当前无业务源码和可复用 Vue 组件；原型中的 DOM/CSS 不作为生产组件起点。
- **Content**：正式中文名统一使用“有点小狗工作室”，英文暂用 `dite dog` 并从同一站点设置输出。正式 Logo 仍在回执；例图中的狗头闪电不是正式 Logo，不提取、描摹或上线。临时 OC 素材只用于开发期样张，正式验收必须替换为授权作品与正式 Logo。

## Key Interactions

- 首页首屏内容在服务器 HTML 中存在；轻量入场仅增强呈现，不延迟标题、主行动和主图显示。
- 精选作品轨道不自动播放；桌面可点击箭头和键盘操作，触控设备可直接滑动，首尾状态有明确反馈。
- 作品筛选即时取交集并保持后台人工顺序；筛选改变不创建另一套详情 URL。
- 作品卡始终通过普通链接进入 `/works/{slug}`；灯箱只用于详情页内图集浏览，不代替 canonical 页面。
- 图片加载失败时保留比例和可读作品名称，不出现大面积空洞或布局跳动。
- 价格只在适用作品有已发布人民币金额时出现，格式如 `¥15,600`；未录入时删除整个价格区域，不显示零价、“请咨询”或空标签。
- FAQ、移动导航和图集覆盖层管理焦点与关闭行为；关闭后焦点返回触发元素。
- 邮件行动同时支持 `mailto:` 与复制邮箱反馈；不模拟站内提交成功。
- `prefers-reduced-motion` 下取消大幅位移、自动过渡和非必要图片缩放。

## Responsive Behavior

- **390px 基线**：首屏保持全视口；导航折叠；作品网格两列；详情转单列；业务入口上下排列；筛选允许换行但不横向溢出。
- **768px 基线**：平板保持明确图片密度；作品网格可使用三列；菜单和触控目标不依赖 Hover。
- **1440px 基线**：桌面作品网格四列；首页精选横向浏览；内容最大宽度不让文字跨越过长，图片可突破正文容器。
- **1080p / 2K / 4K**：按实际 CSS viewport 校准首屏、导航、详情大图与网格密度；不以物理分辨率直接决定断点。
- 主图和叠加文字分别使用桌面/手机裁切与安全区；不得仅依赖 `object-position: center`。

## Accessibility Requirements

无障碍专项验收不属于一期硬门禁，但生产组件仍采用以下工程基线：

- 语义化标题、导航、链接、按钮和表单；关键动作不绑定到不可聚焦容器。
- 正文和交互文本维持可读对比；图片覆盖文字必须使用受控遮罩并逐图复核。
- 导航、筛选、FAQ、精选轨道和图集支持键盘操作与可见焦点。
- 使用后台 alt 或契约规定的安全回退文本；装饰图明确为空 alt。
- 尊重减少动效设置；不以颜色或动画作为唯一状态表达。
- 不宣称达到完整 WCAG 等级，专项合规留给后续独立范围。

## Out of Scope

- 在线估价、站内委托表单、领养登记、访客账号、订单、付款和评论。
- 多语言页面、委托统一公开价目表、公告/排期页、独立 FAQ、独立展会专题。
- 首屏视频、声音、粒子、WebGL、GSAP 时间线、滚动劫持和深色主题切换。
- 访客画像、个性化推荐、热度排序和自动轮播。
- 正式 Logo、最终摄影选片和法律文本本身；这些必须由工作室提供/确认后进入内容验收。例图中的狗头闪电和景宸个人 QQ 二维码不作为替代品。
