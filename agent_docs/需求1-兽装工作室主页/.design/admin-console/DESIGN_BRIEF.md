# Design Brief：兽装工作室管理端

## Problem

景宸需要在不了解 SQLite、OSS、SEO 和发布边界的情况下维护作品与站点内容。首要风险是误公开私有资料、误删原图、发布不完整媒体，或被一套远超实际业务的 CMS/Dashboard 淹没。

## Solution

把管理端设计为“安静的内容工具”：登录后直接进入作品管理；页面按作品、媒体、营业状态和站点内容等真实对象组织；保存、处理、发布和失败状态持续可见。P0 只显示已实现核心入口，P1/P2 功能实现后再进入导航。

## Experience Principles

1. **发布确定性高于操作速度**：草稿、处理中、READY、已发布、已下架和失败必须清楚区分。
2. **业务对象高于万能 CMS**：用“作品、返图、营业状态、首页内容”等直白名称，不用含义模糊的页面树。
3. **最小上线范围高于功能堆积**：P0 不显示邮件找回、原图档案、导出、统计等 P2 假入口。
4. **私有信息最小暴露**：浏览器以 `assetId` 操作媒体，不展示私有 Object Key；联系人和返图授权记录不进入公开预览。
5. **高频轻操作优先**：PC 完成复杂图片操作；手机完成登录、查看、状态、文字、单图和发布。

## Aesthetic Direction

- **Philosophy**：Quiet Editorial Tool。
- **Tone**：平静、清楚、可靠，不做企业销售化 Dashboard。
- **Canvas**：白色与浅灰工作区；品牌蓝只用于主行动、焦点和当前导航。
- **Color ratio**：管理端不要求公开站的摄影面积，但仍禁止大面积深蓝侧栏或整页蓝色卡片；蓝色应是局部操作色。

### Anti-references

- 默认 Dashboard、KPI、图表、消息中心和动态公告；
- 把公开站的大字、图片叠加和装饰动效搬进后台；
- 用全屏弹窗承载完整作品编辑；
- 超长万能表单、所有控件都胶囊化；
- 用模拟成功 Toast 掩盖 OSS、数据库或发布失败；
- 在 P1/P2 未实现时展示可点击空入口。

## Scope by Phase

### P0 Navigation

- 作品；
- 营业状态；
- 必要站点内容；
- 账号（改密、退出）。

登录后直接进入作品列表，不设置 Dashboard。

### P1 Navigation

- 返图；
- 当前展会；
- 回收站；
- 更完整站点内容。

### P2 Navigation

- 原图档案；
- 完整导出；
- 访问统计；
- 登录页可用的邮件找回入口（不是主导航项）。

P2 未实现前不出现。

## Component Inventory

| Component | Notes |
| --- | --- |
| `AdminLoginPanel` | 用户名/邮箱、密码、错误和锁定；P0 不强制邮件找回 |
| `AdminShell` / `AdminNav` | 无 Dashboard；按阶段只显示已实现入口 |
| `AdminPageHeader` | 页面名、保存状态、预览、发布/下架 |
| `WorkTable` | 作品、用途、发布状态、业务状态、CNY 价格摘要、媒体完整性 |
| `WorkEditor` | 基础信息、联系人、短属性、CNY 价格、图片、预览和发布检查 |
| `PublicationChecklist` | 必填矩阵、媒体 READY、展会关系和公开影响 |
| `MediaUploader` / `UploadItem` | 私有直传、摘要、进度、校验、处理、公开生成和失败 |
| `AssetGrid` / `AssetSorter` | 来源、顺序、主图；浏览器不显示私有 Key |
| `CropFocusEditor` | 按真实用途编辑 3:4、16:9、原比例焦点；不默认生成 1:1 |
| `ReturnEditor` | P1；关联作品、图片、公开元数据和可选授权记录 |
| `BusinessStatusEditor` | 委托与领养分别维护 |
| `SiteContentEditor` | 受限字段，不允许任意 HTML/脚本 |
| `ConfirmImpactDialog` | 下架、删除、改址、永久删除等动作特定说明 |
| `OperationFeedback` | Toast + 页面内持久状态；失败不只用短暂 Toast |

## Key Interactions

- 未认证只渲染登录；P0 密码重置通过受保护命令，不制造无法使用的找回链接。
- 创建作品按小步保存草稿；现有作品使用快速编辑，不强迫重走向导。
- 联系人字段明确标注“仅后台可见”；不提供定金/付款备注字段。
- CNY 价格只在领养/掉落作品出现，清空表示公开端整个价格区域隐藏。
- 返图授权来源、确认时间、备注均为可选，界面标题使用“授权记录（可选）”，不形成发布阻断清单。
- 上传状态按“计算摘要 / 私有上传 / 校验 / 处理 / READY / 公开生成 / 失败”展示。
- 发布不显示“切换 ACL”；应显示“生成并验证公开图片”。
- 手机遇到复杂裁切、批量排序或原图档案时明确提示使用桌面，不提供半成品控件。

## Responsive Behavior

- 桌面 ≥1280px：侧栏 + 主工作区；编辑与预览/发布检查可并列。
- 平板 768–1279px：折叠导航；编辑和预览切换显示。
- 手机约390px：单列；登录、查看、状态、文字、单图上传和发布完整可用。
- 常规编辑使用页面；对话框只处理确认和短流程。

## Accessibility Baseline

- 标签、帮助、错误和字段程序化关联；
- 错误汇总可定位首个问题；
- 表格、菜单、步骤、上传和对话框键盘可达；
- 状态同时使用文字、图标和颜色；
- 主要触控目标至少 44px；
- 减少动效设置得到尊重。

## Out of Scope

订单、支付、排期、合同、客户生命周期、多管理员、RBAC、OAuth、二次验证、自动媒体队列、worker、任意 CMS、公开投稿，以及手机端复杂裁切和批量原图维护。
