# Design Brief：兽装工作室管理端

> **状态**：阶段 C 已落地并经用户浏览器人工验收；阶段 D 首要候选为返图管理。
> **最后校准**：2026-08-07。

## Problem

景宸需要在不了解 SQLite、OSS、SEO 和发布边界的情况下维护作品、首页轮播与站点内容。首要风险是误公开私有资料、误删原图、把横版设定图和竖版出厂照混成一个“主图”、只上传首页一个方向、发布错误保护模式的图片，或被一套远超实际业务的 CMS/Dashboard 淹没。

阶段 D 的返图又带来新的区分：返图不是出厂照，可选授权记录不是公开文案，轻量水印也不能靠 CSS 临时叠加。

## Solution

把管理端设计为“安静的内容工具”：登录后直接进入作品管理；页面按作品、媒体角色、首页与委托 Hero、营业状态、站点内容和品牌水印等真实对象组织；保存、处理、发布、失败和恢复状态持续可见。

阶段 C 已实现：

- 作品、设定图、出厂照和发布管理；
- 首页与委托横竖双源 Hero；
- 无水印站点展示位与有水印作品保护位；
- 文案分区 Card 与独立版本；
- 居中活动水印 profile；
- 真实长任务进度、失败和恢复。

阶段 D 如实施返图墙，新增独立返图入口；不把返图塞进作品出厂照分区，不提前显示展会、回收站或更多内容的空页面。

## Experience Principles

1. **发布确定性高于操作速度**：草稿、处理中、READY、已发布、已下架和失败清楚区分。
2. **媒体角色高于通用上传器**：Hero 横/竖、设定图、出厂照、返图和 Logo 有明确用途与约束。
3. **展示位置高于统一水印开关**：站点展示位最终无水印，作品位使用活动水印；返图使用单独确认的轻量水印。
4. **业务对象高于万能 CMS**：用作品、首页与委托大图、返图、营业状态、文案配置等直白名称，不使用页面树。
5. **最小上线范围高于功能堆积**：只显示已实现入口；邮件找回、原图档案、导出和统计等未实现能力不出现。
6. **私有信息最小暴露**：浏览器以 `assetId` 操作媒体，不展示私有 Object Key；联系人和返图授权记录不进入公开预览。
7. **原图保护高于视觉捷径**：私有原图无水印、不可覆盖；公开预览代表真实衍生结果，不修改原图。
8. **高频轻操作优先**：PC 完成横竖配对、复杂裁切和多图排序；手机完成查看、状态、文字、单图和发布。
9. **长任务进度高于等待猜测**：上传、处理、发布、全站应用、reconcile、清理和恢复持续显示真实阶段与进度。
10. **E2E 页面结果高于通过数量**：测试验证用户实际看到和操作到的页面，不以状态码、元素存在或用例数量自证质量。

## Aesthetic Direction

- **Philosophy**：Quiet Editorial Tool。
- **Tone**：平静、清楚、可靠，不做企业销售化 Dashboard。
- **Canvas**：白色与浅灰工作区；品牌蓝只用于主行动、焦点和当前导航。
- **Color ratio**：禁止大面积深蓝侧栏或整页蓝色卡片；蓝色是局部操作色。
- **Media previews**：预览区用中性棋盘或浅灰安全画布区分完整 contain 和裁切 cover，并显示真实公开保护结果。

### Anti-references

- 默认 Dashboard、KPI、图表、消息中心和动态公告；
- 把公开站的大字、图片叠加和装饰动效搬进后台；
- 用全屏弹窗承载完整作品或返图编辑；
- 超长万能表单、所有控件都胶囊化；
- 把所有媒体塞进一个“图片”区；
- 用一个焦点控件声称已经完成首页横版/竖版适配；
- 用 CSS 预览水印却发布无对应衍生文件；
- 用模拟成功 Toast 掩盖 OSS、数据库或发布失败；
- 在功能未实现时展示可点击空入口；
- 把返图授权记录当作公开来源文字自动展示。

## Navigation by Phase

### Current Navigation

- 作品；
- 首页与委托大图；
- 文案配置；
- 品牌水印；
- 账户。

登录后直接进入作品列表，不设置 Dashboard。

### Stage D Navigation

T35–T36 完成后增加：

- 返图。

只有对应任务被用户保留并实现后，才能再增加：

- 当前展会；
- 回收站；
- 更多站点内容维护。

Slug 改址历史属于作品动作，不作为一级导航。

### Stage E Navigation

原图档案、完整导出和访问统计只在对应功能实现后出现。邮件找回是登录页能力，不是主导航项。

## Key Interactions

- 未认证只渲染登录；当前密码重置通过受保护命令，不制造无法使用的找回链接。
- 创建作品按小步保存草稿；现有作品使用快速编辑，不强迫重走向导。
- 联系人字段明确标注“仅后台可见”；不提供定金或付款备注字段。
- CNY 价格只在领养/掉落作品出现，清空表示公开端整个价格区域隐藏。
- 选择领养用途后出现独立设定图区，出厂照保持另一分区。
- 出厂照控件使用统一按钮、文件名提示和独立上传状态；刷新后通过 `assetId` 短时预览继续显示私有原图。
- 摘要、PUT 百分比和服务端校验状态显示在当前上传项附近。
- 页面有未保存修改时，发布流程先保存、重读发布待办，再决定是否继续；不让管理员在顶部和媒体分区之间反复找按钮。
- 未发布作品删除确认说明公开衍生清理、私有原图边界、已发布作品需先下架和不可撤销范围。
- 作品列表支持角色名/物种查找，并按用途、装型和发布状态筛选；筛选变化回到第一页。
- Hero 每项同时显示横版和竖版槽位；缺失任一方向、alt 或 READY variant 时阻止启用。
- 横版低于 `1920×1080`、竖版低于 `1080×1920` 时允许保存，但用持久提示说明放大会损失清晰度；确认后显示真实 FFmpeg 适配 operation。
- Hero 预览使用实际 `<picture>` 和无水印站点展示结果；不再显示作品活动水印，也不提供每图四角水印锚点。
- 品牌水印预览使用固定居中活动 profile；profile 影响摘要明确排除 Hero 和业务入口。
- 返图授权来源、确认时间和备注为可选候选字段，标题使用“授权记录（仅后台可见）”；是否阻断发布以最终 SPEC 为准。
- 返图不进入作品图集假装出厂照；作品编辑页只显示关联返图摘要和跳转。
- 上传状态按“计算摘要 / 私有上传 / 校验 / 处理 / 公开生成 / READY / 失败”展示。
- 发布不显示“切换 ACL”，而显示“生成并验证公开图片”。
- 发布期间显示真实完成量/总量；总量未知时使用不定进度，刷新后通过 operation ID 恢复。
- 手机遇到复杂横竖配对、批量排序或多图焦点编辑时明确提示使用桌面，不提供半成品控件。

## Stage D Return Management

返图入口实现后：

- 列表支持作品、状态和文本筛选；
- 编辑页分为关联作品、公开内容、返图图片、授权记录、预览与发布、危险操作；
- 图片明确标为返图，不使用出厂照组件标题；
- 私有原图与轻量水印公开预览并列时有清楚标识；
- 授权记录不进入公开预览、复制文本或浏览器日志；
- 发布、下架、失败、刷新和重启后仍显示服务端真实状态；
- T40 未确认前，不假设返图已经有通用 30 天回收站。

## Responsive Behavior

- 桌面 ≥1280px：侧栏 + 主工作区；编辑与预览/发布检查可以并列；Hero 横竖预览并列。
- 平板 768–1279px：折叠导航；编辑和预览切换显示；横竖槽位上下排列但角色标题始终可见。
- 手机约390px：单列；登录、查看、状态、文字、单图上传和发布完整可用；复杂横竖配对、批量排序和多图焦点给出桌面提示。
- 常规编辑使用页面；对话框只处理确认和短流程。

## Accessibility Baseline

- 标签、帮助、错误和字段程序化关联；
- 横版/竖版、设定图/出厂照/返图不能只靠缩略图比例区分，必须有文字标签；
- 错误汇总可定位首个问题；
- 表格、菜单、步骤、上传、排序和对话框键盘可达；
- 状态同时使用文字、图标和颜色；
- 主要触控目标至少 44px；
- 减少动效设置得到尊重；
- 授权记录的“私有”状态不能只用颜色表达。

## Out of Scope

订单、支付、排期、合同、客户生命周期、多管理员、RBAC、OAuth、二次验证、自动媒体队列、worker、任意 CMS、公开投稿、由管理员上传脚本/任意 Logo，以及手机端复杂裁切、横竖批量配对和批量原图维护。
