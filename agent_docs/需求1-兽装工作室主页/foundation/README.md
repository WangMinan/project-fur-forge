# 兽装工作室主页 · 产品地基

> **角色**：定义长期稳定的产品目标、用户、范围和不可突破的边界。当前阶段和任务状态见 [`../STATE.md`](../STATE.md)。
> **最后校准**：2026-08-07。

## 1. 产品目标

为“有点小狗工作室”建设一个以兽装图片为主体的公开主页和轻量管理后台。

公开站服务于四件事：

1. 让访客连续、清晰地浏览标准作品；
2. 让访客理解自设委托、常规领养和展会掉落的当前状态与基本方式；
3. 通过独立 `/returns` 返图墙展示作品交付后的真实使用照片；
4. 让工作室能够维护作品、返图、首页展示、业务状态、固定文案和品牌媒体，而不依赖开发人员逐次改代码。

管理后台面向单一工作室管理员，不追求通用 CMS、多人协作平台、展会运营平台或交易系统。

## 2. 核心设计原则

景宸确认的长期原则保持不变：

> **网站要简洁，以图片为主；Logo、文字介绍和符号都只为兽装展示提供辅助。**

据此形成以下约束：

- 兽装图片始终是公开页的最高视觉层级；
- 标准作品与用户返图分开呈现，各自回答“制作质量”和“真实使用效果”；
- 文字只说明图片不能表达的事实、状态和行动方式；
- 不使用复杂装饰、密集卡片和过度动效抢夺注意力；
- 首页、列表、详情、委托、领养和返图墙使用同一视觉语言；
- 管理端强调清晰、可恢复和低误操作，不模仿公开站的摄影排版；
- 所有公开业务文案便于非技术人员理解，不出现内部任务号和中英混杂术语。

## 3. 用户与访问面

### 3.1 公开访客

公开访客可以：

- 浏览首页代表作品和精选作品；
- 浏览作品列表并按用途、装型筛选；
- 查看作品详情、设定图、出厂照、属性和公开价格；
- 浏览常规领养与展会掉落；
- 查看展会掉落的展会名称和时间；
- 在独立 `/returns` 浏览无水印原比例返图；
- 从返图进入关联作品详情；
- 查看委托范围、人工估价方式、营业状态、关于、服务条款、隐私政策和官方联系方式。

公开访客不能：

- 访问原图、私有处理源、后台预览或 Logo 私有源；
- 查看角色主人私密联系方式或返图授权记录；
- 上传返图、发表评论、点赞或建立访客账户；
- 在线登记委托、领养、展会抽选、支付定金、付款或自动获取报价；
- 修改站点内容。

### 3.2 唯一管理员

唯一管理员可以：

- 创建、编辑、发布、下架和按当前规则删除作品；
- 管理设定图、出厂照、排序、主图和公开属性；
- 通过现有作品编辑器维护常规领养与轻量展会掉落；
- 管理一图一记录的返图、无水印公开预览和可选私有授权记录；
- 管理首页与委托页大图；
- 管理委托、领养营业状态和现有固定文案；
- 管理水印 Logo 候选和活动作品水印 profile；
- 查看长任务进度、失败原因和恢复入口；
- 修改密码并通过离线命令重置密码；
- 执行备份、恢复和部署维护。

管理员不能通过后台任意编辑数据库字段、输入任意 Object Key、上传脚本、建设任意页面、绕过媒体角色约束或把私有授权记录公开。

## 4. 阶段 C 范围

阶段 C 是可维护、可恢复的核心产品能力，包含：

- Nuxt 公开 SSR 与管理端 CSR；
- 公开 Host 和管理 Host 隔离；
- SQLite/Drizzle 与版本化迁移；
- 唯一管理员认证、Session、Origin、CSRF、限流和日志脱敏；
- 双 OSS Bucket：私有原图与公开衍生图分离；
- 作品、常规领养、首页、委托、关于、政策页和固定文案；
- 角色化媒体上传、服务端核验、公开派生、发布、下架和清理；
- 可配置活动作品水印 profile；
- 备份、验证恢复、迁移和管理员初始化能力；
- Node 24 镜像、Compose/Nginx 配置、健康检查和 CI 骨架；
- 三视口真实浏览器与用户人工验收。

阶段 C 已于 2026-08-07 经用户浏览器人工验收完成。阶段完成允许继续产品开发，但不自动代表正式环境已经达到发布条件。

## 5. 阶段 D 范围

阶段 D 已确认，只包含：

### 5.1 返图墙

- 一张返图对应一条记录；
- 必须关联已有作品和 `return_photo` 私有原图；
- 可选授权来源、确认时间和备注仅后台可见；
- 公开图通过独立无水印配方预生成、验证并去除不需要的 EXIF；
- 公开站增加一级导航 `/returns`；
- 页面采用原比例 masonry/瀑布流；
- 不在作品详情建设返图 Tab；
- 不建设返图者主页、返图详情、点赞、评论、公开投稿或社交时间线。

### 5.2 轻量展会掉落

- 继续作为领养的一种方式：`purpose=adoption`、`adoption_method=event_drop`；
- 只增加展会名称和展会时间展示文本；
- 复用现有领养状态、价格、设定图、出厂照、水印、发布和下架；
- `/adoptions`、首页和统一详情展示展会信息；
- 不建设独立展会表、展会管理页、展会详情、地点、摊位或归档；
- 展会时间不自动驱动业务状态。

### 5.3 已裁剪范围

- 不扩张更多站点文字内容；
- 当前版本不做 slug 改址历史，未来与分享形态统一讨论；
- 不建设 30 天回收站；
- 手机轻量维护并入返图和掉落任务，不建设通用手机后台项目。

阶段 D 不得削弱阶段 C 的私有/公开 Bucket、媒体身份、版本冲突、发布原子性和恢复能力，也不得为取消项预建万能框架。

## 6. 阶段 E 与正式发布

阶段 E 可以按实际价值选择：

- 邮件找回密码；
- 安全 CSV 导出；
- 永久原图档案 UI；
- 最小化访问统计；
- 高级媒体恢复和批量运维；
- CDN 专项优化。

阶段 E 同时承担上线前发布收口：

- 修复 GitHub Actions 当前 Production build 失败；
- 取得 `checks`、`image-build`、`e2e` 同一 SHA 全绿；
- 完成上线前综合审查与最终浏览器复核。

正式环境阶段还需完成域名、TLS、线上 Compose、空卷初始化、备份、监控、升级、回滚、恢复演练和景宸真实使用验收。

## 7. 明确不做

当前可预见范围内不建设：

- 在线支付、定金、退款和结算；
- 自动报价；
- 委托排期与订单流转；
- 用户注册、访客账户、公开投稿和社交互动；
- 多工作室、多租户和角色权限矩阵；
- 任意页面搭建器或万能富文本 CMS；
- 独立展会运营系统；
- 全站通用回收站；
- 公开原图下载；
- 依赖客户端查询参数临时加工图片的媒体方案。

## 8. 数据与隐私边界

- 公开 DTO 只包含公开展示所需字段；
- `ownerContact`、返图授权记录、私有 Object Key、签名 URL、原文件名、敏感 EXIF、AK/SK、Session 和内部错误不得进入公开响应；
- 公开价格只使用人民币最小单位存储，网站不执行交易；
- 官方联系方式由管理员维护，并明确官方渠道和防诈骗边界；
- 管理响应、预览和错误页使用 `no-store`；
- 日志只记录必要的请求、任务和错误分类，敏感值统一脱敏。

## 9. 媒体边界

- 原图和处理源永久私有；
- 公开页只消费预生成、验证完成的衍生图；
- 首页与委托 Hero、首页业务入口无水印；
- 作品、常规领养和展会掉落使用活动作品水印；
- `/returns` 返图使用独立无水印公开变体；
- 活动水印 profile 切换不得影响站点展示位和返图；
- 公开图片身份不可变，配置变化生成新对象；
- 发布、profile 切换和清理失败不得破坏当前公开版本；
- 首页业务入口使用独立派生用途，不直接复用其他页面 URL。

详细矩阵、迁移和验收只在媒体策略中维护。

## 10. 技术基线

- Nuxt 4、Vue 3、Nitro Node Server；
- Node.js 24、pnpm 11；
- TypeScript strict、Zod；
- SQLite、Drizzle；
- 阿里云 OSS 双 Bucket；
- FFmpeg 仅用于必要私有预处理或经确认的大图适配；
- Docker Compose 与 Nginx 作为正式部署入口；
- Playwright、Vitest 和 GitHub Actions 作为质量门禁。

技术方案和顺序见 [`../planning/PLAN.md`](../planning/PLAN.md)。未来候选见 [`../planning/FUTURE-ITERATIONS.md`](../planning/FUTURE-ITERATIONS.md)，后者不是实施授权。

## 11. 完成定义分层

### 11.1 产品阶段完成

某一产品阶段完成，至少要求：

- 该阶段最终保留的业务范围已经实现；
- 数据、媒体、安全、失败和恢复边界有证据；
- 相关自动化与真实浏览器检查完成；
- 用户完成该阶段业务和视觉验收；
- 当前活文档与代码进展一致。

用户明确取消的候选任务不应继续充当阶段阻断项。

### 11.2 正式发布就绪

正式上线还必须满足：

- GitHub Actions 核心门禁在同一最新 SHA 全绿；
- 空数据卷能够迁移、初始化并进入 ready；
- Compose、Nginx、数据卷、备份、升级和回滚有版本化配置与演练记录；
- 正式域名、TLS、安全头、监控和恢复路径完成；
- 三固定视口在正式素材和目标环境下无坏图、异常裁切和横向溢出；
- 景宸完成真实使用验收。

阶段 C 已完成，阶段 D 可以实施；但 T49、T50、T52、T53 关闭前不得宣布正式发布就绪。
