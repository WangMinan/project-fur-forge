## 自检重点与后续独立评审范围

- 语言初始化只采用一个权威结果，SSR 不闪回中文或水合变英文；非法 Cookie 不成为支持语言。
- 管理登录复用 PublicHeader/PublicFooter；公开错误页也使用 brandOnly，不能仅凭该属性决定语言。语言资源可能与管理 Host 白名单冲突，需实跑。
- `server/error.ts` 的内部错误请求目前未带语言，需最小化传递，避免英文错误页漏改。
- 首页第三幕和委托底部均是独立申请入口；X 分流需覆盖全部调用方。
- 表单语言切换不能丢失输入/文件/回执，也不能在英文视图继续触发上传或提交。
- 中文后台文章与英文静态文案需要事实校对；不能把状态自定义 label 当作已翻译，不能虚构工作室信息。
- 停止公开价格需要检查 DTO/SSR/payload 和元信息，不能只隐藏 DOM；图片或文章自带价格单独人工检查。
- sitemap 复用公开资格，避免把草稿/下架或仅内部存在的作品放进搜索索引；分页 canonical 与实际数据页一致。
