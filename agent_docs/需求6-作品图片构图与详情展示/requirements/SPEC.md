## 目标

1. 每张详情缩略图可单独框住头部或其他主体，大图仍完整。
2. 同一素材用于不同公开位置时独立构图，后台预览与正式结果一致，不因设备变化再次裁切。
3. 管理员可明确指定领养封面来源，并独立决定横版封面、设定图是否进入详情。
4. 历史作品继续可用；新能力通过管理员主动操作逐件启用。

## 非目标

不改变页面排版、栏目、画框比例或断点；不新增通用媒体库、任意选封面照片、详情自由排序、滤镜、旋转、翻转、抠图、标注。Hero 与委托页大图、私有委托附件不在本轮。后台识别/上传预览不新增独立裁切用途；可复用已有构图预览，不要求上传前先配置构图。不自动批量生成、重裁、清理存量公开图，不执行生产发布。

## 契约

### 1. 用途与显示

所有比例为宽:高。配置属于素材与用途，不属于屏幕尺寸；不同用途互不联动。

| 用途 | 画框 | 构图模式 |
| --- | --- | --- |
| 详情缩略图 | 各端 1:1 | 每张图片独立方形选区；无手动配置时提供默认构图 |
| 作品目录 | 各端 4:5 | 固定 4:5 选区，或完整显示允许留白；默认延续摄影填框/领养兜底完整显示的语义 |
| 首页代表作品 | 各端 3:4 | 固定 3:4 选区，或完整显示允许留白 |
| 领养目录 | 手机 16:9，平板/PC 不固定 | 默认完整显示，可独立自由裁切，选区始终完整展示 |
| 首页当前领养 | 各端不固定 | 默认完整显示，可独立自由裁切，与领养目录互不覆盖 |
| 详情大图 | 不统一 | 保留完整源图内容，独立于其他用途的选区 |

- 出厂照、横版封面、公开设定图进入详情时均可配置自己的 1:1 缩略图。
- 目录与代表作品沿用当前主图/可用出厂照选择和资格规则；本需求不增加这两处任意选图功能。无出厂照时作品目录仍优先横版封面，再回落设定图。
- 移动端缩略图须消除 min-height 与响应式宽度冲突，触控目标仍不小于 44×44 CSS px。
- 手动裁切结果须匹配固定画框；完整显示/自由裁切结果通过 contain 展示。不得仅靠横竖方向猜测显示模式。
- 不得从旧 16:9 封面或 3:4 卡片再裁新用途。新模式的横版封面详情须使用完整源图派生。
- 静止与 hover 终态不截断已确认选区；检查首页领养的放大/旋转，必要时局部约束，不重做轮播动效。
- 每张图片无需逐用途强制人工操作；未配置用途有明确默认值，当前有效构图和显示模式可预览。

### 2. 领养封面来源

作品级“领养封面来源”取值为自动、使用横版封面、使用设定图，默认自动。

- 自动：优先可用设定图，没有时使用横版封面。
- 指定来源共同控制领养目录与首页当前领养；这两处构图仍各自独立。
- 不改变作品目录的既有出厂照与缺图兜底顺序，不改变首页代表作品资格。
- 指定不存在、未就绪或无完整公开输出的来源不能在线生效；未发布作品以发布前生成验证为准。
- 删除/替换被指定使用的素材时，必须使来源在同次有效编辑或先行来源更新后仍成立；不静默替换为另一角色。
- 切换来源加载目标素材已有构图，无配置则默认；切回后原构图仍在。来源不改写素材角色。
- 在线更新只切换已有合格公开来源，不自行启动像素重建。

### 3. 详情显隐与初始选图

两个作品级偏好为“在详情图集中显示领养横版封面”“在详情图集中显示设定图”，默认都开启；替换素材不重置偏好。

| 有可用出厂照时 | 图库 |
| --- | --- |
| 两项关闭 | 仅出厂照 |
| 仅横版封面开启 | 出厂照＋横版封面 |
| 仅设定图开启 | 出厂照＋设定图 |
| 两项开启 | 出厂照＋横版封面＋设定图 |

- 维持出厂照顺序，然后横版封面、设定图；按资产身份去重，保持真实角色。图库最多七张，出厂照仍最多五张。
- 没有出厂照时，至少保留一张实际存在、可公开展示的附加图。在线隐藏最后一张须失败；草稿可以暂未上传图片，但不能保存会移除已有最后一张可展示图的操作，且发布必须检查图库非空。
- 移除最后一张出厂照时若导致空图库，提示先开启附加图或添加可用图片并阻止该次保存；不悄悄重新开启偏好。
- 已发布状态按实际完整 READY 输出判断，不能只按上传记录数判断；未发布状态结合源图 READY、显示偏好与发布时的成套输出校验。
- 从领养入口进入时优先选当前封面来源对应的可见图片；若被隐藏则选可见主出厂照，再回落最终图库第一张。其他入口优先可见主图，再第一张。
- 显隐只作用于详情投影，不改变卡片选图、公开资产状态、原图、公开文件或领养身份/价格/状态。
- 运行时缺图可显示既有媒体失败/空态并记录脱敏错误；不能通过复活隐藏图片掩盖正常流程校验缺失。

### 4. 管理交互与保存

- 现有作品编辑页增加对应用途入口、封面来源和两个详情开关，不新建管理中心。
- 编辑器显示完整原图构图与目标用途预览；支持移动/调整选区大小、保存还原、取消、仅重置当前用途。固定用途锁比例，自由用途不锁比例。
- 作品目录预览包含实际名称/渐变覆盖，避免主体虽未裁掉却被文字挡住。
- 编辑器“应用”写入页面编辑状态，页面保存才持久化；未保存离开提示覆盖构图字段。
- 选区清晰度按原图实际选区像素提示；防止越界、空区域和不受限放大，不把低分辨率旧素材一律变成无法发布。
- 显示设置可在线更新，沿用乐观版本与发布操作冲突检查，不改变领养排序时间。
- 像素构图沿用下架后编辑、重新发布；未发布时显示“构图已保存，重新发布后生效”，在线显隐保存显示“详情展示设置已更新”。

### 5. 接口、数据模型与存储契约

- 管理接口以 expectedVersion 与严格 payload 校验保存作品偏好和用途配置；旧调用省略新增字段时保留已有配置，不将遗漏解释为清空。
- 显隐、来源与构图是独立字段；归一化矩形以方向统一的完整源图为基准，必须可确定性还原。
- 公开媒体分别提供完整 sources、缩略图来源、对应用途来源与显示模式，不暴露私有位置或构图编辑凭据。
- 同一图片的排序、说明和主图修改保留全部用途配置；替换成新资产不继承旧资产坐标。重置仅影响指定用途。
- 原图不可变，新像素对应新身份、新 Key。成套输出与发布状态必须一致，失败不能切换到半套图片。
- 具体字段映射与兼容规则见 [models](../models/README.md)；不改变原有公开业务字段和权限边界。

### 6. 存量与覆盖关系

- 旧已发布作品不因数据库迁移、页面加载或显示设置保存而换图。
- 新作品使用新模式；旧作品主动保存新构图后，在重新发布时逐件启用。单纯修改说明、排序、来源或显隐不触发构图版本升级。
- 未启用的新用途可回退旧完整来源；不得因为没有新缩略图或 4:5 输出让旧作品消失。旧文件比例差异仅作为兼容状态，不作为新模式达标结果。
- 本需求覆盖旧“详情必追加封面/设定图”、作品目录与代表作品共用单一卡片输出、只有焦点可调等明确条款；页面布局、素材发布资格、私有访问、退役与部署规则不变。
- 本需求已在任务分支实现；本地实现不代表生产环境已生效，提交、人工验收和部署状态看 STATE。
