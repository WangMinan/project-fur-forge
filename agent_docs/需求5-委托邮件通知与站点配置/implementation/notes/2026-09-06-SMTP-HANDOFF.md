## Regression Risks

- 删除动作先持久化发送屏障，避免跨进程邮件读取正在删除的数据；如果删除中途失败，屏障继续保留，需按既有流程重入删除，不自动恢复发信。
- 发送中的连接通过领取心跳防止被第二个 runner 接管；库的 socket 超时处理网络空闲，不用提前返回但连接继续发送的假取消。
- SMTP 账号和授权码变更后必须重启对应进程/重建容器；后台只维护收件人，不提供秘密编辑入口。
- 领取过期可能意味着 SMTP 已接受但本地未落库，因此恢复可能产生相同编号邮件；成功行不会被普通重试再次发送。
