# Information Architecture：兽装工作室管理端

## Site Map

后台使用独立 Host。生产后台 Host 的 `/` 重定向到 `/admin/login`。

- 登录 `/admin/login`
- 找回密码 `/admin/forgot-password`
- 重设密码 `/admin/reset-password`
- 作品管理 `/admin/works`
  - 新建作品 `/admin/works/new`
  - 编辑作品 `/admin/works/{id}`
- 返图管理 `/admin/returns`
- 营业状态 `/admin/business-statuses`
- 当前展会 `/admin/events`
- 首页内容 `/admin/site/home`
- 委托说明与 FAQ `/admin/site/commission`
- 关于我们与基本约定 `/admin/site/about`
- 联系与站点 SEO `/admin/site/contact`
- 回收站 `/admin/trash`
- 永久原图档案 `/admin/original-archive`
- 完整导出 `/admin/exports`
- 账号安全 `/admin/account`
- 草稿预览 `/preview/{resource}/{id}`（受认证、noindex，不属于后台主导航）

一期不设置 `/admin/dashboard`、公告、订单、客户、排期、支付或多账号页面。

## Navigation Model

- **Primary navigation**：作品、返图、营业状态、站点内容、数据与恢复。
- **Secondary navigation**：
  - 站点内容：主页、委托说明与 FAQ、关于与约定、联系与 SEO；
  - 数据与恢复：回收站、原图档案、完整导出。
- **Utility navigation**：账号安全、退出登录；不显示虚构消息中心或帮助工单。
- **Landing**：登录成功进入 `/admin/works`，不建设数据看板。
- **Mobile navigation**：优先作品、返图、营业状态、站点内容、账号五个入口；低频桌面功能通过“更多”说明可用范围。

## Content Hierarchy

### 登录

1. 明确后台身份。
2. 用户名/邮箱与密码。
3. 登录错误或锁定剩余时间。
4. 找回密码。
5. 不展示任何作品缩略图、状态或后台导航。

### 作品管理

1. 新建作品行动。
2. 作品列表、用途、发布状态、适用业务状态、媒体完整性。
3. 快速编辑、预览、发布/下架。
4. 人工顺序和首页精选。
5. 列表可显示领养/掉落作品的人民币价格摘要，并明确“发布后公开”；委托统一价不在本页维护。

### 新建作品

1. 基础信息、用途、适用状态、0–8 条有序作品短属性，以及领养/掉落作品可选人民币价格。
2. 按用途上传出厂照或领养设定图。
3. 主图、焦点和 3:4/16:9/1:1 裁切。
4. 公开预览、发布检查和保存草稿。

### 编辑作品

1. 当前发布状态、保存状态和主要动作。
2. 基础信息、业务字段、有序作品短属性与适用人民币价格；价格控件提示其公开影响，清空表示公开端整区隐藏。
3. 图片来源分组、排序、主图、处理状态。
4. 当前展会、领养资料和首页精选。
5. SEO、预览、显式 slug 改址。

### 返图管理

1. 关联已有作品。
2. 返图上传和处理状态。
3. 可选昵称、日期、主页。
4. 排序、预览和发布。
5. 不增加授权证明字段。

### 营业状态

1. 委托营业状态。
2. 领养营业状态。
3. 各自公开文案与预览。
4. 发布后即时可见确认。

### 站点内容

1. 当前对象的公开预览。
2. 受限字段与内容完整性。
3. 保存草稿、预览、发布。
4. FAQ 支持人工顺序和发布状态；不允许任意脚本/HTML。

### 回收站与原图档案

1. 对象、删除时间和剩余天数。
2. 恢复。
3. 到期语义与原图去向。
4. 原图档案检索、下载、重新关联。
5. 永久删除只允许三类原因并二次确认。

### 完整导出

1. 业务 CSV。
2. 图片清单 CSV。
3. 原图复选下载入口。
4. 导出边界说明：无图片二进制、凭据、Object Key 和校验值。

## User Flows

### 首次初始化后登录

1. 用户通过受保护命令初始化唯一管理员。
2. 打开后台 Host，进入 `/admin/login`。
3. 输入用户名/邮箱和密码。
4. 登录成功进入作品管理；失败按统一错误或锁定状态反馈。

### 新建并发布非领养作品

1. 从作品管理选择“新建作品”。
2. 填写角色名、物种、装型、角色主人展示值和用途。
3. 上传至少一张出厂照并等待 READY。
4. 选择主图、焦点和裁切，预览公开效果。
5. 发布检查通过后发布。
6. 新访客会话打开 `/works/{slug}`，看到公开内容和衍生图。

### 新建并发布领养作品

1. 新建作品并选择领养用途。
2. 维护领养方式、业务状态、必要展会、该作品短属性和可选人民币价格。
3. 上传唯一设定图，生成水印网页衍生组。
4. 选择水印设定图作为主图，预览。
5. “展会出售中”无当前展会时阻止发布；补齐后发布。
6. `/adoptions` 卡片进入 `/works/{slug}`。

### 上传返图

1. 进入返图管理并选择已有作品。
2. 上传一张或多张返图，查看进度和处理状态。
3. 可选填写昵称、日期和主页，调整顺序。
4. 发布后在 `/returns` 展示；失败项保持可读并允许手动重试。

### 修改并下架

1. 进入现有作品快速编辑。
2. 修改文字、状态、展会、精选或媒体。
3. 预览并发布更新；旧公开图片保留到新衍生组 READY。
4. 选择下架时确认公开正文和网页衍生图将撤销匿名访问。
5. 公开页和 Sitemap 移除内容。

### 失败恢复

1. 上传/处理/ACL 操作失败。
2. 页面保留失败阶段、错误码和受影响对象，不只弹出短暂 Toast。
3. 管理员检查并手动重试或重新上传。
4. 重新上传创建新会话与新 Object Key；旧已发布图片在新组 READY 前继续可用。

## Naming Conventions

| Concept | Label in UI | Notes |
| --- | --- | --- |
| Publication state | 草稿 / 已发布 / 已下架 | READY 不是发布状态 |
| Media state | 待上传 / 上传中 / 校验中 / 处理中 / READY / 失败 | 显示真实阶段 |
| Existing work edit | 编辑作品 | 不称“重新创建” |
| New work flow | 新建作品 | 四步门禁 |
| Site content | 首页内容 / 委托说明与 FAQ / 关于与基本约定 / 联系与 SEO | 不使用含糊“页面内容”总括 |
| Original archive | 永久原图档案 | 与回收站和公开媒体分开 |
| Retry | 重试处理 / 重新上传 | 两者语义不同；重新上传产生新 Key |
| Publish check | 发布检查 | 不称“审核流” |
| Work feature | 作品属性 | 0–8 条有序短标签，只描述当前作品 |
| Public RMB price | 公开人民币价格 | 只用于领养/掉落作品；清空后公开端整区隐藏 |

## Component Reuse Map

| Component | Used on | Behavior differences |
| --- | --- | --- |
| `AdminShell` | 所有认证后页面 | 桌面侧栏、平板抽屉、手机轻量导航 |
| `AdminPageHeader` | 所有管理页 | 动作按对象变化；发布页显示保存/预览/发布 |
| `PublicationChecklist` | 作品、返图、站点内容 | 校验规则按对象不同 |
| `MediaUploader` | 作品、返图 | 数量上限和图片来源由入口锁定 |
| `ConfirmImpactDialog` | 下架、删除、改址、重开、永久删除 | 必须使用动作特定文案，不能复用模糊“确定吗” |
| `OperationFeedback` | 所有写操作 | 成功可短暂，失败与未完成状态必须持久可见 |

## Content Growth Plan

- 作品与返图列表预留分页接口和筛选位置，当前个位数内容不引入虚拟列表或复杂搜索。
- FAQ 和首页精选支持人工排序，数量保持受限。
- 永久原图档案会持续增长，需从一期开始支持检索与分页边界。
- 管理端不随着站点内容增长演进为任意页面树；新增内容对象先回到 SPEC/PLAN。

## URL Strategy

- 后台路由统一在 `/admin/**`，管理 API 统一在 `/api/admin/v1/**`。
- `/preview/**` 只供认证管理员使用并强制 noindex。
- 路由参数使用稳定数据库 ID，不把敏感资料、Object Key 或作品标题直接放入管理 URL。
- 公开 Host 不转发后台、管理 API 或预览路径；应用内 Host 校验重复执行同一边界。
