# T46-F8 · 代表作品标题、留白与详情切换修正

## 最终口径

- “代表作品 / 自设委托 / 设定领养”复用同一左上标题 CSS；代表作品标题不再占用右侧说明栏。
- 代表作品右侧文案只保留“更多角色与制作细节，请前往完整作品展示。”，并保留唯一“浏览作品展示”按钮。
- 桌面双图最大 360×480；1440px 宽视口的双图间距为 56px。更窄视口按可用宽度缩小，保持 3:4，不横向滚动。
- 首页图片仍进入 `/works/{slug}?view=home-featured`，但代表作品路径不再执行共享媒体 View Transition；委托与领养的既有共享媒体路径保持不变。

## 根因与实现

旧实现只把第一张代表作品链接标记为 `home-featured-media`，而两张链接都使用 `view=home-featured`。点击第二张时，浏览器仍会把第一张竖图当作共享对象，与详情页主图进行 720ms 的比例和位置形变；目标媒体与详情数据加载同时发生，形成明显卡顿。

本轮删除代表作品源/目标的共享对象名，并从全局路由中间件移除 `home-featured` 的 View Transition 启用条件。入口 query 继续保留，URL 与作品详情返回语义不变。标题样式抽到公共 `.home-scene-heading`，三幕删除各自重复的标题 CSS。
