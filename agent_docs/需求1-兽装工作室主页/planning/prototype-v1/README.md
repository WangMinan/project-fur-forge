# PLAN 交互原型 v5

这是阶段 2 的第五轮设计验证产物，不是生产前端，也不会连接 SQLite、OSS 或 QQ SMTP。为保持审查链接稳定，目录仍沿用 `prototype-v1`；页面内版本与本说明统一为 v5。公开站入口为 [index.html](./index.html)，后台登录评审入口为 [index.html#admin-login](./index.html#admin-login)；直接打开即可浏览，使用本地 HTTP 服务时剪贴板等浏览器能力更稳定。

> **2026-07-29 事实覆盖**：本目录内 HTML、截图和旧审查文件保留为历史原型证据，其中的占位工作室名、隐藏价格、20 MB 上传提示、旧辅助色和狗头闪电方向均不再具有生产实施效力。当前契约以 SPEC/PLAN 为准：中文名“有点小狗工作室”、英文暂用 `dite dog`、适用领养/掉落作品公开人民币价格、每件作品可有有序短属性、原图上限 30,000,000 字节并受 OSS 配额门禁约束；正式 Logo 仍待回执。

## 本轮要验证的判断

1. 首页以一张代表作品图铺满首个视口，工作室名称、短口号、导航和符号只做辅助，不再使用文字/图片等权左右分栏。
2. 向下滚动首先进入 6 件精选作品，验证 3–6 件人工精选和横向滚动；之后才以两张作品图承载自设委托与角色领养入口。
3. 领养设定图、类型和状态清楚可见，但最终行动只能是邮件或展会线下联系。
4. 委托页先用一张代表作品宽图建立制作气质，再公开制作范围、营业状态、邮件人工估价入口和可折叠 FAQ；不伪造站内估价流程，也不编造排期、付款、修改、量体或运输规则。
5. 新建作品使用四步门禁；编辑现有作品直接进入“状态与发布 / 图片管理”，不重复经过新建流程。
6. 当前返图为零时，公开页展示瀑布流骨架与真实空状态；后台仍有独立返图上传、作品关联、元数据和发布入口。
7. 后台“完整导出”统一承载业务数据、图片清单、原图复选下载与永久原图档案入口。
8. “关于我们”与基本约定合并为一个一级页面；同页覆盖 SPEC 锁定的七类约定，不再用大块隐私/统计说明抢占内容。
9. 公开导航提供可见的“首页”入口；内页不使用占据大半屏的说明型页头，作品页直接进入筛选和等大图片网格。
10. 后台使用独立登录页；未登录时不显示任何管理内容，公开站也不暴露后台入口。登录页同时预览用户名/密码登录、空值校验和 30 分钟单次找回邮件流程。

## 正式版本不得出现的原型/评审内容

以下内容只服务于规划和审查，已经从 v5 公开页面移除，并作为生产验收禁用项写入 SPEC：

- `PLAN 原型` 浮条、公开页脚后台入口、公开导航中的登录入口或任何“切换到后台原型”控件；
- “状态由景宸后台维护”“按后台人工顺序”“超过 5 件时如何滚动”“这是骨架屏/加载阶段”等实现说明；
- “先把边界讲清楚”“规划阶段信息结构”“正式文本仍需确认”等评审提示；
- 单独占据大块页面的统计/隐私说明卡片，以及“名称待替换”“示例作品数”等占位说明；
- 为解释页面结构而写的路径标签，例如“我已经有角色设定”“我想遇见一个新角色”。

正式站只保留访客完成浏览作品、了解委托/领养、查看约定和找到联系方式所需的内容。原型中的模拟成功提示只允许存在于后台评审流程，生产后台必须对应真实操作结果。

### 后台

公开站不提供后台入口。原型审查时单独打开 [后台登录页](./index.html#admin-login)，填写任意非空用户名和密码即可进入模拟后台；生产环境必须接入真实认证，不能保留该模拟行为。

- 后台登录：独立地址、用户名/密码、空值错误、找回密码入口；未登录时不渲染可见的管理表格或客户资料。
- 作品管理：查看作品、用途、图片数量与发布状态；编辑直接处理业务/发布状态、当前展会和图片。
- 新建作品：基础信息/用途/状态 → 出厂照或设定图上传处理 → 主图裁切与焦点 → 公开预览/保存草稿。
- 返图管理：关联已有作品 → 批量上传/排序 → 可选署名/日期/主页 → 草稿或发布；不增加授权证明字段。
- 营业状态：委托与领养分别维护开关和公开文案。
- 首页与页面：维护不属于单件作品的站点内容；明确分为首页配置、自设委托说明与 FAQ、角色领养与展会、关于我们与基本约定、联系方式与 SEO。
- 完整导出：业务 CSV、图片清单 CSV、原图复选下载，以及永久原图档案的检索/重新关联入口。

上传向导支持选择本机图片做浏览器预览，也可点击“使用示例图模拟上传”。两者都不会发出 OSS 请求。

## 视觉与交互方向

- 总原则：景宸确认“简洁、以图片为主，Logo、文字介绍以及一些符号都是为兽装展示做辅助的”。页面层级固定为作品图片优先，辅助元素与图片冲突时先删减辅助元素。
- 方向：`全幅作品影像 × 极简工作室标识`，而不是电商商城、赛博世界观或深色工业后台。
- 历史 v5 基线使用白底与低饱和辅助色；生产设计已改用景宸例图提取的 `#1D2D5A/#293C84/#324DAF/#6274BB/#CED3E5` 受控蓝色阶，具体用法见 `.design/public-site/DESIGN_TOKENS.md`。仍不使用大面积黑色或米色区块。
- 字体：中文衬线负责角色感和大标题，系统黑体负责导航、状态与管理界面。
- 图片：首页首屏铺满桌面和手机视口；作品默认 3:4；领养设定图使用较宽画布；自设委托先显示代表作品宽图。正式实现全部由后台裁切用途、主体焦点和桌面/手机文字安全区驱动。
- 首页顺序：`全幅作品首屏 → 精选作品 → 图片式委托/领养入口 → 营业状态 → 当前领养推荐`。
- 作品浏览：首页精选保留横向滚动容器与前后箭头，正式数据为 3–6 件；作品总表使用人工排序的等大 3:4 网格，并按作品用途、装型做两组交集筛选，不做全文搜索。
- 内页页头：只保留短标题、必要营业状态和作品筛选，不重复解释正文内容；访客可在更短滚动距离内看到作品或主要操作。
- 返图表现：公开页使用不等高瀑布流；加载时使用轻量骨架，零数据时切换到真实空状态。
- 动效：只允许菜单、弹窗、卡片轻微位移与图片缩放；尊重 `prefers-reduced-motion`，不使用视频、粒子、声音或 WebGL。
- 移动端：导航折叠；公开作品两列；详情弹窗转为纵向；后台导航固定到底部，创建/上传仍保持单列可操作。
- 原型插画：`assets/*.svg` 为本站原创规划占位图，不来自竞品或用户正式素材；生产前必须全部替换。

## OSS 对界面的直接约束

本节只记录阿里云官方文档已经明确的事实，具体实现以 [PLAN.md](../PLAN.md) 为准。

- OSS 的 Object 由唯一 Key、Data、Object Meta 以及可选 Version ID 组成；所谓目录只是 Key 中的 `/` 前缀效果。因此后台展示“文件夹”不能让业务模型依赖真实目录。
- 历史 v5 页面显示 20 MB；当前产品契约为 30,000,000 字节（UI 显示 30 MB，等于上限可接受）。浏览器仍使用 V4 预签名 `PUT` 直传私有原图，生产签名固定 `Content-MD5`、SHA-256 元数据与 `x-oss-forbid-overwrite: true`；对象键不可预测，重新上传使用新会话和新 Key。开始 T18 前必须先通过 OSS 30 MB 图片处理配额和合成图 `sys/saveas` 门禁。
- 文件 ACL 的私有是官方推荐选项；`public-read` 允许匿名访问并可能带来流量与泄露风险。本项目的原图和草稿衍生图保持私有，预览使用管理员短时签名 URL；只在作品发布后公开对应衍生图，作品下架时撤销公开访问。
- 简单下载对应一次 `GetObject`；后台原图下载必须在鉴权后获得短时访问能力，公开页面不能得到原图对象键。
- OSS 默认 Bucket 域名在浏览器中访问 HTML、图片等文件会强制下载，不能作为生产图片在线预览域名。生产公开图片需要绑定自定义媒体域名；杭州 Bucket 的绑定域名必须先完成 ICP 备案，并按“先绑定、再 CNAME、最后验证”的顺序配置。
- 在正式媒体域名可用前，本地公开页面可通过仅开发环境启用的同源媒体端点显示已被发布内容引用的 `READY` 衍生图；该端点由 Nitro 按数据库媒体 ID 和发布关系校验，不接受任意 Object Key，不允许读取草稿/已下架衍生图或原图，也不进入生产拓扑。管理员草稿预览使用短时签名 GET。
- 当前同一 Bucket 同时保存私有原图和公开网页衍生图，因此不启用 CDN 私有 OSS 全桶回源；公开站只访问经处理、验证后明确设为 `public-read` 的网页衍生对象。

## 已确认的审查结论

用户已通过 `PLAN:OQ-018` 确认以下九项方向；它们是后续实现和视觉验收基线，不再是待答问题：

1. 全视口作品图建立首页第一印象，工作室名、短句、导航与符号退居辅助。
2. 首页下滑后先看精选作品，再进入图片式自设委托/角色领养。
3. 以 3–6 件人工精选、横向滚动与箭头承载首页作品浏览。
4. 作品页采用“作品用途 + 装型”两组筛选和严格等大的作品网格。
5. “关于我们”页内继续展示基本约定，不拆成两个一级页签。
6. 自设委托先展示代表作品宽图，再进入制作范围、邮件和 FAQ。
7. 后台使用独立登录页，与公开站入口分离。
8. 后台区分新建四步门禁、现有作品快速编辑、独立返图上传及“首页与页面”职责。
9. 完整导出中心覆盖业务 CSV、图片清单、原图下载和永久原图档案。

生产设计仍需用最终正式 Logo、出厂照与设定图再做一次样张校准；例图狗头闪电不得替代正式 Logo。该校准不得改变以上已确认的信息架构和视觉层级。
